### 关键 Bug 与教训
1. **v1 bug**: `$_` 变量在 PowerShell 交互式会话中扩展为空，导致保存了文件名（string）而非文件对象 → 首次移动后后续循环 Find 同名文件产生幽灵引用
2. **v2 bug**: 在 Move-Item 时 `-Destination "$RootDir\99_Catchall\Doc"` 中的 `Doc` 原本应为目录，但目标目录创建时被脚本逻辑赋值为文件路径，导致 `Doc` 变成了文件而不是目录。后果：后续所有移动到 99_Catchall\Doc 的文件被重命名为 "Doc"（覆盖原文件），丢失了 69 个文件的内容
3. **编码教训**: UTF-8 无 BOM 在 PowerShell 5.1 下会导致中文乱码/解析失败。解决方案：用 Python 写文件时指定 `encoding='utf-8-sig'`
4. **路径规范**: 中文路径在 PowerShell 中需用环境变量或确保编码正确
