# 第8章 地基承载力

## 8.1 概述

### 8.1.1 地基承载力的概念

**地基承载力**（Bearing Capacity）是指地基土在外荷载作用下抵抗剪切破坏和过大变形的能力。当基底压力超过地基承载力时，地基土发生整体或局部剪切破坏，导致建筑物产生过大的沉降、不均匀沉降或倾斜，严重时会导致建筑物的倒塌。

地基承载力问题是土力学三大核心问题（渗透、沉降、承载力）之一，也是基础工程设计的核心内容。与土压力问题（侧向荷载）和边坡稳定问题（主动滑动）不同，地基承载力问题涉及的是**地基土在基底压力作用下的整体稳定性**。

地基承载力的研究具有重要的工程意义和经济意义：
- 合理确定地基承载力，可以优化基础设计，降低工程造价
- 过高估计承载力可能导致地基失稳事故
- 过低估计承载力则造成基础设计保守，增加建设成本

### 8.1.2 地基承载力的相关规范

我国与地基承载力相关的主要规范有：
- **《建筑地基基础设计规范》GB 50007**：规定地基承载力的确定方法和设计要求
- **《岩土工程勘察规范》GB 50021**：规定承载力参数的获取方法和原位测试方法
- **《公路桥涵地基与基础设计规范》JTG 3363**：公路桥涵地基的设计规定
- **《铁路桥涵地基和基础设计规范》TB 10093**：铁路工程的地基设计规定

### 8.1.3 地基承载力的确定方法

地基承载力的确定方法分为三大类：

**1. 理论公式法**：基于土力学原理（极限平衡理论、塑性理论）推导承载力公式，如太沙基公式、普朗德尔公式、梅耶霍夫公式、汉森公式、魏锡克公式等。

**2. 规范表格法**：根据标准贯入试验（SPT）、静力触探试验（CPT）、平板载荷试验等原位测试结果，查表确定承载力特征值。

**3. 经验估算法**：根据地区经验或类比已有工程资料，结合室内试验结果综合确定。

工程设计中，通常**理论公式法**和**规范表格法**相结合，并以**载荷试验**结果作为验证。

## 8.2 地基破坏模式

### 8.2.1 三种破坏模式

当地基上的荷载逐渐增加时，地基土可能发生三种不同类型的破坏模式：

**整体剪切破坏**（General Shear Failure）：这是最典型的破坏模式，发生于密实土或硬黏土地基。其特征为：
- 基础一侧土体被向外侧推移
- 形成明显的滑动面，从基底边缘延伸至地表
- 基底一侧土体突然下沉，另一侧土体被挤出
- 地面出现隆起
- 荷载-沉降（$p$-$s$）曲线有明显的陡降段
- 破坏具有突发性，事前有明显预兆

**局部剪切破坏**（Local Shear Failure）：发生于中等密实砂土或中等硬度黏土地基。其特征为：
- 滑动面不延伸到地表，终止于基底以下某一深度
- 地面变形以沉降为主，隆起不明显
- $p$-$s$ 曲线没有明显陡降，为渐进性破坏
- 破坏过程相对缓慢

**冲切破坏**（Punching Shear Failure）：发生于松砂或软黏土地基。其特征为：
- 基础如冲刀一样切入土中
- 基础侧面与土之间发生垂直剪切
- 地面沉降均匀，无明显隆起
- $p$-$s$ 曲线为缓变形，无明显破坏点

### 8.2.2 影响破坏模式的因素

破坏模式主要取决于：
- **土的密实度或硬度**：密实 $\Rightarrow$ 整体剪切；松散/软 $\Rightarrow$ 冲切
- **基础埋深**：埋深越大，约束越大，越倾向于整体剪切
- **荷载施加速率**：快速加载 $\Rightarrow$ 更易发生整体剪切
- **土的压缩性**：高压缩性土 $\Rightarrow$ 局部或冲切破坏
- **地下水**：降低有效应力，可能改变破坏模式

### 8.2.3 破坏模式的判定

Vesic（1963）提出用刚塑性指数 $I_r$ 判定破坏模式：

$$I_r = \frac{G}{c + q\tan\varphi} = \frac{E}{2(1+\nu)[c + q\tan\varphi]}$$

其中 $G$ 为剪切模量，$E$ 为弹性模量，$\nu$ 为泊松比，$q$ 为基底有效侧限压力。

- $I_r > I_{r,cr}$（临界值，约3～5）：整体剪切破坏
- $I_r \approx I_{r,cr}$：局部剪切破坏
- $I_r < I_{r,cr}$：冲切破坏

### 8.2.4 三种破坏模式的详细特征

#### 8.2.4.1 整体剪切破坏

**整体剪切破坏**（General Shear Failure）是典型的地基破坏模式，发生于密实砂土或硬黏土地基。

**特征**：
1. 地基土在荷载作用下形成一个完整的滑动面，从基础边缘延伸至地表
2. 滑动面由三部分组成：两个主动 Rankine 区（直线段）+ 一个被动 Rankine 区（曲线段）
3. 基础一侧的土体被向上挤出，另一侧土体向下沉降
4. 荷载-沉降（$p$-$s$）曲线有明显拐点（破坏荷载）
5. 破坏前兆明显（地面隆起、倾斜）

**典型工程现象**：地面出现明显的隆起和裂缝，基础一侧沉降明显，另一侧上抬。

#### 8.2.4.2 局部剪切破坏

**局部剪切破坏**（Local Shear Failure）介于整体剪切和冲剪之间：

**特征**：
1. 滑动面只延伸到地基内部某处，不延伸至地表
2. 基础两侧地表的隆起不明显
3. 荷载-沉降曲线拐点不明显
4. 地基土表现出一定的塑性变形能力

**典型条件**：中等密实砂土（相对密度 $D_r \approx 50\% \sim 70\%$）、中硬黏土。

#### 8.2.4.3 冲剪破坏（刺入破坏）

**冲剪破坏**（Punching Shear Failure）发生于松散砂土或软黏土地基：

**特征**：
1. 基础向下"刺入"土中，基础两侧土体不发生明显的侧向挤出
2. 滑动面不发展至地表
3. 荷载-沉降曲线呈缓变型，无明显拐点
4. 基础沉降很大但地基土未发生整体滑动
5. 破坏具有突然性（前兆不明显）

**典型条件**：松砂（$D_r < 30\%$）、软黏土（$c_u < 30$ kPa）、高压缩性土。

#### 8.2.4.4 三种破坏模式的判断

**经验判断**（Vesic, 1973）：

$$I_r = \frac{G}{c + q\tan\varphi}$$

其中 $G$ 为土的剪切模量，$q$ 为基础旁侧压力（$\gamma D$）。

| $I_r$ 范围 | 破坏模式 |
|-----------|---------|
| $> I_{rr}$ | 整体剪切 |
| $\approx I_{rr}$ | 局部剪切 |
| $< I_{rr}$ | 冲剪破坏 |

$$I_{rr} = \frac{1}{2}\sec\varphi \cdot \left(\frac{q}{c}\right)^{1/2}$$

## 8.3 临塑荷载与临界荷载

### 8.3.1 临塑荷载

**临塑荷载**（Load at Initial Yield）是指地基中任意一点达到极限平衡状态（开始出现塑性区）时，对应的基底压力。临塑荷载对应地基土开始屈服，但尚未发生整体破坏的临界状态。

对于均质土地基，基底宽度为 $B$，埋深为 $D$，地基土的重度为 $\gamma$，饱和重度为 $\gamma_{\text{sat}}$，由弹性理论解（普朗德尔解）可得塑性区边界方程。令塑性区最大深度 $a_{\max} = 0$（即塑性区恰好出现），得到临塑荷载 $p_{cr}$：

$$p_{cr} = \frac{\pi(\gamma D + c\cot\varphi)}{\cot\varphi + \varphi - \pi/2} + \gamma D$$

### 8.3.2 临界荷载

**临界荷载**是指地基中塑性区开展到一定深度（但尚不至于整体破坏）时对应的基底压力。工程中通常控制塑性区最大开展深度为基底宽度的 $1/3$ 或 $1/4$。

《建筑地基基础设计规范》GB 50007 采用塑性区开展深度 $z_{\max} = B/4$ 时的临界荷载 $p_{1/4}$ 作为承载力特征值的理论依据：

$$p_{1/4} = \frac{\pi(B\gamma + 4D\gamma + 4c\cot\varphi)}{\cot\varphi + \varphi - \pi/2} + \gamma D$$

临塑荷载 $p_{cr}$ 和临界荷载 $p_{1/4}$ 的物理意义：它们是按塑性区开展范围控制的承载力取值标准，适用于中等压缩性土。对于高压缩性土，建议采用 $p_{1/4}$；对于低压缩性土，$p_{cr}$ 已足够安全。

## 8.4 极限承载力理论

### 8.4.1 太沙基极限承载力理论

#### 8.4.1.1 基本假定

太沙基（K. Terzaghi，1943）提出了第一个完整的极限承载力公式。其基本假定为：
1. 地基土为均匀、各向同性的刚塑性体
2. 基底完全粗糙
3. 滑动面由直线（主动区）、对数螺旋线（过渡区）和直线（被动区）组成
4. 忽略基底以上侧覆土的抗剪强度，仅考虑其超载作用
5. 忽略基底与土之间的黏聚力

#### 8.4.1.2 极限承载力公式

在中心竖向荷载作用下，均质地基的极限承载力为：

$$p_u = \frac{1}{2}\gamma B N_\gamma + q N_q + c N_c$$

其中：
- $B$：基础宽度（对于条形基础）
- $q = \gamma D$：基底以上超载（$D$ 为埋深）
- $c$：地基土黏聚力
- $N_\gamma$、$N_q$、$N_c$：**承载力系数**，仅为内摩擦角 $\varphi$ 的函数

太沙基承载力系数：
$$N_q = e^{2\pi\tan\varphi}\tan^2\left(45^{\circ} + \frac{\varphi}{2}\right)$$

$$N_c = (N_q - 1)\cot\varphi$$

$$N_\gamma \approx 0.5(N_q + 1)\tan\varphi \quad \text{（太沙基近似公式）}$$

对于条形基础：
$$p_u = \gamma B N_\gamma / 2 + q N_q + c N_c$$

#### 8.4.1.3 承载力系数表

| $\varphi$（°） | $N_q$ | $N_c$ | $N_\gamma$ |
|----------------|-------|-------|------------|
| 0              | 1.00  | 5.70  | 0.00       |
| 5              | 1.57  | 6.82  | 0.45       |
| 10             | 2.47  | 8.35  | 1.22       |
| 15             | 3.94  | 10.98 | 2.65       |
| 20             | 6.40  | 14.83 | 5.39       |
| 25             | 10.66 | 20.72 | 10.68      |
| 30             | 18.40 | 30.14 | 21.10      |
| 35             | 33.29 | 46.12 | 42.40      |

#### 8.4.1.4 不同破坏模式的修正

太沙基对三种破坏模式给出了不同的公式：
- **整体剪切**：$p_u = 0.5\gamma B N_\gamma + q N_q + c N_c$
- **局部剪切**（用于中等密实砂土和硬黏土）：取 $c' = (2/3)c$，$\tan\varphi' = (2/3)\tan\varphi$，按整体剪切公式计算
- **冲切破坏**（用于松散砂土和软黏土）：$p_u = q N_q' + \frac{2}{3}c N_c'$，忽略 $N_\gamma$ 项

**例题8.1**：某条形基础宽度 $B = 3$ m，埋深 $D = 1.5$ m，地基土为砂土，$\gamma = 18.5$ kN/m³，$\varphi = 30^{\circ}$，$c = 0$。求极限承载力。

**解**：由 $\varphi = 30^{\circ}$，查表得：$N_q = 18.40$，$N_\gamma = 21.10$

$$q = \gamma D = 18.5 \times 1.5 = 27.75 \text{ kPa}$$

$$p_u = \frac{1}{2}\gamma B N_\gamma + q N_q + c N_c$$
$$= \frac{1}{2} \times 18.5 \times 3 \times 21.10 + 27.75 \times 18.40 + 0$$
$$= 586.0 + 510.6 = 1096.6 \text{ kPa} \approx 1097 \text{ kPa}$$

### 8.4.2 梅耶霍夫极限承载力理论

#### 8.4.2.1 理论特点

梅耶霍夫（Meyerhof, 1951, 1963）在太沙基理论的基础上进行了以下改进：
1. 引入了**基底倾斜荷载**的修正（不仅考虑竖直荷载）
2. 考虑了**基础埋深范围内土的抗剪强度**（不仅视为超载）
3. 给出了适用于**方形基础和圆形基础**的经验系数
4. 提出了**浅基础和深基础**的统一分析方法

梅耶霍夫的理论在现代工程实践中应用最为广泛，被众多国际规范（如Eurocode 7, API规范）所采用。

#### 8.4.2.2 梅耶霍夫承载力公式

梅耶霍夫公式的一般形式为：

$$p_u = c N_c s_c d_c i_c + q N_q s_q d_q i_q + \frac{1}{2}\gamma B N_\gamma s_\gamma d_\gamma i_\gamma$$

其中：
- $N_c$、$N_q$、$N_\gamma$：承载力系数（梅耶霍夫值，与太沙基略有不同）
- $s$：**形状系数**（考虑基础平面形状的影响）
- $d$：**深度系数**（考虑基础埋深范围内土的抗剪强度）
- $i$：**荷载倾斜系数**（考虑荷载倾斜的影响）

梅耶霍夫承载力系数：
$$N_q = e^{\pi\tan\varphi}\tan^2\left(45^{\circ} + \frac{\varphi}{2}\right)$$

$$N_c = (N_q - 1)\cot\varphi$$

$$N_\gamma = (N_q - 1)\tan(1.4\varphi) \quad \text{（梅耶霍夫经验公式）}$$

#### 8.4.2.3 修正系数

**形状系数**（用于非条形基础）：
$$s_c = 1 + 0.2\frac{B}{L}\frac{N_q}{N_c}, \quad s_q = 1 + 0.1\frac{B}{L}\tan\varphi, \quad s_\gamma = 1 - 0.1\frac{B}{L}$$

其中 $L$ 为基础长度。对于条形基础（$L \gg B$），$s_c = s_q = s_\gamma = 1$。

**深度系数**（考虑埋深范围内土的强度）：
$$d_c = 1 + 0.4\frac{D}{B}, \quad d_q = 1 + 0.2\frac{D}{B}\tan\varphi, \quad d_\gamma = 1$$

（当 $D/B > 1.5$ 时，$d_c = d_q = 1.2$ 封顶）

**荷载倾斜系数**（当荷载与竖直方向夹角为 $\alpha$）：
$$i_c = i_q = \left(1 - \frac{\alpha}{90^{\circ}}\right)^2, \quad i_\gamma = \left(1 - \frac{\alpha}{\varphi}\right)^2$$

### 8.4.3 汉森与魏锡克承载力公式

#### 8.4.3.1 汉森公式

汉森（Hansen, 1970）在梅耶霍夫理论的基础上，进一步完善了深基础、地基非均质性、不排水条件下的承载力公式。其特点是**将各种影响因素分解为独立的修正系数**，便于工程应用：

$$p_u = c N_c s_c d_c i_c b_c g_c + q N_q s_q d_q i_q b_q g_q + \frac{1}{2}\gamma B N_\gamma s_\gamma d_\gamma i_\gamma b_\gamma g_\gamma$$

其中 $b$ 为**基底倾斜系数**（考虑基底面倾斜），$g$ 为**地面倾斜系数**（考虑地表倾斜）。

汉森公式在《港口工程地基规范》JTS 147中被采用，是我国港口工程地基设计的法定方法。

#### 8.4.3.2 魏锡克公式

魏锡克（Vesic, 1973, 1975）在汉森公式的基础上，进一步完善了：
1. 引入**承载力系数 $N_\gamma$ 的更精确表达式**
2. 提出了**应变影响因子**，用于分析地基破坏前的非线性沉降
3. 给出了**局部或冲切破坏模式**的统一处理方法

魏锡克承载力系数 $N_\gamma$：
$$N_\gamma = 2(N_q + 1)\tan\varphi \quad / \quad (1.5 - \sin\varphi)$$

魏锡克公式被《公路桥涵地基与基础设计规范》JTG 3363等采用。

#### 8.4.3.3 承载力公式的比较

| 公式 | 适用条件 | 特点 |
|------|---------|------|
| 太沙基 | 条形基础 | 经典公式，有三个基本项，忽略了形状效应 |
| 梅耶霍夫 | 各种形状基础 | 引入形状、深度、倾斜修正，应用最广 |
| 汉森 | 港口工程 | 系数体系完整，修正因子全面 |
| 魏锡克 | 公路桥涵 | $N_\gamma$ 修正精确，考虑应变软化 |

对于同一地基，用不同公式计算的极限承载力可能相差 $20\% \sim 50\%$，这反映了土力学参数不确定性和理论近似性的客观现实。

## 8.5 影响地基承载力的因素

### 8.5.1 土的性质

- **内摩擦角 $\varphi$**：承载力系数 $N_\gamma$、$N_q$ 对 $\varphi$ 极为敏感。$\varphi$ 每增加 $5^{\circ}$，$N_\gamma$ 可能增加一倍以上。因此 $\varphi$ 的准确取值至关重要。
- **黏聚力 $c$**：$N_c$ 直接与 $c$ 相乘，$c$ 的准确性影响 $c N_c$ 项的贡献。
- **重度 $\gamma$**：$N_\gamma$ 项与 $\gamma$ 成正比。地下水位以下，$\gamma$ 应改为有效重度 $\gamma'$。

### 8.5.2 基础条件

- **基础宽度 $B$**：$N_\gamma$ 项与 $B$ 成正比。宽基础的地基承载力高于窄基础（宽度效应）。
- **基础埋深 $D$**：埋深越大，$q = \gamma D$ 越大，承载力越高（深度效应）。
- **基础形状**：方形和圆形基础的承载力高于条形基础（形状效应）。
- **基底粗糙度**：粗糙基底可以更充分地发挥土的强度，承载力高于光滑基底。

### 8.5.3 地下水的影响

地下水对地基承载力的影响主要体现在三个方面：
1. **有效重度降低**：地下水位以下采用有效重度 $\gamma'$，使 $N_\gamma$ 项减小
2. **浮力作用**：基底以下一定深度范围内的土受到浮力作用，减小了地基土的有效自重
3. **水压力叠加**：基底以下的水压力作为附加应力叠加在土压力上

工程中，地下水位对承载力的折减原则为：
- 当 $0 < d_w < B$（地下水位在基底以下，$d_w$ 为距基底的距离）：按线性内插折减 $\gamma$
- 当 $0 < d_w < D$（地下水位在基底以上）：忽略毛细饱和区的强度，采用干重度
- 当 $d_w \geq \max(B, D)$：地下水位影响可忽略

### 8.5.4 荷载条件

- **偏心荷载**：偏心荷载使地基中的应力分布不均匀，有效宽度减小至 $B' = B - 2e$（$e$ 为偏心距）
- **倾斜荷载**：倾斜荷载引入水平分力，降低竖向承载力
- **瞬时荷载**：快速加载条件下，黏性土的不排水强度 $\varphi_u = 0$，需采用不排水分析

### 8.5.5 偏心和倾斜荷载下的地基承载力

#### 8.5.5.1 偏心荷载下的地基承载力

当基础承受偏心荷载（竖向力 $F$ 和弯矩 $M$）时，可以用**等效面积法**将偏心荷载转化为作用于基底中心点的等效竖向荷载：

$$e = \frac{M}{F} \quad \text{（偏心距）}$$

将基底面积修正为等效面积：

$$B' = B - 2e, \quad L' = L$$

当 $e \leq B/6$ 时，基底压力分布为梯形（部分脱开）；当 $e > B/6$ 时，基底压力分布为三角形（部分脱开）。

#### 8.5.5.2 倾斜荷载下的地基承载力

当基础承受倾斜荷载（竖向力 $V$ 和水平力 $H$）时，需要在承载力公式中引入**倾斜修正系数**：

$$p_u = c N_c s_c i_c d_c + q N_q s_q i_q d_q + \frac{1}{2}\gamma B' N_\gamma s_\gamma i_\gamma d_\gamma$$

其中 $i_c$、$i_q$、$i_\gamma$ 为倾斜修正系数（Hansen公式）：

$$i_q = i_c = \left(1 - \frac{0.7H}{V + A c \cot\varphi}\right)^3 \quad (\text{用于 } \varphi = 0)$$
$$i_\gamma = \left(1 - \frac{0.65H}{V + A c \cot\varphi}\right)^3 \quad (\text{用于 } \varphi > 0)$$

当 $H/V > \tan\varphi$ 时，基础将发生水平滑动破坏（而非地基承载力破坏），需要验算抗滑稳定性。

## 8.6 地基承载力特征值的确定

### 8.6.1 载荷试验法

**平板载荷试验**（Plate Load Test, PLT）是确定地基承载力最直接、最可靠的方法。试验在基底标高处的地基土上进行，通过逐级施加荷载，记录荷载-沉降（$p$-$s$）曲线。

根据 $p$-$s$ 曲线确定承载力特征值 $f_{ak}$：
1. **比例界限法**：取 $p$-$s$ 曲线上第一拐点对应的荷载为 $f_{ak}$
2. **极限荷载法**：取极限荷载 $p_u$ 除以安全系数 $K = 2.0 \sim 3.0$ 得 $f_{ak}$
3. **相对沉降控制法**：取 $s/b = 0.01 \sim 0.015$（$b$ 为载荷板宽度）对应的荷载为 $f_{ak}$，用于中、高压缩性土

载荷试验的**局限性**：
- 载荷板尺寸（通常 $0.5 \times 0.5$ m 或圆形 $\phi 0.8$ m）远小于实际基础尺寸，存在**尺寸效应**
- 试验深度有限（通常在地表或基坑底部），难以模拟深基础条件
- 试验周期短，黏性土的固结效应未体现（短期承载力）

### 8.6.2 平板载荷试验详细方法

#### 8.6.2.1 试验方法

平板载荷试验（Plate Load Test, PLT）是在现场对标准尺寸的刚性承压板（方形 $0.5 \times 0.5$ m 或圆形 $\phi 0.8$ m）施加逐级递增的荷载，测定荷载-沉降关系曲线的现场试验方法。

**试验方法**：
1. 基坑开挖至基底设计标高，铺设薄砂垫层（约 50 mm）
2. 安放承压板、千斤顶和反力装置（地锚或堆载）
3. 采用**快速维持荷载法**或**慢速维持荷载法**逐级加荷
4. 每级荷载下，沉降稳定标准：$s_t / s_{t-10min} < 0.1$（或连续 2 小时沉降 $< 0.1$ mm/h）

#### 8.6.2.2 承载力特征值的确定

根据 $p$-$s$ 曲线的形态，采用不同方法确定地基承载力特征值 $f_{ak}$：

**方法一：比例界限法**

当 $p$-$s$ 曲线存在明显的比例界限 $p_0$（线性段终点）时，取 $p_0$ 作为 $f_{ak}$。

**方法二：极限荷载法**

当 $p$-$s$ 曲线存在明显的极限荷载 $p_u$ 时，取 $f_{ak} = p_u / 2.0$。

**方法三：相对沉降控制法（Settlement Criterion）**

当 $p$-$s$ 曲线无明显拐点时，取 $s = 0.01B \sim 0.02B$ 对应的荷载作为 $f_{ak}$（$B$ 为承压板宽度）。

#### 8.6.2.3 从载荷试验结果推算地基承载力

平板载荷试验的承压板尺寸（$B_p = 0.5$ m）远小于实际基础（$B = 3 \sim 30$ m）。由载荷试验结果推算实际基础承载力时，需要考虑：

**尺寸效应**：
$$f_a = f_{p} \cdot \frac{B}{B_p} \quad \text{（经验修正）}$$

实际工程中，应将载荷试验结果与理论公式计算结果相互验证，综合确定 $f_{ak}$。

#### 8.6.2.4 载荷试验结果的修正

由于承压板尺寸（$B_p = 0.5$ m）远小于实际基础尺寸（$B = 3 \sim 30$ m），需要将载荷试验结果换算为实际基础的承载力。

**修正方法一：沉降控制法**（Sowers, 1962）

实际基础的沉降 $s$ 与承压板沉降 $s_p$ 的关系：

$$\frac{s}{s_p} = \left(\frac{B}{B_p}\right)^{\alpha}$$

其中 $\alpha = 0.5 \sim 0.8$（对于砂土 $\alpha \approx 0.5$，对于黏土 $\alpha \approx 0.8$）。

**修正方法二：临界荷载法**

取承压板沉降 $s = 0.01B_p$（即 5 mm）对应的荷载作为地基承载力特征值 $f_{ak}$。该方法适用于无明显比例界限和极限荷载的情况。

### 8.6.3 其他原位测试方法

#### 8.6.3.1 旁压试验（PMT）

**旁压试验**（Pressuremeter Test, PMT）是将圆柱形旁压器（带有可膨胀的橡皮膜）放入钻孔中，通过膨胀橡皮膜对孔壁施加均匀径向压力，测量孔壁土体变形（径向位移）的原位试验。

**旁压模量**（$E_M$）的计算：

$$E_M = 2(1+\nu)(V_c + V_m)\frac{\Delta p}{\Delta V}$$

其中 $V_c$ 为旁压器初始体积，$V_m$ 为压力-体积曲线的斜率截距，$\Delta p / \Delta V$ 为 $p$-$V$ 曲线的斜率，$\nu$ 为泊松比（取 0.33）。

**由旁压试验确定地基承载力**：

$$f_a = \frac{p_L - p_0}{F} + \sigma_v$$

其中 $p_L$ 为极限旁压压力，$p_0$ 为静止旁压压力（初始水平地应力），$F$ 为安全系数（通常 $F = 3.0$）。

#### 8.6.3.2 十字板剪切试验

**十字板剪切试验**（Field Vane Test, FVT）是直接在现场测定饱和软黏土**不排水抗剪强度** $c_u$ 的原位试验方法。

**试验方法**：
1. 将十字板头（四个叶片）旋转插入待测深度
2. 用扭力仪施加扭矩 $T$，使十字板头以一定转速旋转
3. 记录峰值扭矩 $T_{max}$（土体破坏）和残余扭矩 $T_r$（土体重塑后破坏）

**计算公式**：

$$c_u = \frac{2T_{max}}{\pi D^2 H}$$

其中 $D$ 为十字板直径，$H$ 为十字板高度。

#### 8.6.3.3 各原位测试方法的比较

| 方法 | 适用范围 | 测试参数 | 优点 | 缺点 |
|------|---------|---------|------|------|
| 载荷试验 | 浅层土 | $f_a$、$E_s$ | 直接、可靠 | 费时、成本高 |
| 旁压试验 | 各层土 | $E_M$、$p_L$、$c_u$ | 可测深层、快速 | 需要钻孔 |
| 十字板剪切 | 软黏土 | $c_u$ | 快速、简单 | 仅适用于软黏土 |
| SPT | 砂土、黏土 | $N$、$q_c$ | 简单、广泛应用 | 扰动大 |
| CPT | 连续土层 | $q_c$、$f_s$ | 连续、精度高 | 设备复杂 |

### 8.6.4 规范表格法

根据标准贯入试验（SPT）的 $N$ 值或静力触探试验（CPT）的 $q_c$ 值，查规范表格确定承载力特征值。

《建筑地基基础设计规范》GB 50007 中的砂土承载力特征值表（示例）：

| 密实度 | $N$ (击) | $f_{ak}$ (kPa) |
|--------|----------|---------------|
| 松散   | 4～10    | 150～250      |
| 稍密   | 5～15    | 200～300      |
| 中密   | 10～26   | 300～450      |
| 密实   | > 26     | 450～600      |

### 8.6.5 理论公式法

将极限承载力 $p_u$ 除以安全系数 $K$（通常取 $K = 2.0 \sim 3.0$），得到地基承载力特征值：

$$f_a = \frac{p_u}{K}$$

《建筑地基基础设计规范》GB 50007 采用**修正后的临塑荷载公式**（由塑性区 $z_{\max} = B/3$ 的临界荷载导出）作为理论依据：

$$f_a = M_b \gamma B + M_d \gamma_m D + M_c c$$

其中 $M_b$、$M_d$、$M_c$ 为承载力系数，仅与 $\varphi$ 有关（已内置于规范表格）。

### 8.6.6 修正后的地基承载力特征值

当基础宽度 $B \geq 3$ m 或埋深 $D \geq 0.5$ m 时，地基承载力特征值应按下式进行宽度和深度修正：

$$f_a = f_{ak} + \eta_b \gamma (B - 3) + \eta_d \gamma_m (D - 0.5)$$

其中：
- $f_{ak}$：地基承载力特征值（由载荷试验或规范表格确定）
- $\eta_b$、$\eta_d$：宽度和深度修正系数（按土类查表）
- $\gamma$：基底以下土的重度
- $\gamma_m$：基底以上土的加权平均重度
- $B$：基础宽度
- $D$：基础埋深

**例题8.2**：某柱下独立基础，底面尺寸 $3.0 \times 4.5$ m，埋深 $D = 1.8$ m，地基土为粉质黏土，$\gamma = 18.5$ kN/m³，$\gamma_{\text{sat}} = 19.2$ kN/m³，$c = 45$ kPa，$\varphi = 18^{\circ}$。地下水位在基底以下 $3$ m。由载荷试验确定的 $f_{ak} = 200$ kPa。求修正后的地基承载力特征值。

**解**：
（1）查表得 $\varphi = 18^{\circ}$：$\eta_b = 0.3$，$\eta_d = 1.6$

（2）宽度修正：$\eta_b \gamma (B - 3) = 0.3 \times 18.5 \times (3.0 - 3) = 0$

（3）深度修正：地下水位在基底以下，$\gamma_m = \gamma = 18.5$ kN/m³
$$\eta_d \gamma_m (D - 0.5) = 1.6 \times 18.5 \times (1.8 - 0.5) = 1.6 \times 18.5 \times 1.3 = 38.5 \text{ kPa}$$

（4）修正后承载力：
$$f_a = 200 + 0 + 38.5 = 238.5 \text{ kPa}$$

## 8.7 扩展专题

### 8.7.1 复合地基承载力与沉降计算

#### 8.7.1.1 复合地基的基本概念

**复合地基**（Composite Foundation）是指在地基土中设置增强体（桩体），由增强体和桩间土共同承担荷载的地基形式。

**复合地基的分类**：

| 类型 | 代表方法 | 增强体材料 | 传力方式 |
|------|---------|-----------|---------|
| 散体材料桩 | 碎石桩、砂桩 | 散粒体 | 桩体侧向膨胀传递 |
| 柔性桩 | 水泥搅拌桩、旋喷桩 | 水泥土 | 桩体直接承载 |
| 刚性桩 | CFG桩、管桩 | 混凝土/钢筋 | 桩体直接承载 |

**复合地基的工作机理**：

1. **应力分担**：荷载由桩体和桩间土共同承担，桩体承担较大比例的荷载（$\sigma_p > \sigma_s$）
2. **桩体排水**：对于饱和软黏土，桩体（碎石桩、砂桩）可加速固结
3. **挤密效应**：桩体施工过程中对周围土体的挤密作用，提高土的密实度
4. **褥垫层作用**：通过褥垫层的流动补偿，使桩-土共同作用

#### 8.7.1.2 复合地基承载力计算

**承载力计算公式**（复合求和法）：

$$f_{spk} = \beta \cdot m \cdot f_{pk} + (1-m)\beta_s \cdot f_{sk}$$

其中：
- $f_{spk}$：复合地基承载力特征值（kPa）
- $m$：**面积置换率**，$m = A_p / A$（$A_p$ 为单桩截面积，$A$ 为单桩分担的处理面积）
- $f_{pk}$：桩体承载力特征值（kPa）
- $f_{sk}$：桩间土承载力特征值（kPa）
- $\beta$：桩体承载力发挥系数（通常 $0.9 \sim 1.0$）
- $\beta_s$：桩间土承载力发挥系数（通常 $0.9 \sim 1.0$）

**面积置换率**：
$$m = \frac{d^2}{d_e^2}$$

其中 $d$ 为桩径，$d_e$ 为单桩分担的等效处理面积圆的直径。

对于正方形布桩：$d_e = 1.13s$（$s$ 为桩间距）
对于等边三角形布桩：$d_e = 1.05s$

#### 8.7.1.3 复合地基沉降计算

**复合模量法**（将复合地基等效为均质地基）：

$$E_{sp} = m E_p + (1-m) E_s$$

其中 $E_p$ 为桩体压缩模量，$E_s$ 为桩间土压缩模量，$E_{sp}$ 为复合地基的等效压缩模量。

将复合地基视为均质体，用分层总和法计算沉降：

$$s = \psi_s \sum_{i=1}^{n} \frac{\Delta p_i}{E_{sp,i}} \Delta h_i$$

其中 $\psi_s$ 为沉降计算经验系数（根据地区经验确定）。

### 8.7.2 筏板基础与地基的共同作用

#### 8.7.2.1 地基-基础-上部结构共同作用分析

传统的筏板基础设计将筏板视为绝对刚性，将地基视为独立弹簧（温克尔假设），不考虑上部结构的刚度贡献。这是一种**简化分析**，适用于初步设计。

**共同作用分析**（Soil-Structure Interaction, SSI）则需要同时考虑：
1. 地基土的变形特性（地基刚度矩阵）
2. 筏板基础的弯曲变形（筏板刚度矩阵）
3. 上部结构的刚度贡献（上部结构刚度矩阵）

三者通过变形协调条件联立求解，得到筏板内力、地基反力和上部结构内力的真实分布。

**为什么要考虑共同作用？**
- 上部结构的刚度（剪力墙、核心筒）可以"卸载"筏板内力，降低筏板的弯矩和配筋
- 地基的变形（沉降差）会影响上部结构的次应力
- 基础筏板的内力计算结果与简化方法相比，弯矩可降低 $20\% \sim 40\%$

#### 8.7.2.2 筏板基础的破坏模式

筏板基础的破坏通常表现为以下三种模式之一：

1. **弯曲破坏**：筏板配筋不足，产生过大的弯曲裂缝
2. **冲切破坏**：柱下筏板受冲切荷载，产生斜截面裂缝（45°锥形破坏面）
3. **剪切破坏**：筏板受剪承载力不足，产生斜裂缝

**冲切承载力验算**：

$$F_{l} \leq 0.7 \beta_h f_t a_m h_0$$

其中 $F_l$ 为冲切荷载（柱轴力减去筏板冲切破坏锥体内的地基反力），$\beta_h$ 为截面高度影响系数，$a_m = (a_t + a_b)/2$（冲切破坏锥体斜截面的平均长度），$h_0$ 为筏板有效高度。

### 8.7.3 桩基础的承载力与沉降

#### 8.7.3.1 单桩承载力的确定方法

单桩承载力是桩基础设计的核心参数，确定方法包括：

**1. 静载荷试验**（最可靠）

通过在桩顶逐级施加荷载，测量桩顶沉降，得到荷载-沉降曲线（$Q$-$s$ 曲线）。

极限承载力确定方法：
- 明显陡降段：取陡降段起点对应的荷载
- 无明显陡降段：取 $s = 40$ mm（或 $0.05D$）对应的荷载

**2. 经验参数法**

$$Q_u = Q_s + Q_p = u\sum q_{sik}l_i + q_{pk}A_p$$

其中 $q_{sik}$ 为第 $i$ 层土的极限侧阻力标准值，$q_{pk}$ 为极限端阻力标准值。

**3. 静力触探法**

利用 CPT 探头阻力 $q_c$ 和侧壁摩阻 $f_s$ 估算桩承载力：

$$Q_u = u\sum \beta_i f_{si} l_i + \alpha q_{cb} A_p$$

其中 $\alpha$、$\beta_i$ 为经验系数。

#### 8.7.3.2 群桩效应

当桩距较近时，群桩的承载力不等于单桩承载力之和，需考虑**群桩效应**。

**群桩效应系数**：
$$\eta = \frac{Q_{ug}}{n Q_u}$$

其中 $Q_{ug}$ 为群桩极限承载力，$n$ 为桩数，$Q_u$ 为单桩极限承载力。

**影响因素**：
- 桩距：桩距越小，群桩效应越显著
- 桩数：桩数越多，群桩效应越显著
- 土性：黏性土中群桩效应大于砂土

**设计规定**：
- 桩距 $s \geq 3d$：可不考虑群桩效应
- 桩距 $s < 3d$：需考虑群桩效应折减

#### 8.7.3.3 桩基沉降计算

桩基沉降包括三部分：

$$s = s_1 + s_2 + s_3$$

其中：
- $s_1$：桩身压缩变形（对长桩不可忽略）
- $s_2$：桩端土压缩变形（主要分量）
- $s_3$：桩端刺入变形（对软土中的摩擦桩）

**实体深基础法**（简化计算）：

将群桩视为一个实体深基础，基底位于桩端平面，按浅基础沉降计算方法计算：

$$s = \psi_p \sum_{i=1}^{n} \frac{\sigma_{zi}}{E_{si}} \Delta z_i$$

其中 $\psi_p$ 为桩基沉降计算经验系数。

### 8.7.4 特殊土地基的承载力

#### 8.7.4.1 黄土地基承载力

湿陷性黄土地区的地基承载力需考虑湿陷影响：

**承载力修正**：
$$f_a = f_{ak} + \eta_b\gamma(b-3) + \eta_d\gamma_m(d-1.5)$$

注意：黄土的深度修正从 $d = 1.5$ m 开始（而非 0.5 m），因为黄土湿陷性随深度减小。

**湿陷起始压力**：

当基底压力小于湿陷起始压力 $p_{sh}$ 时，黄土不发生湿陷：
$$p_k \leq p_{sh}$$

#### 8.7.4.2 膨胀土地基承载力

膨胀土地基设计需考虑膨胀力的影响：

**承载力验算**：
$$p_k + p_e \leq f_a$$

其中 $p_e$ 为膨胀力（膨胀土浸水膨胀时产生的压力）。

**设计措施**：
- 基础埋深应大于大气影响深度（通常 3~5 m）
- 采用柔性基础（筏板、梁板）适应不均匀胀缩变形
- 设置砂垫层或灰土垫层缓冲胀缩变形

#### 8.7.4.3 冻土地基承载力

多年冻土地区的地基承载力取决于冻土的温度和含冰量：

**承载力影响因素**：
- 地温：温度越低，承载力越高
- 含冰量：含冰量越高，承载力越高
- 荷载类型：长期荷载下冻土蠕变，承载力降低

**设计原则**：
- 保持冻土冻结状态（"保护冻土"原则）
- 或允许冻土融化，按融后土计算承载力（"允许融化"原则）

### 8.7.5 地基处理方法分类与选择

#### 8.7.5.1 地基处理的目的

当天然地基不能满足承载力或沉降要求时，需要进行地基处理。处理的目的包括：

1. **提高承载力**：增强土的抗剪强度
2. **减小沉降**：降低土的压缩性
3. **提高稳定性**：改善土的整体性能
4. **改善环境**：消除特殊土的不良特性（湿陷、膨胀、液化）

#### 8.7.5.2 地基处理方法分类

| 处理类型 | 处理方法 | 适用土类 | 处理深度 |
|---------|---------|---------|---------|
| 换填法 | 挖除换填、抛石挤淤 | 软弱表层土 | 3~5 m |
| 预压法 | 堆载预压、真空预压 | 软黏土 | 10~30 m |
| 复合地基 | 搅拌桩、CFG桩、碎石桩 | 软土、松散砂土 | 5~25 m |
| 强夯法 | 动力固结、强夯置换 | 砂土、填土、黄土 | 5~15 m |
| 振密法 | 振冲密实、振动碾压 | 砂土、粉土 | 5~20 m |
| 化学固化 | 深层搅拌、高压旋喷 | 软土 | 5~30 m |
| 加筋法 | 土工格栅、加筋土 | 填土、软土 | 浅层 |

#### 8.7.5.3 地基处理方法选择

**选择原则**：

1. **技术可行**：处理方法适用于场地土质条件
2. **经济合理**：综合造价最低（包括材料、施工、工期）
3. **环境友好**：施工对周边环境影响小
4. **工期可控**：满足工程进度要求

**选择步骤**：

1. 分析场地地质条件，确定需要处理的问题（承载力不足？沉降过大？液化？）
2. 初选几种可行的处理方法
3. 进行技术经济比较
4. 必要时进行现场试验验证
5. 确定最终方案

#### 8.7.5.4 典型工程的地基处理选择

**案例一：某高层住宅，软土地基**

场地条件：淤泥质黏土，厚度 15 m，$f_{ak} = 60$ kPa，$E_s = 2.5$ MPa。

方案比选：
- 换填法：挖深大，造价高，不推荐
- 预压法：工期长（>1年），不满足工期要求
- CFG桩复合地基：承载力满足，沉降可控，推荐
- 钻孔灌注桩：承载力高，但造价高

**选定方案**：CFG 桩复合地基，桩长 18 m，桩径 400 mm，桩距 1.2 m。

**案例二：某工业厂房，填土地基**

场地条件：素填土，厚度 8 m，成分杂乱，$f_{ak} = 80$ kPa。

方案比选：
- 换填法：挖除换填，造价中等，可行
- 强夯法：处理效果好，造价低，推荐
- 振冲碎石桩：适用于填土，可行

**选定方案**：强夯法，单击能 2000 kN·m，分三遍夯击。

### 8.7.6 地基处理设计实例

#### 8.7.6.1 水泥搅拌桩复合地基设计

**设计条件**：
- 地基土：淤泥质黏土，厚度 12 m，$f_{sk} = 70$ kPa，$E_s = 3.0$ MPa
- 设计要求：$f_{spk} \geq 150$ kPa，$s \leq 80$ mm
- 桩参数：桩径 $d = 500$ mm，桩长 $L = 12$ m

**设计步骤**：

（1）确定桩身强度：

水泥掺量 15%，水泥土无侧限抗压强度 $f_{cu} = 1.5$ MPa。

桩身承载力：
$$R_a = \eta f_{cu} A_p = 0.25 \times 1500 \times 0.196 = 73.5 \text{ kN}$$

（2）确定桩端阻力：

桩端进入持力层（假设为粉质黏土，$q_p = 300$ kPa）：
$$R_p = q_p A_p = 300 \times 0.196 = 58.8 \text{ kN}$$

（3）确定桩侧阻力：

假设桩周土平均侧阻力 $q_s = 10$ kPa：
$$R_s = u_p \sum q_{si} l_i = \pi \times 0.5 \times 10 \times 12 = 188.5 \text{ kN}$$

单桩承载力特征值：
$$R_a = \min(73.5, 58.8 + 188.5) = 73.5 \text{ kN}$$

（4）确定置换率：

$$f_{spk} = m \frac{R_a}{A_p} + \beta (1-m) f_{sk}$$
$$150 = m \times \frac{73.5}{0.196} + 0.9 \times (1-m) \times 70$$
$$150 = 375 m + 63 - 63 m = 312 m + 63$$
$$m = \frac{87}{312} = 0.279 = 27.9\%$$

（5）确定桩距：

正方形布桩：
$$d_e = \frac{d}{\sqrt{m}} = \frac{0.5}{\sqrt{0.279}} = \frac{0.5}{0.528} = 0.95 \text{ m}$$
$$s = \frac{d_e}{1.13} = \frac{0.95}{1.13} = 0.84 \text{ m}$$

取桩距 $s = 0.9$ m。

**设计结果**：水泥搅拌桩，桩径 500 mm，桩长 12 m，桩距 0.9 m，正方形布桩。

#### 8.7.6.2 强夯法设计

**设计条件**：
- 地基土：素填土，厚度 10 m
- 设计要求：$f_{ak} \geq 150$ kPa，消除湿陷性

**设计步骤**：

（1）确定有效加固深度：

$$H = \alpha \sqrt{W \cdot h / 10}$$

其中 $W$ 为锤重（kN），$h$ 为落距（m），$\alpha$ 为修正系数（0.4~0.6）。

要求 $H = 10$ m，取 $\alpha = 0.5$：
$$W \cdot h = \left(\frac{10}{0.5}\right)^2 \times 10 = 4000 \text{ kN·m}$$

选取：锤重 $W = 200$ kN（20 t），落距 $h = 20$ m。

（2）确定单击夯击能：
$$E = W \cdot h = 200 \times 20 = 4000 \text{ kN·m}$$

（3）确定夯击遍数：

分三遍夯击：
- 第一遍：点夯，间距 6 m，每点 8~10 击
- 第二遍：点夯，与第一遍错开，每点 8~10 击
- 第三遍：满夯，搭接 1/4 锤印，每点 3~5 击

（4）确定间歇时间：

两遍之间间歇 7~14 天，使孔隙水压力消散。

**设计结果**：单击夯击能 4000 kN·m，三遍夯击，总夯沉量控制 < 50 mm。

## 8.8 补充例题精选

### 例题8-1（太沙基公式应用）

**题目**：某条形基础，宽度 $B = 3.0$ m，埋深 $D = 1.5$ m。地基土参数：$\gamma = 18.5$ kN/m³，$c = 15$ kPa，$\varphi = 25^{\circ}$。地下水位与基底齐平（$\gamma' = 9.5$ kN/m³）。用太沙基公式计算地基极限承载力 $p_u$ 和承载力特征值 $f_a$（安全系数 $F = 3.0$）。

**解题步骤**：

（1）太沙基公式（条形基础）：
$$p_u = c N_c + q N_q + \frac{1}{2}\gamma B N_\gamma$$

（2）承载力系数（$\varphi = 25^{\circ}$，查表）：
$$N_c = 25.1, \quad N_q = 12.7, \quad N_\gamma = 9.8$$

（3）计算各项：
$$q = \gamma D = 18.5 \times 1.5 = 27.75 \text{ kPa}$$
$$c N_c = 15 \times 25.1 = 376.5 \text{ kPa}$$
$$q N_q = 27.75 \times 12.7 = 352.4 \text{ kPa}$$
$$\frac{1}{2}\gamma' B N_\gamma = \frac{1}{2} \times 9.5 \times 3.0 \times 9.8 = 139.7 \text{ kPa}$$

（4）极限承载力：
$$p_u = 376.5 + 352.4 + 139.7 = 868.6 \text{ kPa}$$

（5）承载力特征值：
$$f_a = \frac{p_u}{F} = \frac{868.6}{3.0} = 289.5 \text{ kPa} \approx 290 \text{ kPa}$$

**答案**：极限承载力 $p_u = 868.6$ kPa；承载力特征值 $f_a = 290$ kPa（安全系数 3.0）。

### 例题8-2（软弱下卧层验算）

**题目**：某柱下独立基础，基底尺寸 $B \times L = 3 \times 4$ m，埋深 $D = 2$ m。上部结构传至基底荷载：竖向力 $F = 1800$ kN，弯矩 $M = 300$ kN·m（沿 $B$ 方向）。

地基土层分布：
- 第①层：粉质黏土（持力层），厚度 $4$ m，$\gamma = 18$ kN/m³，$f_{ak} = 180$ kPa
- 第②层：淤泥质黏土（软弱下卧层），$\gamma_{sat} = 17$ kN/m³，$f_{ak} = 80$ kPa

验算：（1）持力层承载力；（2）软弱下卧层承载力（验算点：基底中心线下第②层顶面）。

**解题步骤**：

（1）持力层验算：

$$p_k = \frac{F}{BL} = \frac{1800}{12} = 150 \text{ kPa} < f_a = 180 \text{ kPa} \quad \checkmark$$

考虑弯矩（沿 $B$ 方向）：
$$e = \frac{M}{F} = \frac{300}{1800} = 0.167 \text{ m} < \frac{B}{6} = 0.5 \text{ m}$$

$$p_{k,\max} = \frac{F}{BL}\left(1 + \frac{6e}{B}\right) = 150 \times \left(1 + \frac{6 \times 0.167}{3}\right) = 150 \times 1.334 = 200 \text{ kPa}$$

$p_{k,\max} = 200 > 180$ kPa，持力层承载力**不满足**！需调整基础尺寸。

（2）软弱下卧层验算（调整后）：

假设基底尺寸调整为 $B \times L = 3.5 \times 4.5$ m，重新验算：
$$p_c = \frac{F}{BL} = \frac{1800}{15.75} = 114.3 \text{ kPa}$$

软弱下卧层顶面处的附加应力（应力扩散法）：
$$p_z = \frac{p_c B L}{(B + 2z \tan\theta)(L + 2z \tan\theta)}$$

其中 $z = 4$ m，$\theta = 23^{\circ}$（$\varphi = 20^{\circ}$ 的经验值）：

$$p_z = \frac{114.3 \times 3.5 \times 4.5}{(3.5 + 2 \times 4 \times 0.424)(4.5 + 2 \times 4 \times 0.424)} = \frac{1800}{(3.5 + 3.39)(4.5 + 3.39)} = \frac{1800}{6.89 \times 7.89} = 33.2 \text{ kPa}$$

下卧层顶面自重应力：
$$\sigma_{cz} = \gamma_1 h_1 + \gamma_2 z = 18 \times 4 + 17 \times 4 = 140 \text{ kPa}$$

下卧层承载力修正：
$$f_{az} = f_{ak2} + \eta_d \gamma_{m2}(d - 0.5) = 80 + 1.0 \times 17.5 \times (6 - 0.5) = 80 + 96.3 = 176.3 \text{ kPa}$$

验算：$p_z + \sigma_{cz} = 33.2 + 140 = 173.2 < 176.3$ kPa，**满足**。

**答案**：（1）原尺寸不满足持力层要求；（2）调整为 $3.5 \times 4.5$ m 后，下卧层验算满足。

### 例题8-3（复合地基承载力计算）

**题目**：某 CFG 桩复合地基，采用正方形布桩，桩间距 $s = 1.5$ m，桩径 $d = 0.4$ m，桩长 $L = 15$ m。桩体承载力特征值 $f_{pk} = 450$ kPa，桩间土承载力特征值 $f_{sk} = 120$ kPa。CFG 桩的压缩模量 $E_p = 150$ MPa，桩间土压缩模量 $E_s = 6$ MPa。

计算：（1）面积置换率 $m$；（2）复合地基承载力特征值 $f_{spk}$（取 $\beta = 0.95$，$\beta_s = 0.95$）；（3）复合压缩模量 $E_{sp}$。

**解题步骤**：

（1）面积置换率：
$$d_e = 1.13s = 1.13 \times 1.5 = 1.695 \text{ m}$$
$$m = \frac{d^2}{d_e^2} = \frac{0.4^2}{1.695^2} = \frac{0.16}{2.873} = 0.0557 \approx 5.6\%$$

（2）复合地基承载力：
$$f_{spk} = \beta m f_{pk} + (1-m)\beta_s f_{sk}$$
$$= 0.95 \times 0.0557 \times 450 + (1-0.0557) \times 0.95 \times 120$$
$$= 23.8 + 0.944 \times 114 = 23.8 + 107.6 = 131.4 \text{ kPa}$$

（3）复合压缩模量：
$$E_{sp} = m E_p + (1-m)E_s = 0.0557 \times 150 + 0.944 \times 6 = 8.36 + 5.66 = 14.02 \text{ MPa}$$

**答案**：（1）$m = 5.6\%$；（2）$f_{spk} = 131.4$ kPa；（3）$E_{sp} = 14.0$ MPa。

### 例题8-4（筏板基础冲切验算）

**题目**：某高层建筑筏板基础，筏板混凝土强度等级 C35（$f_t = 1.57$ MPa $= 1570$ kPa），筏板有效高度 $h_0 = 1.2$ m。底层柱截面尺寸 $0.8 \times 0.8$ m，柱轴向荷载设计值 $F = 12000$ kN。验算柱下筏板的冲切承载力。

**解题步骤**：

（1）计算冲切破坏锥体的投影面积：

冲切破坏锥体斜截面在基础底面的投影长度：
$$a_b = a_t + 2h_0 = 0.8 + 2 \times 1.2 = 3.2 \text{ m}$$

（假设柱周围筏板足够大，满足 $a_b < L_{筏板}$）

$$a_m = \frac{a_t + a_b}{2} = \frac{0.8 + 3.2}{2} = 2.0 \text{ m}$$

（2）冲切验算：

假设筏板基底反力 $p = F / A$（筏板总面积），若柱距足够大，基底反力近似均布：

冲切荷载：
$$F_l = F - p \cdot a_b^2 = 12000 - p \times 3.2 \times 3.2$$

冲切承载力：
$$F_{lu} = 0.7 \beta_h f_t a_m h_0 = 0.7 \times 1.0 \times 1570 \times 2.0 \times 1.2 = 0.7 \times 1570 \times 2.4 = 2638 \text{ kN}$$

要求 $F_l \leq F_{lu}$，即 $p \leq (F - F_{lu}) / a_b^2 = (12000 - 2638) / 10.24 = 9362 / 10.24 = 914$ kPa。

若基底压力 $p < 914$ kPa，冲切验算满足。

**答案**：冲切承载力 $F_{lu} = 2638$ kN；需满足 $F_l \leq 2638$ kN（对应基底反力 $< 914$ kPa）。

### 例题8-5（单桩承载力计算）

**题目**：某钻孔灌注桩，桩径 $d = 0.8$ m，桩长 $L = 25$ m。穿越土层：

| 层号 | 土类 | 层厚 (m) | $q_{sk}$ (kPa) |
|------|------|---------|---------------|
| ① | 淤泥 | 8 | 25 |
| ② | 粉质黏土 | 10 | 60 |
| ③ | 砂砾石 | 7 | 120 |

桩端持力层为砂砾石，$q_{pk} = 2000$ kPa。

计算单桩竖向极限承载力标准值。

**解题步骤**：

（1）桩侧阻力：
$$Q_s = \pi d \sum q_{sik}l_i = \pi \times 0.8 \times (25 \times 8 + 60 \times 10 + 120 \times 7)$$
$$= 2.51 \times (200 + 600 + 840) = 2.51 \times 1640 = 4116 \text{ kN}$$

（2）桩端阻力：
$$Q_p = q_{pk} A_p = 2000 \times \frac{\pi \times 0.8^2}{4} = 2000 \times 0.503 = 1006 \text{ kN}$$

（3）单桩极限承载力：
$$Q_u = Q_s + Q_p = 4116 + 1006 = 5122 \text{ kN}$$

（4）单桩承载力特征值：
$$R_a = \frac{Q_u}{2} = \frac{5122}{2} = 2561 \text{ kN}$$

**答案**：单桩极限承载力标准值 5122 kN，承载力特征值 2561 kN。

### 例题8-6（群桩承载力验算）

**题目**：某柱下桩基，采用 9 根 $\phi600$ 钻孔灌注桩，桩距 $s = 2.0$ m（$3.33d$），正方形布桩。单桩承载力特征值 $R_a = 1200$ kN。柱轴力设计值 $F = 9000$ kN。

桩距 $s = 2.0$ m $= 3.33d > 3d$，可不考虑群桩效应折减。

群桩承载力特征值：
$$R_{ag} = n R_a = 9 \times 1200 = 10800 \text{ kN}$$

（2）承载力验算：

$$\frac{F}{R_{ag}} = \frac{9000}{10800} = 0.83 < 1.0 \text{（满足）}$$

**答案**：群桩承载力满足要求，无需考虑群桩效应折减。

### 例题8-7（碎石桩复合地基设计）

**题目**：某松散砂土地基，$f_{sk} = 100$ kPa，$E_s = 8$ MPa。采用振冲碎石桩处理，桩径 $d = 0.8$ m，桩长 $L = 10$ m，正三角形布桩，桩距 $s = 2.0$ m。桩体承载力特征值 $f_{pk} = 500$ kPa。

计算：（1）面积置换率；（2）复合地基承载力特征值；（3）复合压缩模量。

**解题步骤**：

（1）面积置换率：
$$d_e = 1.05 s = 1.05 \times 2.0 = 2.1 \text{ m}$$
$$m = \frac{d^2}{d_e^2} = \frac{0.8^2}{2.1^2} = \frac{0.64}{4.41} = 0.145 = 14.5\%$$

（2）复合地基承载力：
$$f_{spk} = m f_{pk} + (1-m) f_{sk} = 0.145 \times 500 + 0.855 \times 100 = 72.5 + 85.5 = 158 \text{ kPa}$$

（3）复合压缩模量：

假设桩体压缩模量 $E_p = 30$ MPa：
$$E_{sp} = m E_p + (1-m) E_s = 0.145 \times 30 + 0.855 \times 8 = 4.35 + 6.84 = 11.2 \text{ MPa}$$

**答案**：（1）$m = 14.5\%$；（2）$f_{spk} = 158$ kPa；（3）$E_{sp} = 11.2$ MPa。

## 🤖 AI在地基承载力预测中的应用 🤖

### 数据驱动预测方法

传统极限承载力公式依赖于土性参数的准确测定，但实际工程中参数往往存在空间变异性、测量误差和模型不确定性。机器学习方法可以从大量历史工程数据中学习承载力与各影响因素之间的非线性映射关系，提供可靠的快速预测。

**常用机器学习算法**：
- **人工神经网络（ANN）**：前馈神经网络、卷积神经网络（CNN）处理多维输入
- **支持向量机（SVM/ SVR）**：核函数方法处理非线性问题
- **随机森林（RF）**：集成学习方法，输出特征重要性排序
- **梯度提升树（XGBoost/LightGBM）**：高精度梯度提升算法

### 工程数据库的构建

构建高质量的地基承载力数据库是机器学习应用的基础。数据来源包括：
- 现场载荷试验记录（最可靠）
- 标准贯入试验（SPT）与承载力反分析数据
- 静力触探（CPT）与承载力经验关系数据
- 文献中的试验数据

**数据预处理**：
- 缺失值处理（插值或删除）
- 异常值检测（统计检验或物理合理性判断）
- 归一化处理（$z = (x - \mu) / \sigma$）
- 特征工程（$B/L$、$D/B$ 等组合特征）

### 预测模型实例

以随机森林预测地基承载力特征值为例：

```python
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import cross_val_score
from sklearn.metrics import mean_absolute_error, r2_score

# 特征变量：基础宽度B、埋深D、内摩擦角phi、黏聚力c、重度gamma、标贯击数N
features = ['B', 'D', 'phi', 'c', 'gamma', 'N']
target = 'f_ak'  # 承载力特征值(kPa)

# 加载数据（地基承载力数据库.csv）
df = pd.read_csv('地基承载力数据库.csv')

X = df[features]
y = df[target]

# 训练随机森林
rf = RandomForestRegressor(
    n_estimators=300,
    max_depth=10,
    min_samples_leaf=3,
    random_state=42
)
rf.fit(X, y)

# 交叉验证
cv_scores = cross_val_score(rf, X, y, cv=5, scoring='r2')
print(f"5折交叉验证 R²: {cv_scores.mean():.3f} ± {cv_scores.std():.3f}")

# 预测新样本
new_data = np.array([[3.0, 1.8, 18, 45, 18.5, 12]])  # B=3m, D=1.8m, phi=18°, c=45kPa
f_ak_pred = rf.predict(new_data)
print(f"预测地基承载力特征值: {f_ak_pred[0]:.1f} kPa")

# 特征重要性
importance = pd.Series(rf.feature_importances_, index=features).sort_values(ascending=False)
print("\n特征重要性排序：")
print(importance)
```

典型随机森林模型在承载力预测中的精度可达 $R^2 = 0.88 \sim 0.95$，MAE（平均绝对误差）约为 $30 \sim 60$ kPa。

### 不确定性量化和可靠度设计

机器学习预测结果的**不确定性量化**对于可靠度设计至关重要。贝叶斯方法（如贝叶斯神经网络、贝叶斯线性回归）可以同时给出预测均值和预测标准差，从而计算承载力的置信区间。

$$f_{ak} = f_{\text{ML}} \pm z_{\alpha/2} \cdot \sigma_{\text{pred}}$$

其中 $z_{\alpha/2}$ 为正态分布分位数（如 $95\%$ 置信区间对应 $z = 1.96$）。

基于概率的承载力设计（可靠度设计）将承载力视为随机变量，与荷载效应（随机变量）一起进行可靠度分析：

$$P_f = P(R - S < 0) = \Phi(-\beta) \leq [P_f]$$

其中 $R$ 为抗力（地基承载力），$S$ 为荷载效应，$\beta$ 为可靠度指标（目标值 $\beta_T = 3.0 \sim 3.5$）。

## 🟥 课程思政：工程规范与工程师责任 🟥

### 地基失稳的惨痛教训

地基承载力问题直接关系到建筑物的安全与稳定。一旦地基失稳，往往造成不可挽回的人员伤亡和财产损失。

**案例：某教学楼地基沉降事故（2004年）**
某地一栋6层教学楼，投入使用3年后出现严重不均匀沉降，最大沉降差超过200 mm，墙体开裂严重，最终被迫拆除。事故调查显示：
- 场地地质勘察不充分，未发现基底以下8米处存在厚度3.5米的淤泥质软土层
- 设计采用的地基承载力特征值（220 kPa）仅基于表层土试验，未考虑深部软土的影响
- 施工期间发现地基土与勘察报告不符，但未引起足够重视
- 未进行沉降计算和变形验算，仅按承载力控制设计

### 岩土工程师的规范意识

地基承载力的确定是一个**系统工程**，涉及勘察、设计、施工、监测多个环节。任何环节的疏忽都可能导致承载力取值失误。

岩土工程师在承载力问题上的责任意识应包括：
1. **勘察为本**：地基承载力的根本依据是工程勘察。勘察孔间距、数量、取样质量直接决定参数的代表性。
2. **变形控制**：现代地基设计已经从单纯的"承载力控制"转变为"变形控制"。即使承载力满足要求，过大的沉降或不均匀沉降也会导致建筑物的正常使用功能受损。
3. **动态设计**：地基-基础-上部结构是一个相互作用体系。设计应充分考虑施工过程中的信息反馈，必要时调整设计参数。
4. **终身负责**：工程师对工程质量的终身责任，意味着承载力的确定必须经得起时间和实践的检验。

《建设工程质量管理条例》明确规定："从事建设工程勘察、设计的单位应当依法取得相应等级的资质证书，并在其资质等级许可的范围内承揽工程。""勘察、设计单位必须按照工程建设强制性标准进行勘察、设计，并对其勘察、设计的质量负责。"

## 8.9 本章小结

1. 地基承载力是地基土抵抗剪切破坏和过大变形的综合能力，其确定方法包括**载荷试验、规范表格和理论公式**三类。

2. 地基破坏模式分为**整体剪切、局部剪切和冲切破坏**，取决于土的密实度、压缩性和基础条件。Vesic刚塑性指数 $I_r$ 可用于破坏模式的判定。

3. **太沙基极限承载力公式**是经典理论，形式为 $p_u = 0.5\gamma B N_\gamma + q N_q + c N_c$。**梅耶霍夫、汉森、魏锡克**公式在此基础上引入了形状、深度、倾斜等修正系数，使公式更加完善。

4. 地基承载力特征值 $f_{ak}$ 由**载荷试验**或**规范表格**确定，当基础宽度 $B \geq 3$ m 或埋深 $D \geq 0.5$ m 时，需进行**宽度和深度修正**。

5. **地下水**对承载力的影响不可忽视：有效重度折减、浮力作用和水压力叠加均会降低有效承载力。

6. **机器学习**方法为地基承载力的快速预测提供了新的技术途径，但高质量训练数据库的构建和模型不确定性量化仍是当前研究的重点。

7. 地基设计应遵循**承载力控制与变形控制相结合**的原则，以工程勘察为根本依据，以规范标准为基本准则。
