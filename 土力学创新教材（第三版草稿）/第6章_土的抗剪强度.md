# 第6章 土的抗剪强度

## 6.1 概述

**土的抗剪强度**是指土体抵抗剪切破坏的极限能力。当土体受到外荷载作用时，内部产生剪应力；当某一点的剪应力达到土的抗剪强度时，该点发生剪切破坏；随着破坏点的发展，最终形成完整的滑动面，土体丧失整体稳定性。土坡滑动、挡土墙倾覆、地基承载力丧失、深基坑底部隆起等工程问题，其本质都是土的抗剪强度被外力超越所致。

抗剪强度是土力学中最核心的力学参数之一。与钢材的屈服强度或混凝土的抗压强度不同，土的抗剪强度不是材料的固有常数，而是强烈依赖于**应力状态**、**排水条件**、**剪切速率**以及**土的应力历史**的综合结果。这使得抗剪强度的确定远比金属材料复杂，也是土力学教学中的重点和难点。

本章将系统阐述土的抗剪强度理论、试验方法以及不同条件下的强度特性。特别强调**莫尔-库仑强度理论**这一核心框架，它是土坡稳定分析、地基承载力计算、挡土墙土压力计算的理论基础。通过本章学习，读者应掌握：
1. 莫尔-库仑强度准则的物理意义和数学表达式
2. 不同试验方法的原理、适用范围和成果应用
3. 饱和黏性土在不同排水条件下的强度特性
4. 无黏性土的强度机理
5. 应力路径对强度的影响规律
6. 特殊土（软土、黄土、膨胀土、冻土）的强度特性

## 6.2 莫尔-库仑强度理论

### 6.2.1 库仑定律

1773年，法国物理学家库仑（Charles-Augustin de Coulomb）通过砂土的剪切试验，提出了著名的库仑定律：

$$\tau_f = \sigma \tan\varphi$$

对于黏性土，库仑定律推广为：

$$\tau_f = c + \sigma \tan\varphi$$

其中：
- $\tau_f$ 为土的抗剪强度（kPa）
- $\sigma$ 为剪切面上的法向应力（kPa）
- $c$ 为土的黏聚力（kPa）
- $\varphi$ 为土的内摩擦角（°）

**内摩擦角 $\varphi$** 反映了土颗粒之间的滑动摩擦和咬合摩擦效应。对于粗粒土（砂土、碎石土），$\varphi$ 主要来自颗粒间的滑动摩擦和翻越效应；对于黏性土，$\varphi$ 还包括颗粒间胶结物的破坏效应。纯砂土的 $\varphi$ 可达 $30^{\circ} \sim 40^{\circ}$，而高塑性黏土的 $\varphi$ 可低至 $5^{\circ} \sim 10^{\circ}$。

**黏聚力 $c$** 反映了土颗粒之间的黏结作用。砂土的 $c \approx 0$（无黏性土）；黏性土的 $c$ 由颗粒间的分子引力（原始黏聚力）、化学胶结作用（固化黏聚力）和土骨架的加固作用（次生黏聚力）共同构成。

### 6.2.2 莫尔应力圆

材料力学中，任意一点应力状态可以用相互垂直的 $\sigma$ 和 $\tau$ 表示。一点的法向应力 $\sigma$ 和剪应力 $\tau$ 与主应力 $\sigma_1$、$\sigma_3$ 的关系为：

$$\sigma = \frac{\sigma_1 + \sigma_3}{2} + \frac{\sigma_1 - \sigma_3}{2}\cos2\alpha$$

$$\tau = \frac{\sigma_1 - \sigma_3}{2}\sin2\alpha$$

在 $\sigma$-$\tau$ 坐标系中，上述方程描述了一个圆，称为**莫尔应力圆**（Mohr's Circle）。圆上任意一点代表与主应力平面成 $\alpha$ 角度平面上的应力状态。圆的半径为 $(\sigma_1 - \sigma_3)/2$，圆心坐标为 $[(\sigma_1+\sigma_3)/2, 0]$。

### 6.2.3 莫尔-库仑强度理论

1900年，奥地利工程师莫尔（Christian Otto Mohr）提出了莫尔强度理论：当材料某一点任意方向平面上的剪应力 $\tau$ 达到该平面法向应力 $\sigma$ 下的极限剪应力 $\tau_f$ 时，材料发生剪切破坏。即：

$$|\tau| = \tau_f(\sigma)$$

将库仑定律代入，得到**莫尔-库仑强度准则**（Mohr-Coulomb Failure Criterion）：

$$|\tau| = c + \sigma \tan\varphi$$

在 $\sigma$-$\tau$ 坐标系中，库仑定律是一条直线，称为**抗剪强度包线**。当莫尔应力圆与抗剪强度包线相切时，材料处于极限平衡状态；圆在包线下方时，安全；圆超出包线时，已发生破坏。

莫尔-库仑理论的核心物理意义在于：**材料是否破坏，不仅取决于最大剪应力的大小，还取决于破坏面上法向应力的大小。** 同一大小的剪应力，在高法向应力下不会引起破坏，但在低法向应力下可能导致破坏。这与土的实际行为高度吻合。

**极限平衡条件**：将莫尔应力圆与强度包线相切的几何关系代入，可以得到用主应力表示的极限平衡条件。对于平面应变问题，主应力与破坏面法向方向夹角为 $\alpha_f = 45^{\circ} + \varphi/2$。

推导如下：设破坏面与最大主应力平面夹角为 $\alpha_f$，该面上的正应力 $\sigma$ 和剪应力 $\tau$ 为：

$$\sigma = \frac{\sigma_1 + \sigma_3}{2} + \frac{\sigma_1 - \sigma_3}{2}\cos2\alpha_f$$

$$\tau = \frac{\sigma_1 - \sigma_3}{2}\sin2\alpha_f$$

当莫尔圆与强度包线相切时，切点坐标 $(\sigma, \tau)$ 满足 $\tau = c + \sigma \tan\varphi$。联立求解可得：

$$\sigma_1 = \sigma_3 \tan^2\left(45^{\circ} + \frac{\varphi}{2}\right) + 2c\tan\left(45^{\circ} + \frac{\varphi}{2}\right)$$

$$\sigma_3 = \frac{\sigma_1}{\tan^2\left(45^{\circ} + \frac{\varphi}{2}\right)} - \frac{2c}{\tan\left(45^{\circ} + \frac{\varphi}{2}\right)}$$

这两个公式是土坡稳定分析、地基承载力计算和土压力计算的基本公式。

### 6.2.4 应力状态与破坏准则

在实际工程中，我们需要判断土体是否已经发生破坏，或在给定的应力状态下安全系数有多大。设安全系数为 $F_s$，则允许的抗剪强度为：

$$\tau_f' = \frac{\tau_f}{F_s} = \frac{c}{F_s} + \frac{\sigma\tan\varphi}{F_s}$$

将实际莫尔圆与降低后的强度包线比较，即可判断安全度。当莫尔圆在降低包线以下时，安全。

**例题6.1**：某土样进行三轴试验，围压 $\sigma_3 = 100 \text{ kPa}$，破坏时轴向应力 $\sigma_1 = 380 \text{ kPa}$。求该土的黏聚力 $c$ 和内摩擦角 $\varphi$。

**解**：根据莫尔-库仑极限平衡条件：

$$\sigma_1 = \sigma_3 \tan^2\left(45^{\circ} + \frac{\varphi}{2}\right) + 2c\tan\left(45^{\circ} + \frac{\varphi}{2}\right)$$

设 $N_\varphi = \tan^2(45^{\circ} + \varphi/2)$，则 $380 = 100N_\varphi + 2c\sqrt{N_\varphi}$。

由单一试验点可近似令 $c=0$ 计算 $\varphi$：

$$N_\varphi = \frac{\sigma_1}{\sigma_3} = \frac{380}{100} = 3.8$$

$$\tan^2\left(45^{\circ} + \frac{\varphi}{2}\right) = 3.8 \Rightarrow 45^{\circ} + \frac{\varphi}{2} = 62.7^{\circ} \Rightarrow \varphi = 35.4^{\circ}$$

当 $c \neq 0$ 时，需要至少两个不同围压的试验数据来联立求解 $c$ 和 $\varphi$。

## 6.3 抗剪强度试验方法

### 6.3.1 直接剪切试验

#### 6.3.1.1 试验原理

**直接剪切试验**（Direct Shear Test）是最简便、最常用的土的抗剪强度测定方法。试验使用标准剪切盒，将土样置于上下两个盒体之间的剪切面上，通过施加垂直压力 $P$ 使土样产生法向应力 $\sigma = P/A$（$A$ 为剪切面积），然后施加水平推力 $T$ 逐渐增加剪切位移，直至土样破坏。记录剪切过程中的水平力 $T$ 和剪切位移 $\Delta$，得到剪应力 $\tau = T/A$ 随剪切位移的变化曲线。

剪切盒的截面通常为圆形（面积 $30 \text{ cm}^2$ 或 $60 \text{ cm}^2$）或方形（$60\text{ mm} \times 60\text{ mm}$）。试验时，上盒固定，下盒水平移动。

#### 6.3.1.2 试验方法分类

根据剪切排水条件的不同，直剪试验分为三种类型：

**快剪试验（Q试验）**：试验过程中不允许土样排水。施加垂直压力后，立即施加水平剪切力，剪切速率较快（通常 $0.8 \sim 1.2 \text{ mm/min}$），使土样在 $3 \sim 5$ 分钟内破坏。该方法模拟土体快速加载且来不及排水的条件，适用于透水性低的黏性土。

**固结快剪试验（RQ试验）**：先使土样在垂直压力下固结排水，待固结完成后，再快速施加水平剪切力（不排水）。该方法模拟土层在长期荷载下固结，然后快速加载的条件。

**慢剪试验（S试验）**：先固结，然后以极慢的速率施加剪切力（$<0.02 \text{ mm/min}$），使土样在剪切过程中始终保持排水状态。该方法得到的内摩擦角与固结排水三轴试验结果相近。

#### 6.3.1.3 成果整理

对同一土样，在不同的垂直压力 $\sigma_1$、$\sigma_2$、$\sigma_3$ 下进行剪切试验，得到相应的破坏剪应力 $\tau_{f1}$、$\tau_{f2}$、$\tau_{f3}$。在 $\sigma$-$\tau$ 坐标系中绘制散点图，用直线拟合，该直线的截距为黏聚力 $c$，倾角为内摩擦角 $\varphi$。

直剪试验的**优点**：
1. 设备简单，操作方便，试验周期短
2. 试验费用低，适合大批量试验
3. 可以方便地控制排水条件

直剪试验的**缺点**：
1. 剪切面被固定为水平面，与实际可能的最弱剪切面不一致
2. 剪切过程中剪切面积不断减小，应力分布不均匀
3. 试样内的应力状态随剪切位移变化，不是单一的主应力状态
4. 无法控制试样的孔隙水压力（只能通过控制速率间接实现）
5. 无法严格控制排水边界条件

#### 6.3.1.4 试验注意事项

1. **试样制备**：从原状土样中切取，保证土样的天然含水率和结构不受扰动。砂土采用击实方法制备不同密度的试样。
2. **加荷速率**：对于黏性土，速率过快会导致超静孔隙水压力积累，使测得的 $c$、$\varphi$ 偏低；对于砂土，速率对结果影响较小。
3. **饱和处理**：对于饱和土样，应在试验前进行真空饱和或反压力饱和，确保饱和度 $S_r > 95\%$。
4. **平行试验**：每组试验至少进行 3～4 个试样的平行试验，以提高成果的可靠性。

### 6.3.2 三轴压缩试验

#### 6.3.2.1 试验原理与设备

**三轴压缩试验**（Triaxial Compression Test）是测定土的抗剪强度最完善的方法。土样为圆柱形，高径比通常为 $2.0 \sim 2.5$（常用 $80\text{ mm} \times 40\text{ mm}$）。试样外套一层橡皮膜，放入充满液体（通常是水）的压力室中。通过液压系统对试样施加均匀的围压 $\sigma_3$，然后通过轴向加载系统施加轴向压力 $\Delta\sigma$（称为偏应力）。试样破坏时的最大轴向应力为 $\sigma_1 = \sigma_3 + \Delta\sigma_f$。

三轴试验的**核心优势**在于：试样内的应力状态是均匀的 $\sigma_1$（轴向）和 $\sigma_3$（径向），孔隙水压力可以精确测量，排水条件可以严格控制。这使得三轴试验成为研究土的强度特性、验证强度理论和确定设计参数的首选方法。

#### 6.3.2.2 试验类型

根据排水条件的不同，三轴试验分为三种类型：

**不固结不排水试验（UU试验，Unconsolidated Undrained）**：
- 先施加围压 $\sigma_3$，然后立即施加偏应力 $\Delta\sigma$
- 全过程不排水，不测量孔隙水压力
- 适用于快速加载条件下的黏性土（如施工期的软土地基）
- 破坏包线为水平直线，即 $c_u = (\sigma_1 - \sigma_3)/2$，$\varphi_u = 0$
- 这一特性称为"$\varphi = 0$ 分析法"，是软土地基稳定分析的常用方法

**固结不排水试验（CU试验，Consolidated Undrained）**：
- 先在围压下固结排水（测量固结量和排水量），待固结完成后关闭排水阀门
- 然后施加偏应力，剪切过程中不排水
- 在剪切过程中测量孔隙水压力 $u$
- 适用于分析土层在固结后快速加载的情况
- 可同时得到总应力强度参数 $c_{cu}$、$\varphi_{cu}$ 和有效应力参数 $c'$、$\varphi'$

**固结排水试验（CD试验，Consolidated Drained）**：
- 先固结，然后以极慢速率施加偏应力，剪切过程中全程排水
- 孔隙水压力始终保持为零（或与反压平衡）
- 剪切速率极慢（每级荷载下等待超静孔隙水压力完全消散）
- 适用于长期稳定分析（地基的长期承载力、挡土墙的长期土压力）
- 所得参数 $c_d$、$\varphi_d$ 与 CU 有效应力参数 $c'$、$\varphi'$ 接近

#### 6.3.2.3 成果整理

对于 CU 试验，可以得到两组强度参数：
- **总应力参数**：由总应力莫尔圆得到的 $c_{cu}$、$\varphi_{cu}$
- **有效应力参数**：由有效应力 $\sigma' = \sigma - u$ 计算莫尔圆，得到 $c'$、$\varphi'$

有效应力强度参数 $c'$、$\varphi'$ 具有更明确的物理意义，不依赖于应力历史和排水条件，因此是理论研究和工程设计（特别是长期稳定分析）的首选参数。

**例题6.2**：某饱和黏土进行 CU 三轴试验，围压 100 kPa，破坏时偏应力 180 kPa，测得孔隙水压力 60 kPa。求总应力参数和有效应力参数。

**解**：
总应力：
- $\sigma_1 = \sigma_3 + \Delta\sigma = 100 + 180 = 280 \text{ kPa}$
- $\sigma_3 = 100 \text{ kPa}$
- 莫尔圆圆心：$(190, 0)$，半径：$90$ kPa

有效应力：
- $\sigma_1' = 280 - 60 = 220 \text{ kPa}$
- $\sigma_3' = 100 - 60 = 40 \text{ kPa}$
- 莫尔圆圆心：$(130, 0)$，半径：$90$ kPa

若由单一试验点可近似确定 $c'=0$，则：
$$\tan^2\left(45^{\circ} + \frac{\varphi'}{2}\right) = \frac{\sigma_1'}{\sigma_3'} = \frac{220}{40} = 5.5 \Rightarrow \varphi' = 42.7^{\circ}$$

同样，总应力参数若取 $c_{cu}=0$，则 $\tan^2(45°+\varphi_{cu}/2) = 280/100 = 2.8$，$\varphi_{cu} = 28.1°$。

#### 6.3.2.4 破坏标准的确定

三轴试验中，破坏标准的取法直接影响试验结果。常用的破坏标准有：

1. **最大偏应力准则**：取 $\Delta\sigma - \varepsilon_a$ 曲线峰值点对应的偏应力为破坏点。若无明显峰值，取轴向应变 $\varepsilon_a = 15\% \sim 20\%$ 对应的偏应力为破坏点。
2. **最大主应力比准则**：取 $\sigma_1'/\sigma_3'$ 达到最大值时为破坏点。
3. **最大有效主应力比准则**：取 $(\sigma_1 - u)/(\sigma_3 - u)$ 达到最大值。
4. **应变控制准则**：取轴向应变达到某一规定值（如 $\varepsilon_a = 15\%$）时为破坏点。

对于脆性破坏的土（如密砂、硬黏土），以最大偏应力为准；对于塑性破坏的土（如软黏土），以应变控制准则更合适。

### 6.3.3 无侧限抗压强度试验

#### 6.3.3.1 试验原理

**无侧限抗压强度试验**（Unconfined Compression Test）是三轴试验的一种特例，即围压 $\sigma_3 = 0$ 的轴向压缩试验。土样在无侧限条件下承受轴向压力 $q$，破坏时的最大轴向压力称为**无侧限抗压强度** $q_u$。

由于 $\sigma_3 = 0$，根据莫尔-库仑理论，破坏时的最大主应力为 $\sigma_1 = q_u$，最小主应力为 $\sigma_3 = 0$。由极限平衡条件可得：

$$q_u = 2c\tan\left(45^{\circ} + \frac{\varphi}{2}\right)$$

当 $\varphi = 0$ 时（饱和软黏土的 UU 条件），有：

$$q_u = 2c_u \Rightarrow c_u = \frac{q_u}{2}$$

因此，无侧限抗压强度试验可以直接得到饱和软黏土的不排水抗剪强度 $c_u$，这也是该试验最主要的工程应用。

#### 6.3.3.2 试验方法

1. 将圆柱形土样（$\phi 39.1\text{ mm} \times 80\text{ mm}$）放在底座上
2. 以 $0.5\% \sim 2.0\%$ 应变/分钟的速率施加轴向荷载
3. 记录轴向压力和轴向应变，绘制 $q - \varepsilon_a$ 曲线
4. 取曲线的峰值（或 $\varepsilon_a = 15\%$ 对应的值）为 $q_u$
5. 若 $q - \varepsilon_a$ 曲线无明显峰值，取 $\varepsilon_a = 15\%$ 对应的压力为 $q_u$

#### 6.3.3.3 应用与局限

**主要应用**：
- 快速评估饱和软黏土的不排水抗剪强度 $c_u$
- 估算地基承载力（太沙基公式中的 $c_u$）
- 判断黏性土的灵敏度

**局限性**：
- 仅适用于能够自立的不排水土（饱和软黏土）
- 假设 $\varphi = 0$，对于内摩擦角较大的土不适用
- 试验中无侧向约束，试样侧面无橡皮膜保护，含水量变化会影响结果
- 试验结果受取样扰动影响较大

#### 6.3.3.4 灵敏度

土的**灵敏度**（Sensitivity）$S_t$ 定义为原状土的无侧限抗压强度 $q_u$ 与相同含水量下重塑土的无侧限抗压强度 $q_u'$ 之比：

$$S_t = \frac{q_u}{q_u'}$$

灵敏度反映土的结构性对强度的影响。按灵敏度分类：
- $1 < S_t \leq 2$：低灵敏
- $2 < S_t \leq 4$：中等灵敏
- $4 < S_t \leq 8$：高灵敏
- $S_t > 8$：超高灵敏（结构性黏土，如海相黏土）

高灵敏土在扰动后强度急剧降低，在工程中应特别注意取样和施工扰动问题。

### 6.3.4 十字板剪切试验

#### 6.3.4.1 试验原理

**十字板剪切试验**（Vane Shear Test）是一种在现场条件下直接测定土的不排水抗剪强度的试验方法，特别适用于软黏土地基的原位测试。试验时，将十字形叶片（通常为 $75\text{ mm} \times 100\text{ mm}$ 或 $50\text{ mm} \times 100\text{ mm}$）插入待测深度的土层中，通过扭矩施加剪切力，使土体沿圆柱形剪切面发生扭转破坏。

假设土的抗剪强度均匀分布，破坏扭矩 $M$ 与不排水抗剪强度 $c_u$ 的关系为：

$$M = c_u \cdot \pi D H \cdot \frac{D}{2} + 2c_u \cdot \frac{\pi D^2}{2} \cdot \frac{D}{3}$$

化简为：

$$c_u = \frac{2M}{\pi D^2 H + \frac{2\pi D^3}{3}} = \frac{6M}{7\pi D^3}$$

其中 $D$ 为十字板叶片直径，$H$ 为叶片高度。

#### 6.3.4.2 试验特点

**优点**：
1. 现场原位测试，不扰动土样
2. 适用于软黏土（$c_u < 50 \sim 100 \text{ kPa}$）
3. 可在不同深度连续测试，了解 $c_u$ 的垂向分布
4. 试验设备轻便，操作简单

**缺点**：
1. 假设土的不排水抗剪强度沿破坏圆柱面均匀分布
2. 叶片尺寸有限，对于不均匀土层代表性不足
3. 假设破坏面为理想圆柱面，与实际不完全一致
4. 结果受土的各向异性和应力历史影响

#### 6.3.4.3 成果应用

十字板剪切试验测得的不排水抗剪强度 $c_u$ 可用于：
- 软土地基的短期稳定性分析
- 估算地基承载力（与极限平衡理论结合）
- 确定基坑开挖的抗隆起安全系数
- 监测软土地基加固效果（如排水固结）

### 6.3.5 三轴试验详细操作与分析

#### 6.3.5.1 三轴仪组成

**三轴仪组成**：
1. 压力室：透明有机玻璃筒，内装试样和围压介质
2. 加压系统：围压（室压）和轴压（活塞）
3. 排水系统：排水阀、量管、孔隙水压力传感器
4. 量测系统：轴向位移、轴向力、体积变化

#### 6.3.5.2 三轴试验类型总结

**UU 试验**（Unconsolidated Undrained）：
- 不固结：不施加围压固结
- 不排水：剪切过程不排水
- 适用：饱和黏土的短期稳定分析

**CU 试验**（Consolidated Undrained）：
- 固结：施加围压后固结
- 不排水：剪切过程不排水，测孔隙水压力
- 适用：长期稳定分析、有效应力参数测定

**CD 试验**（Consolidated Drained）：
- 固结：施加围压后固结
- 排水：剪切过程排水，超孔隙水压力为零
- 适用：长期稳定分析、排水条件下的强度

#### 6.3.5.3 三轴试验数据分析

**应力计算**：

大主应力：$\sigma_1 = \frac{F}{A} + \sigma_3$

其中 $F$ 为轴向力，$A$ 为当前截面积（考虑鼓胀变形）：
$$A = \frac{A_0 - \Delta V}{H_0 - \Delta H}$$

**有效应力参数计算**：

从 CU 试验的应力路径：
$$\sin\varphi' = \frac{\Delta q}{\Delta p' + 2c'\cos\varphi'}$$

或从破坏时的 Mohr 圆：
$$\sin\varphi' = \frac{(\sigma_1' - \sigma_3')_{max}}{(\sigma_1' + \sigma_3')_{max} + 2c'\cot\varphi'}$$

#### 6.3.5.4 三轴试验注意事项

**1. 试样制备**
- 原状土：小心切削，避免扰动
- 重塑土：控制含水率和密度

**2. 饱和**
- 反压饱和：施加反压使孔隙水压力增大，溶解气泡
- B 值检测：$B = \Delta u / \Delta \sigma_3 \geq 0.95$

**3. 固结**
- 等向固结：$\sigma_1 = \sigma_2 = \sigma_3$
- $K_0$ 固结：$\sigma_3 = K_0 \sigma_1$

**4. 剪切速率**
- UU、CU：0.5~1.0 %/min
- CD：0.003~0.02 %/min（确保排水）

## 6.4 不同类型土的强度特性

### 6.4.1 饱和黏性土的抗剪强度

#### 6.4.1.1 饱和黏性土的强度机理

饱和黏性土的抗剪强度来源于两个机制：**黏聚分量**和**摩擦分量**。

**黏聚分量 $c$** 主要来自：
1. **原始黏聚力**：土颗粒间的分子间吸引力（范德华力），与土的矿物成分、颗粒排列和孔隙溶液的化学成分密切相关
2. **固化黏聚力**：土颗粒间的胶结物质（如碳酸钙、铁氧化物、腐殖质等）在颗粒接触点形成的胶结作用
3. **次生黏聚力**：在长期荷载作用下土骨架的加固效应（触变恢复）

**摩擦分量 $\tan\varphi$** 主要来自：
1. 颗粒表面的粗糙度和形状产生的滑动摩擦
2. 颗粒间的咬合和嵌固作用（这在高应力水平下尤为重要）
3. 颗粒重新排列和翻越所需的能量

对于正常固结饱和黏性土，黏聚力 $c' \approx 0$，有效内摩擦角 $\varphi'$ 通常在 $20^{\circ} \sim 35^{\circ}$ 之间。对于超固结土，$c'$ 显著增大，$\varphi'$ 变化不大。

#### 6.4.1.2 有效应力路径与强度

**有效应力路径**（Effective Stress Path，ESP）是指土样在剪切过程中，有效应力 $\sigma_1'$ 和 $\sigma_3'$ 在 $p'$-$q$ 空间（$p' = (\sigma_1'+\sigma_3')/2$，$q = (\sigma_1 - \sigma_3)/2$）中移动的轨迹。有效应力路径直观地反映了剪切过程中孔隙水压力的变化。

在 CU 试验中，总应力路径（TSP）为水平线（因为总围压 $\sigma_3$ 不变），而有效应力路径（ESP）向左偏离 TSP（因为孔隙水压力 $u > 0$）。ESP 越靠左，说明孔隙水压力越高，土的有效应力降低越快。

有效应力路径的终点就是破坏点。破坏时 ESP 与破坏包线（通常为直线）相切。对于正常固结黏性土，破坏包线在 $p'$-$q$ 空间中为通过原点的直线：

$$q_f = M \cdot p_f'$$

其中 $M$ 为破坏常数，与内摩擦角有关：

$$M = \frac{6\sin\varphi'}{3 - \sin\varphi'} \quad (\text{三轴受压})$$

#### 6.4.1.3 孔隙水压力系数

**孔隙水压力系数 $A$ 和 $B$** 是 Skempton（1954）提出的，用于描述土在剪切过程中孔隙水压力的产生机制。孔隙水压力增量表示为：

$$\Delta u = B[\Delta\sigma_3 + A(\Delta\sigma_1 - \Delta\sigma_3)]$$

- **系数 $B$**：反映土的饱和度和压缩性。对于完全饱和土，$B \approx 1.0$；对于干土，$B \approx 0$；对于非饱和土，$B$ 与饱和度有关。
- **系数 $A$**：反映土的剪胀性。正常固结黏性土和松砂，$A > 0$（剪缩，产生正超静孔隙水压力）；密砂和超固结黏土，在低围压下表现为剪胀，$A < 0$（负孔隙水压力）。

破坏时的孔隙水压力系数记为 $A_f$，其数值可用于估算土的实际有效应力状态。

### 6.4.2 无黏性土的抗剪强度

#### 6.4.2.1 砂土的强度机理

无黏性土（砂土、碎石土）的抗剪强度完全来自颗粒间的摩擦效应，不存在黏聚力（$c = 0$）。其抗剪强度公式简化为：

$$\tau_f = \sigma \tan\varphi$$

内摩擦角 $\varphi$ 由两部分组成：
1. **滑动摩擦分量 $\varphi_\mu$**：颗粒表面间的滑动摩擦，与颗粒表面粗糙度有关，一般为 $20^{\circ} \sim 30^{\circ}$
2. **咬合摩擦分量 $\varphi_c$**：颗粒之间的嵌锁和翻越效应，与土的密实度和颗粒形状有关

对于棱角状、级配良好的砂土，咬合作用强，$\varphi$ 较大；对于圆滑、等粒径的砂土，咬合作用弱，$\varphi$ 较小。碎石土的 $\varphi$ 可达 $40^{\circ} \sim 50^{\circ}$。

#### 6.4.2.2 密实度对强度的影响

**密砂**：颗粒排列紧密，初始孔隙比 $e$ 较小。在剪切过程中，密砂表现出**剪胀性**（剪切时体积膨胀），颗粒需要翻越相邻颗粒才能移动，因此峰值强度较高。但翻越后强度降低，最终降至**临界状态强度**（Critical State Strength），这一现象称为**应变软化**。

**松砂**：颗粒排列松散，初始孔隙比 $e$ 较大。在剪切过程中，松砂表现出**剪缩性**（剪切时体积减小），强度逐渐增加，最终也趋于临界状态强度。松砂没有明显的峰值强度，称为**应变硬化**。

**临界状态**（Critical State）是土力学中的一个重要概念。它是指土体在剪切过程中，当应变足够大、颗粒排列达到一种稳态（既不剪胀也不剪缩）时的状态。在临界状态下，土的应力状态、孔隙比和含水量保持恒定。临界状态线（CSL）在 $p'$-$v$（平均有效应力-比容）平面中为一条对数直线。

#### 6.4.2.3 相对密实度

**相对密实度** $D_r$ 是评价无黏性土密实程度的指标：

$$D_r = \frac{e_{\max} - e}{e_{\max} - e_{\min}} \times 100\%$$

其中 $e_{\max}$、$e_{\min}$、$e$ 分别为最大孔隙比、最小孔隙比和天然孔隙比。

按 $D_r$ 分类：
- $0 \leqslant D_r < 1/3$：松散
- $1/3 \leqslant D_r < 2/3$：中密
- $2/3 \leqslant D_r \leqslant 1$：密实

密实度直接影响砂土的抗剪强度、压缩性和动力液化特性。工程中常通过标准贯入试验（SPT）的 $N$ 值或静力触探试验（CPT）的锥尖阻力 $q_c$ 来评估砂土的密实度。

#### 6.4.2.4 颗粒级配对强度的影响

**良好级配**（级配曲线平缓，$C_u > 5$，$C_c = 1\sim3$）的砂土，颗粒排列紧密，孔隙小，强度高。**不良级配**（级配曲线陡峭，均匀粒径）的砂土，粗颗粒形成骨架，细颗粒填充孔隙，密实度和强度取决于细颗粒的含量和性质。

当细颗粒（$<0.075\text{ mm}$）含量超过一定比例（通常 $> 30\% \sim 50\%$）时，砂土的性质由细颗粒主导，$c$ 增大、$\varphi$ 降低，转变为"砂质粉土"或"粉质砂土"。

### 6.4.3 超固结土的强度特性

#### 6.4.3.1 超固结比与应力历史

土体在地质历史上曾经受到过的最大竖向固结压力称为**先期固结压力** $\sigma_c'$。当前的有效竖向应力 $\sigma_v'$ 与先期固结压力的比值称为**超固结比**（Overconsolidation Ratio, OCR）：

$$\text{OCR} = \frac{\sigma_c'}{\sigma_v'}$$

当 $\text{OCR} = 1$ 时，土处于**正常固结状态**；当 $\text{OCR} > 1$ 时，土处于**超固结状态**。

超固结土的形成原因包括：
- **剥蚀作用**：地表土层被剥蚀卸载（冰川退缩、河流下切）
- **冰川荷载**：历史上曾覆有厚冰层，冰川融化后卸载
- **地下水波动**：地下水位长期下降导致土体卸载
- **人为卸载**：基坑开挖、地下结构建造导致土体侧向卸载

#### 6.4.3.2 超固结土的强度特征

**1. 强度包线的非线性**

超固结土的强度包线在高应力区域不再是直线，而是向下弯曲（曲线形），这意味着有效内摩擦角随围压的增大而降低。这一现象的物理原因是：超高围压下土的结构已经发生不可逆的压碎和重排。

工程中通常将超固结土的强度包线简化为两段直线（双线性模型）：
- 高应力区：$c \approx 0$，$\varphi$ 较低（约 $15^{\circ} \sim 25^{\circ}$）
- 低应力区：$c > 0$，$\varphi$ 较高（约 $25^{\circ} \sim 35^{\circ}$）

转折点对应的围压约为 $\sigma_c'/2 \sim \sigma_c'$。

**2. 卸载-再加载效应**

超固结土在卸载-再加载过程中表现出明显的**回滞效应**：卸载时土的体积变化（回弹）远小于加载时的体积压缩（塑性体积变化）。这意味着卸载阶段的弹性模量（回弹模量）远高于初始加载阶段的压缩模量。

工程意义：基坑开挖后，被动区土体处于卸载状态，其不排水强度和侧向变形模量均比同等深度正常固结土高，这也是基坑设计中"主动区土压力较小、被动区土压力较大"现象的力学基础。

#### 6.4.3.3 现场OCR的评估方法

**1. 室内固结试验**

通过固结试验测定土的$e$-$\log\sigma'$ 曲线，正常固结土的曲线为直线（压缩指数 $C_c$ 为常数），超固结土的卸载-再加载曲线（回弹指数 $C_s$）斜率明显缓于压缩段。OCR 由以下关系确定：

$$\text{OCR} = \frac{\sigma_c'}{\sigma_v'} = 10^{S}$$

其中 $S$ 为现场压缩应力点到正常固结线延长线的水平距离（在 $e$-$\log\sigma'$ 曲线上量取）。

**2. 孔隙水压力法**

利用 CU 试验中的孔隙水压力系数 $A_f$ 推断 OCR：
- 正常固结土（OCR≈1）：$A_f \approx 0.7 \sim 1.0$（正孔压）
- 超固结土（OCR>1）：$A_f \approx 0 \sim 0.3$（孔压较小）
- 强超固结土（OCR>4）：$A_f < 0$（负孔压，即剪胀）

#### 6.4.3.4 工程应用

超固结土的强度特性对以下工程问题具有重要影响：

1. **基坑工程**：开挖后被动区的超固结效应使侧向土压力增加，设计时需考虑
2. **天然边坡**：超固结硬黏土边坡中可能存在卸荷裂隙面（节理、裂隙），这些软弱结构面往往是滑坡的滑动面
3. **古滑坡识别**：古滑坡堆积体中的土体往往经历了强烈的结构性扰动，其 OCR 和强度参数的确定需要特别谨慎

### 6.4.4 应力路径及其对强度的影响

#### 6.4.4.1 应力路径的概念

**应力路径**（Stress Path）是指在外荷载作用下，土体内某一点的主应力状态在应力空间中移动的轨迹。常用的表达方式有：
- $\sigma - \tau$ 平面中的莫尔圆包络图
- $p$-$q$ 平面中的应力路径（$p = (\sigma_1+\sigma_3)/2$，$q = (\sigma_1-\sigma_3)/2$）
- $p'$-$q$ 平面中的有效应力路径

应力路径的概念对于理解土在不同加载条件下的行为非常重要。不同的施工工况对应不同的应力路径。例如：

1. **基础快速加载**：总应力路径为竖直向上（$\sigma_3$ 不变，$\sigma_1$ 增加）
2. **基坑开挖**：总应力路径为水平向左（$\sigma_1$ 减小，$\sigma_3$ 可能不变或减小）
3. **路堤分级填筑**：总应力路径为对角线向上（$\sigma_1$ 和 $\sigma_3$ 同时增加）
4. **地下水位下降**：有效应力路径为竖直向上（总应力不变，有效应力增加）

#### 6.4.4.2 应力路径对破坏的影响

同一土样，在相同的初始应力状态下，施加相同的总应力增量，但以不同的应力路径加载，最终可能达到不同的破坏状态。这是因为不同的应力路径对应不同的孔隙水压力响应，从而导致不同的有效应力状态。

例如，在 $p'$-$q$ 平面中，如果有效应力路径（ESP）始终在破坏线以下，则土体保持稳定；如果 ESP 触及破坏线，则发生剪切破坏。

**例题6.3**：某饱和正常固结黏土的固结排水强度参数为 $c' = 0$，$\varphi' = 30^{\circ}$。在 CU 试验中，围压 200 kPa，破坏时偏应力 280 kPa，孔隙水压力 120 kPa。计算：（1）破坏时的有效主应力比；（2）若改为 CD 试验（同围压），破坏时的偏应力约为多少？

**解**：
（1）破坏时总应力：$\sigma_1 = 380$ kPa，$\sigma_3 = 200$ kPa
有效应力：$\sigma_1' = 380 - 120 = 260$ kPa，$\sigma_3' = 200 - 120 = 80$ kPa
有效主应力比：$\sigma_1'/\sigma_3' = 260/80 = 3.25$

（2）CD 试验中，孔隙水压力始终为零，因此有效应力即为总应力。
由莫尔-库仑准则：$\sigma_1' = \sigma_3' \tan^2(45°+15°) = 200 \times 3.0 = 600$ kPa
偏应力：$\Delta\sigma_f = 600 - 200 = 400$ kPa

可见，同一土样，CU 试验的破坏偏应力（280 kPa）远小于 CD 试验（400 kPa），其原因在于 CU 试验中产生的正孔隙水压力（120 kPa）降低了有效应力。

## 6.5 扩展专题

### 6.5.1 土的破坏准则

#### 6.5.1.1 莫尔-库仑破坏准则的局限性

莫尔-库仑破坏准则在工程实践中应用广泛，但其假设存在以下局限性：

**局限性一：忽略中主应力的影响**

莫尔-库仑准则只考虑最大主应力 $\sigma_1$ 和最小主应力 $\sigma_3$，认为中主应力 $\sigma_2$ 对强度没有影响。但试验研究表明，$\sigma_2$ 对土的强度有显著影响，尤其是对于砂土：
- 三轴压缩（$\sigma_2 = \sigma_3$，即 $b=0$）：强度最低
- 平面应变（$\sigma_2 = (\sigma_1 + \sigma_3)/2$，即 $b \approx 0.3 \sim 0.5$）：强度居中
- 三轴拉伸（$\sigma_2 = \sigma_1$，即 $b=1$）：强度最高

**局限性二：强度包线非直线**

在高应力水平（$\sigma > 5 \sim 10$ MPa）下，土的强度包线不再是直线，而是向下弯曲。这意味着高应力下土的表观内摩擦角降低，破坏面上的正应力增加，剪应力增加的比例减小。

#### 6.5.1.2 其他破坏准则

**Drucker-Prager 准则（扩展的 von Mises 准则）**：

$$f = \alpha I_1 + \sqrt{J_2} - k = 0$$

其中 $I_1 = \sigma_1 + \sigma_2 + \sigma_3$ 为第一应力不变量，$J_2 = \frac{1}{6}[(\sigma_1-\sigma_2)^2 + (\sigma_2-\sigma_3)^2 + (\sigma_3-\sigma_1)^2]$ 为第二偏应力不变量。

该准则考虑了中主应力的影响，在有限元软件（如 ABAQus、PLAXIS）中广泛使用。

**Lade-Duncan 准则**：

$$f = \frac{I_1^3}{I_3} - k = 0$$

其中 $I_3 = \sigma_1 \sigma_2 \sigma_3$ 为第三应力不变量。该准则特别适用于描述砂土在高应力下的破坏行为。

#### 6.5.1.3 破坏准则的选择

工程实践中，应根据土类、应力范围和计算要求选择合适的破坏准则：

| 破坏准则 | 适用场景 | 优点 | 缺点 |
|---------|---------|------|------|
| 莫尔-库仑 | 绝大多数岩土工程 | 物理概念清晰，参数简单 | 忽略中主应力 |
| Drucker-Prager | 有限元数值分析 | 考虑中主应力，光滑连续 | 参数标定复杂 |
| Lade-Duncan | 砂土高应力分析 | 精度高 | 参数多，不对称 |

### 6.5.2 土与结构接触面强度

#### 6.5.2.1 接触面问题的工程意义

土与结构（如桩-土、墙-土、筏板-土）之间的接触面是岩土工程中普遍存在的界面问题。接触面两侧的材料性质差异极大——结构侧（混凝土、钢材）刚度极大，土侧刚度极小——导致接触面上存在复杂的应力传递和变形协调问题。

**典型工程问题**：
1. **桩基中的桩-土界面摩阻力**：桩侧土对桩身的剪切阻力，是桩基承载力的主要来源之一
2. **挡土墙墙背土压力**：土与墙背之间的剪切作用，决定了土压力的大小和分布
3. **地下连续墙槽壁稳定性**：土与槽壁之间的摩阻力，影响槽壁的变形和渗漏

#### 6.5.2.2 接触面剪切试验

研究土-结构接触面强度的标准方法是**直剪仪接触面试验**（Interface Shear Test）：

- 下盒：放置结构材料试块（混凝土板、钢板等）
- 上盒：装入土样
- 施加法向应力 $\sigma_n$（模拟覆盖压力）
- 施加剪切荷载，测定剪切应力 $\tau$ 与剪切位移 $\delta$ 的关系

接触面剪切试验得到的峰值剪切应力通常小于土本身的抗剪强度，这是因为：
- 结构表面粗糙度的影响（光滑面 → 摩阻降低；粗糙面 → 可能产生机械咬合）
- 土颗粒与结构表面之间的吸附作用（化学亲和性）

#### 6.5.2.3 接触面强度参数

接触面的剪切强度通常表示为：

$$\tau_f = c_a + \sigma_n \tan\delta$$

其中：
- $c_a$：**接触面黏聚力**（kPa），取决于土与结构之间的物理化学作用
- $\delta$：**接触面摩擦角**（°），通常 $\delta = \varphi' \sim 0.7\varphi'$（光滑面取小值，粗糙面取大值）

**经验参考**：

| 结构材料 | 接触面条件 | $c_a$ (kPa) | $\delta$ 参考值 |
|---------|-----------|-------------|---------------|
| 混凝土（光滑）| 清洁表面 | $0 \sim 10$ | $(0.5 \sim 0.7)\varphi'$ |
| 混凝土（粗糙）| 振捣粗糙 | $10 \sim 30$ | $(0.7 \sim 1.0)\varphi'$ |
| 钢板（光滑）| 无锈蚀 | $0 \sim 5$ | $(0.3 \sim 0.5)\varphi'$ |
| 木板 | — | $5 \sim 15$ | $(0.4 \sim 0.6)\varphi'$ |

### 6.5.3 超固结与各向异性

#### 6.5.3.1 各向异性的成因

天然土体的强度具有显著的**各向异性**（Anisotropy），主要来源于：

**1. 沉积形成的固有各向异性**

土颗粒在沉积过程中倾向于呈扁平状排列，形成**沉积组构**（Sedimentary Fabric）。这使得土体在水平方向和竖直方向的物理力学性质存在系统性差异。例如，正常固结黏土的竖向固结系数 $C_{v,v}$ 通常小于水平向固结系数 $C_{v,h}$。

**2. 应力诱发的各向异性**

土体在非等向固结（$K_0$ 固结）过程中，主应力方向固定（竖直方向），导致土体在 $\sigma_1$ 和 $\sigma_3$ 方向的刚度和强度不同。当后续加载方向（主应力方向）与初始固结方向不一致时，各向异性的影响尤为显著。

#### 6.5.3.2 强度各向异性

土的抗剪强度随剪切方向而变化。试验研究表明：
- 砂土的 $\varphi$ 随中主应力比 $b = (\sigma_2 - \sigma_3)/(\sigma_1 - \sigma_3)$ 变化
- 对于常规三轴压缩（$b=0$），$K_0$ 固结土的破坏面倾向于与沉积面（水平面）呈 $45^{\circ} + \varphi/2$ 角
- 对于平面应变条件（$b \approx 0.3 \sim 0.5$），有效内摩擦角通常高于三轴压缩条件

#### 6.5.3.3 各向异性强度的影响

**边坡稳定分析中的各向异性**

天然土坡的滑动面往往是近似圆弧或复合滑动面，其与水平沉积面的夹角在不同位置不同。各向异性效应使滑动面不同位置处的土体强度参数不同，导致边坡稳定分析的精确解与各向同性假定下的结果产生差异。

**挡土墙土压力计算中的各向异性**

天然土的静止土压力系数 $K_0$ 在水平向和竖直向也存在差异（横观各向同性）。对于这类土，朗肯和库仑土压力理论中的 $K_0$、$K_a$、$K_p$ 需要根据土的各向异性特性进行修正。

### 6.5.4 土的蠕变与长期强度

#### 6.5.4.1 蠕变的概念

**蠕变**（Creep）是指在恒定应力下，土的应变随时间持续增长的现象。蠕变在以下工程中具有重要意义：
- **高边坡**：蠕变导致边坡位移随时间缓慢增长
- **软土地基**：长期荷载下地基沉降持续增加
- **挡土墙**：蠕变使墙背土压力随时间增大（主动土压力向静止土压力方向迁移）
- **隧道衬砌**：蠕变使围岩压力随时间增加

#### 6.5.4.2 土的蠕变机理

土的蠕变主要由以下机制引起：
1. **颗粒间滑移**：颗粒接触点的滑移和重新排列
2. **黏性流动**：孔隙水在颗粒间的黏性流动（仅对饱和土有意义）
3. **化学作用**：矿物溶解、沉淀和胶结的缓慢演化（时间尺度很长）

#### 6.5.4.3 长期强度

土的**长期强度**是指在长期恒定荷载下，土体能够承受而不发生破坏的最大剪应力。随着荷载作用时间的增加，土的强度逐渐降低，最终趋于一个**长期强度值**。

$$c_{LT} = \frac{1}{2} \sim \frac{2}{3} c_{UU}$$

对于黏性土，长期强度约为不排水强度的 $1/2 \sim 2/3$。这对于长期稳定性分析（如挡土墙设计、边坡稳定验算）具有重要意义。

### 6.5.5 不排水强度与有效应力参数的关系

#### 6.5.5.1 正常固结黏土

对于正常固结（NC）饱和黏土，不排水抗剪强度 $c_u$ 与有效应力参数之间存在确定的关系：

**从临界状态理论推导**：

$$c_u = \frac{M}{2} p_0' \exp\left(\frac{\Lambda - 1}{\Lambda}\right)$$

其中 $M = 6\sin\varphi'/(3-\sin\varphi')$ 为临界状态应力比，$p_0'$ 为前期固结压力，$\Lambda = (\lambda - \kappa)/\lambda$ 为塑性体积比。

**简化关系**（经验公式）：

$$c_u \approx \frac{1}{2} \sigma_v' \sin\varphi'$$

或更常用的：

$$\frac{c_u}{\sigma_v'} = 0.11 \sim 0.33$$（对于正常固结黏土）

#### 6.5.5.2 超固结黏土

对于超固结（OC）黏土，不排水强度与超固结比 OCR 相关：

**SHANSEP 关系**（Ladd and Foott, 1977）：

$$\frac{c_u}{\sigma_v'} = \left(\frac{c_u}{\sigma_v'}\right)_{NC} \cdot OCR^m$$

其中 $m$ 为经验指数，通常 $m = 0.7 \sim 0.85$。

**工程应用**：
- 已知 NC 黏土的 $c_u/\sigma_v'$ 和 OCR，可推算 OC 黏土的不排水强度
- 用于基坑开挖、边坡稳定等短期稳定分析

### 6.5.6 岩土工程勘察中抗剪强度参数的合理选取

#### 6.5.6.1 参数选取的基本原则

抗剪强度参数的选取应遵循以下原则：

1. **与设计工况匹配**：长期稳定分析用有效应力参数（$c'$、$\varphi'$），短期稳定分析用不排水强度参数（$c_u$）
2. **与试验条件匹配**：CU 试验得到的 $c'$、$\varphi'$ 用于有效应力分析，UU 试验的 $c_u$ 用于不排水分析
3. **考虑空间变异性**：同一土层不同位置的参数可能存在差异，设计值应取具有足够安全裕度的代表值

#### 6.5.6.2 不同土类的参数选取参考

**砂土**：
- 内摩擦角 $\varphi'$ 通常 $30^{\circ} \sim 40^{\circ}$（密实砂）
- 有效内摩擦角与密实度直接相关：松砂 $\varphi' \approx 28^{\circ}$，密砂 $\varphi' \approx 38^{\circ}$
- 不排水条件下，松砂可发生液化（$\varphi_u = 0$）

**正常固结饱和黏土**：
- $c' \approx 0$，$\varphi' \approx 20^{\circ} \sim 30^{\circ}$
- $c_u$ 随深度线性增加：$c_u = \lambda + \mu z$（$z$ 为深度）
- $c_u / \sigma_v'$（不排水强度比）约为 $0.2 \sim 0.4$

**超固结饱和黏土**：
- $c' > 0$，$\varphi'$ 降低（高应力区）
- $c_u$ 较高，但随 OCR 增大而增大
- 卸载-再加载区间的弹性模量显著提高

**软土**：
- 灵敏度高，取样扰动会严重低估强度
- 现场十字板剪切试验是获取 $c_u$ 的首选方法
- 建议对 $c_u$ 进行修正：$c_{u,\text{设计}} = \eta \cdot c_{u,\text{试验}}$（$\eta \approx 0.7 \sim 0.9$，考虑扰动和空间变异性）

#### 6.5.6.3 勘察报告中参数的审核要点

岩土工程师在审查勘察报告中的抗剪强度参数时，应重点检查：

1. 试验方法是否与设计工况匹配（CU vs. UU vs. CD）
2. 统计方法是否合理（平均值、标准差、变异系数、样本数量）
3. 是否考虑了排水条件和固结状态
4. 是否有与类似工程的类比验证
5. 特殊土（如软土、有机质土）是否进行了特殊处理

### 6.5.7 临界状态土力学简介

#### 6.5.7.1 临界状态的概念

**临界状态**（Critical State）是土体在持续剪切变形下，应力状态和体积保持不变的状态。

**临界状态的特点**：
1. 剪应力比达到临界值：$\eta = q/p' = M$
2. 体积变化率为零：$dv = 0$
3. 土体处于"流动"状态，不再硬化或软化

#### 6.5.7.2 临界状态线（CSL）

在 $p'$-$q$ 平面中，临界状态线（CSL）是一条通过原点的直线：

$$q = M p'$$

在 $p'$-$v$（平均有效应力-比容）平面中，临界状态线是一条对数直线：

$$v = \Gamma - \lambda \ln p'$$

其中 $M$ 为临界应力比，$\Gamma$ 为截距，$\lambda$ 为压缩指数。

#### 6.5.7.3 临界状态理论的意义

**1. 统一的强度理论**

临界状态理论将土的强度与变形统一在一个框架内：
- 强度是变形发展的最终状态
- 体积变化与应力变化耦合

**2. 本构模型的基础**

剑桥模型（Cam-Clay Model）和修正剑桥模型（Modified Cam-Clay Model）是临界状态理论的具体实现，广泛应用于数值分析。

### 例题6-1（CU三轴试验数据分析）

**题目**：某饱和黏土进行固结不排水（CU）三轴试验，得到以下结果：

| 试件编号 | $\sigma_3$ (kPa) | $\Delta\sigma_f$ (kPa) | $u_f$ (kPa) |
|---------|----------------|--------------------|------------|
| 1 | 100 | 180 | 52 |
| 2 | 200 | 300 | 88 |
| 3 | 300 | 400 | 120 |

试：（1）绘制总应力莫尔圆和有效应力莫尔圆；（2）求总应力强度参数 $c_{cu}$ 和 $\varphi_{cu}$；（3）求有效应力强度参数 $c'$ 和 $\varphi'$。

**解题步骤**：

（1）计算各试件参数：

试件1：$\sigma_1 = \sigma_3 + \Delta\sigma = 280$ kPa；$\sigma_1' = 280 - 52 = 228$ kPa
试件2：$\sigma_1 = 500$ kPa；$\sigma_1' = 500 - 88 = 412$ kPa
试件3：$\sigma_1 = 700$ kPa；$\sigma_1' = 700 - 120 = 580$ kPa

（2）在 $\tau$-$\sigma$ 坐标系中绘制总应力莫尔圆（以 $(\sigma_3 + \Delta\sigma/2, \Delta\sigma/2)$ 为圆心，$\Delta\sigma/2$ 为半径）和有效应力莫尔圆。

（3）分别对总应力莫尔圆和有效应力莫尔圆作切线，得到强度包线：

总应力包线（近似直线）：$c_{cu} \approx 10$ kPa，$\tan\varphi_{cu} \approx 0.32$，即 $\varphi_{cu} \approx 18^{\circ}$

有效应力包线：$c' \approx 5$ kPa，$\tan\varphi' \approx 0.42$，即 $\varphi' \approx 23^{\circ}$

**答案**：$c_{cu} \approx 10$ kPa，$\varphi_{cu} \approx 18^{\circ}$；$c' \approx 5$ kPa，$\varphi' \approx 23^{\circ}$。

### 例题6-2（挡土墙主动土压力计算）

**题目**：某重力式挡土墙，墙高 $H = 6$ m，墙后填土水平，填土参数：$\gamma = 18$ kN/m³，$c = 0$，$\varphi = 30^{\circ}$。墙背与填土间的摩擦角 $\delta = 15^{\circ}$（$\delta = 0.5\varphi$）。地下水位在墙底以下，不考虑水压力。用朗肯理论和库仑理论分别计算主动土压力合力 $E_a$ 及作用点位置。

**解题步骤**：

（1）朗肯理论（$\delta = 0$，墙背光滑）：

$$K_a = \tan^2(45^{\circ} - \varphi/2) = \tan^2(45^{\circ} - 15^{\circ}) = \tan^2 30^{\circ} = (0.577)^2 = 0.333$$

$$\sigma_a(z) = K_a \gamma z \quad \Rightarrow \quad E_a = \frac{1}{2} K_a \gamma H^2 = \frac{1}{2} \times 0.333 \times 18 \times 6^2 = 108 \text{ kN/m}$$

作用点：$H/3 = 2$ m（距墙底）

（2）库仑理论（$\delta = 15^{\circ} \neq 0$）：

$$K_a = \frac{\cos^2(\varphi - \alpha)}{\cos^2\delta \cdot \cos(\delta + \alpha)\left[1 + \sqrt{\frac{\sin(\varphi+\delta)\sin(\varphi-\beta)}{\cos(\delta+\alpha)\cos(\delta-\beta)}}\right]^2}$$

其中 $\alpha = 0$（墙背垂直），$\beta = 0$（填土水平）：

$$K_a = \frac{\cos^2 30^{\circ}}{\cos^2 15^{\circ} \cdot \cos 15^{\circ}\left[1 + \sqrt{\frac{\sin 45^{\circ} \sin 30^{\circ}}{\cos^2 15^{\circ}}}\right]^2} = \frac{0.75}{0.966^2 \times 0.966 \times [1 + 0.68]^2} = \frac{0.75}{0.933 \times 2.82} = 0.285$$

$$E_a = \frac{1}{2} K_a \gamma H^2 = \frac{1}{2} \times 0.285 \times 18 \times 36 = 92.3 \text{ kN/m}$$

朗肯公式由于忽略墙背摩擦，多算了 $(108-92.3)/92.3 = 17\%$。

**答案**：朗肯理论 $E_a = 108$ kN/m；库仑理论 $E_a = 92.3$ kN/m（更精确）。

### 例题6-3（各向异性强度对边坡稳定的影响）

**题目**：某层状黏土边坡，坡高 $H = 10$ m，坡角 $\beta = 30^{\circ}$。黏土层理倾角 $\alpha = 15^{\circ}$（倾向坡内）。强度参数：
- 沿层理面：$c' = 5$ kPa，$\varphi' = 18^{\circ}$
- 垂直层理面：$c' = 15$ kPa，$\varphi' = 25^{\circ}$

分析：若滑动面沿层理面发展，与假设各向同性（$c' = 15$ kPa，$\varphi' = 25^{\circ}$）相比，安全系数降低多少？

**解题步骤**：

（1）各向同性假设的安全系数：简化 Bishop 法计算（过程略），假设 $F_s \approx 1.5$。

（2）沿层理面滑动的安全系数：

滑动面沿层理面发展时，应使用层理面强度参数：
- $c' = 5$ kPa，$\varphi' = 18^{\circ}$

重新计算（过程略），$F_s' \approx 1.0$。

（3）安全系数降低：

$$\Delta F_s = 1.5 - 1.0 = 0.5 \text{（降低 33\%）}$$

**答案**：若滑动面沿层理面发展，安全系数从 1.5 降至约 1.0，降低约 33%。这说明各向异性对边坡稳定有显著影响，设计时应考虑最不利的剪切方向。

### 例题6-4（SHANSEP 关系应用）

**题目**：某黏土地基，正常固结状态下 $c_u/\sigma_v' = 0.22$。现取样深度 $z = 10$ m，测得前期固结压力 $\sigma_p' = 180$ kPa，当前有效竖向应力 $\sigma_v' = 100$ kPa。

计算：（1）超固结比 OCR；（2）该深度处的不排水强度 $c_u$。

**解题步骤**：

（1）超固结比：
$$OCR = \frac{\sigma_p'}{\sigma_v'} = \frac{180}{100} = 1.8$$

（2）不排水强度：

采用 SHANSEP 关系，取 $m = 0.8$：
$$\frac{c_u}{\sigma_v'} = \left(\frac{c_u}{\sigma_v'}\right)_{NC} \cdot OCR^m = 0.22 \times 1.8^{0.8} = 0.22 \times 1.58 = 0.348$$

$$c_u = 0.348 \times 100 = 34.8 \text{ kPa}$$

**答案**：（1）OCR = 1.8；（2）$c_u = 34.8$ kPa。超固结使不排水强度提高了约 58%（相比正常固结状态的 22 kPa）。

### 例题6-5（三轴试验数据分析）

**题目**：某黏土 CU 三轴试验，围压 $\sigma_3 = 200$ kPa。固结后剪切，破坏时测得：
- 轴向应力差：$(\sigma_1 - \sigma_3)_f = 280$ kPa
- 孔隙水压力：$u_f = 80$ kPa

计算：（1）破坏时的有效大主应力 $\sigma_1'$；（2）有效小主应力 $\sigma_3'$；（3）若另一组试验（$\sigma_3 = 100$ kPa）测得 $(\sigma_1 - \sigma_3)_f = 140$ kPa，$u_f = 40$ kPa，确定有效应力参数 $c'$、$\varphi'$。

**解题步骤**：

（1）有效大主应力：
$$\sigma_1' = \sigma_1 - u_f = (\sigma_1 - \sigma_3)_f + \sigma_3 - u_f = 280 + 200 - 80 = 400 \text{ kPa}$$

（2）有效小主应力：
$$\sigma_3' = \sigma_3 - u_f = 200 - 80 = 120 \text{ kPa}$$

（3）有效应力参数：

试验一：$\sigma_1' = 400$ kPa，$\sigma_3' = 120$ kPa
试验二：$\sigma_1' = 140 + 100 - 40 = 200$ kPa，$\sigma_3' = 100 - 40 = 60$ kPa

绘制 Mohr 圆，两圆公切线斜率为 $\sin\varphi'$：

$$\sin\varphi' = \frac{R_2 - R_1}{O_2 - O_1} = \frac{(200-60)/2 - (400-120)/2}{(200+60)/2 - (400+120)/2} = \frac{70 - 140}{130 - 260} = \frac{-70}{-130} = 0.538$$

$$\varphi' = \arcsin(0.538) = 32.5^{\circ}$$

黏聚力：
$$c' = \frac{\sigma_1' - \sigma_3'}{2\cos\varphi'} - \frac{\sigma_1' + \sigma_3'}{2}\tan\varphi' = \frac{400-120}{2\cos 32.5^{\circ}} - \frac{400+120}{2}\tan 32.5^{\circ} = \frac{280}{1.68} - 260 \times 0.637 = 167 - 166 \approx 1 \text{ kPa}$$

**答案**：（1）$\sigma_1' = 400$ kPa；（2）$\sigma_3' = 120$ kPa；（3）$c' \approx 0$，$\varphi' = 32.5^{\circ}$。

## 🤖 AI专题：AI在抗剪强度参数预测中的应用

### 研究背景

传统的抗剪强度参数（$c$、$\varphi$）需要通过室内试验或现场测试获得，试验周期长、成本高，且受取样质量影响大。在工程勘察的初步设计阶段，往往需要快速估计强度参数范围，或者对已有的有限数据进行补充和验证。

人工智能技术，特别是**机器学习**（Machine Learning）和**数据挖掘**（Data Mining）方法，为土性参数的快速预测提供了新的途径。

### 机器学习预测模型

常用的机器学习算法包括：

**多元线性回归（MLR）**：建立基本物理参数（干密度、含水量、液限、塑限、粒度成分等）与强度参数之间的线性关系。模型简单，可解释性强，但难以捕捉非线性关系。

**支持向量机回归（SVR）**：通过核函数将数据映射到高维特征空间，在特征空间中寻找最优回归超平面。SVR 在小样本、高维数据条件下表现良好，适合工程勘察数据量有限的特点。

**随机森林（Random Forest）**：通过集成多棵决策树（每棵树使用不同的特征子集和样本子集），取平均值作为预测结果。随机森林具有较高的预测精度和抗过拟合能力，并能自动评估各输入特征的重要性排序。

**神经网络（ANN / DNN / LSTM）**：深度神经网络可以学习土性参数之间的高度非线性映射关系。其中，**物理信息神经网络（PINN）** 还可以将土力学的本构方程作为物理约束嵌入损失函数，提高预测的物理一致性。

### 工程应用案例

**案例：基于随机森林的砂土内摩擦角预测**

某港口工程收集了 326 组砂土试验数据，选用以下特征变量：
- 粒径 $D_{10}$、$D_{30}$、$D_{50}$、$D_{60}$
- 不均匀系数 $C_u$、曲率系数 $C_c$
- 相对密实度 $D_r$
- 击实试验的最大干密度 $\rho_{d,\max}$

将数据随机划分为训练集（75%）和测试集（25%），使用 Python 的 scikit-learn 库训练随机森林模型。

```python
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score
import pandas as pd
import numpy as np

# 读取数据
data = pd.read_csv('sand_data.csv')
X = data[['D10','D30','D50','D60','Cu','Cc','Dr']]
y = data['phi']

# 数据划分
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=42)

# 训练随机森林模型
rf = RandomForestRegressor(n_estimators=200, max_depth=15, random_state=42, n_jobs=-1)
rf.fit(X_train, y_train)

# 预测与评估
y_pred = rf.predict(X_test)
print(f"R² = {r2_score(y_test, y_pred):.3f}")
print(f"RMSE = {np.sqrt(mean_squared_error(y_test, y_pred)):.2f}°")

# 特征重要性
importances = pd.Series(rf.feature_importances_, index=X.columns).sort_values(ascending=False)
print("特征重要性：")
print(importances)
```

典型模型的预测精度可达 $R^2 = 0.85 \sim 0.92$，均方根误差 RMSE $= 2^{\circ} \sim 4^{\circ}$。

### 不确定性量化与可靠度分析

传统设计采用安全系数 $F_s$ 作为单一安全指标，无法反映参数不确定性的影响。基于机器学习的**不确定性量化**（Uncertainty Quantification）方法，可以给出预测值的置信区间，为**可靠度设计**（Reliability-Based Design）提供依据。

常用的不确定性量化方法包括：
- **贝叶斯神经网络**（Bayesian Neural Network）：在网络权重上引入概率分布，而非固定值，从而自然地估计预测不确定性
- **蒙特卡洛Dropout**：利用神经网络中 Dropout 层的随机性，通过多次前向传播估计预测均值和方差
- **集成方法**：训练多个模型（如多个随机森林），以集成预测的均值和方差估计不确定性

在可靠度分析中，可以将机器学习预测的强度参数的概率分布代入 Monte Carlo 模拟，计算工程结构的失效概率 $P_f$，与目标可靠度指标 $\beta$（如 $\beta = 3.0$ 对应 $P_f = 0.00135$）进行比较。

## 🔗 力学知识链贯通

### 从弹性力学到土力学

材料力学中，材料破坏的判据包括最大正应力准则、最大剪应力准则（特雷斯卡准则）和畸变能准则（密塞斯准则）。然而，这些准则均未考虑**中间主应力**的影响。

莫尔-库仑准则只考虑最大和最小主应力，不考虑中间主应力 $\sigma_2$。而更精确的**德鲁克-普拉格准则**（Drucker-Prager Criterion）在莫尔-库仑准则的基础上引入了 $\sigma_2$ 的影响：

$$f = \alpha I_1 + \sqrt{J_2} - k = 0$$

其中 $I_1$ 为应力张量第一不变量，$J_2$ 为应力偏张量第二不变量，$\alpha$ 和 $k$ 为材料参数。

### 塑性力学视角

从塑性力学的角度看，莫尔-库仑准则是一条**屈服函数**（Yield Function），定义了材料从弹性阶段进入塑性阶段的边界。当应力状态满足 $f > 0$ 时，材料发生塑性流动。

在**极限分析上限法**（Upper Bound Limit Analysis）中，利用虚功率原理，通过构造兼容的速度场，可以得到结构极限荷载的上限。土体的相关联流动法则（与非相关联流动法则的对比）是决定屈服面与塑性势面关系的关键。

### 本构关系的层次结构

土的抗剪强度问题的解决，最终依赖于正确的**本构关系**（Constitutive Model）：
- 最简单：线弹性模型（胡克定律）——无法描述土的非线性
- 弹塑性模型：莫尔-库仑模型、Drucker-Prager模型、剑桥模型——工程实践中应用最广
- 高级模型：边界面模型、Hujeux模型、清华模型——适合复杂加载历史

理解这些模型的层次关系，有助于在不同工程问题中选择合适的分析方法。

## 🔖 课程思政：工程安全与生命至上

### 工程事故的警示

土的抗剪强度是工程安全的关键参数。无数工程事故的教训表明，对土的强度特性认识不足或取值不当，可能导致灾难性后果。

**上海莲花河畔倒楼事故（2009）**：7层住宅楼在施工期间整体倾覆。事故调查表明，地下车库基坑开挖后，堆土在楼北侧形成高堆载，产生指向南侧的侧向力；同时，南侧开挖面以下约4.5 m处存在深厚的淤泥质黏土层，该层土的抗剪强度极低，在侧向荷载作用下发生水平向滑移剪切破坏，导致大楼整体倾覆。这一事故深刻说明了**软土强度参数的正确选取**和**施工顺序的科学组织**的重要性。

**深圳渣土场滑坡事故（2015）**：深圳市光明新区红坳渣土场发生特大滑坡事故，造成73人死亡、4人失踪。事故的直接原因是渣土场超高堆填（原始设计堆高仅60 m，实际堆至160 m），同时底部土层为深厚淤泥，抗剪强度极低，在高堆载超载作用下，淤泥层发生剪切破坏，形成远程滑坡。

### 工程师的职业道德

这些事故不仅揭示了技术问题，更警示了工程伦理的重要性。**岩土工程师的职业道德**包括：

1. **严谨求实**：土性参数的选取必须基于充分的勘察和试验，不弄虚作假，不随意降低安全系数
2. **持续学习**：土力学理论和工程实践不断进步，工程师必须持续更新知识
3. **敬畏自然**：地基和边坡是地球系统的一部分，必须充分认识其复杂性和不确定性
4. **安全至上**：当技术判断与经济效益冲突时，安全永远是第一位的

《注册土木工程师（岩土）执业道德准则》明确规定："岩土工程师应当将公众安全、健康和福祉放在首位，在任何情况下都不得以牺牲安全为代价谋取经济利益。"

## 本章小结

1. **莫尔-库仑强度理论**是土力学最核心的破坏准则：$\tau_f = c + \sigma\tan\varphi$。该准则将抗剪强度分解为黏聚分量和摩擦分量，物理意义明确，工程应用广泛。

2. 土的**排水条件**对抗剪强度有决定性影响。UU 试验（不排水）测得不排水强度，CU 试验（固结不排水）可同时得到总应力和有效应力参数，CD 试验（固结排水）得到长期强度参数。

3. **有效应力原理**是理解土体力学行为的基石。孔隙水压力 $u$ 决定有效应力 $\sigma' = \sigma - u$，而土的强度和变形只与有效应力有关。

4. **抗剪强度参数**的选取必须综合考虑：土的类别、排水条件、施工速率、长期或短期分析等因素。不同条件下应选用不同的参数组合。

5. **超固结土**（OCR > 1）表现出与正常固结土显著不同的强度特性：强度包线的非线性、卸载-再加载效应、以及较高的不排水强度。超固结效应对基坑、边坡等工程问题具有重要影响。

6. **各向异性**是天然土体强度的普遍特征，对边坡稳定分析和土压力计算均可能产生不可忽视的影响。

7. **蠕变**和**长期强度**是软土地基、高边坡和挡土墙等长期稳定性问题的核心考量。长期强度通常低于短期强度，设计时需采用适当的折减系数。

8. 抗剪强度参数的**合理选取**应遵循"与设计工况匹配、与试验条件匹配、考虑空间变异性"三原则，并对勘察报告的参数进行严格审核。

9. **人工智能技术**（机器学习、不确定性量化）为土性参数的快速预测提供了新的技术途径，但试验验证和工程判断始终不可或缺。
