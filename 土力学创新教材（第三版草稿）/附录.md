## 附录A 土力学常用公式汇总 `[课下自学]`

### A.1 土的物理性质指标公式 **（对应第2章）**

**三相换算关系**（基本指标：$G_s$、$w$、$\rho$）：

| 指标 | 符号 | 定义 | 计算公式 |
|------|------|------|---------|
| 土粒比重 | $G_s$ | 土粒重/同体积4°C水重 | 由试验确定 |
| 含水率 | $w$ | $w = m_w/m_s \times 100\%$ | 烘干法测定 |
| 密度 | $\rho$ | $\rho = m/V$（Mg/m³） | 环刀法测定 |
| 干密度 | $\rho_d$ | $\rho_d = \rho/(1 + 0.01w)$ | 计算 |
| 饱和密度 | $\rho_{sat}$ | $\rho_{sat} = (G_s + S_r \cdot e)/(1 + e) \cdot \rho_w$ | 计算 |
| 浮密度 | $\rho'$ | $\rho' = \rho_{sat} - \rho_w$ | 计算 |
| 重度 | $\gamma$ | $\gamma = \rho \cdot g$（kN/m³） | 计算 |
| 有效重度 | $\gamma'$ | $\gamma' = \gamma - \gamma_w$ | 计算 |
| 孔隙比 | $e$ | $e = V_v/V_s$ | $e = G_s\rho_w(1+w)/\rho - 1$ |
| 孔隙率 | $n$ | $n = V_v/V \times 100\%$ | $n = e/(1+e) \times 100\%$ |
| 饱和度 | $S_r$ | $S_r = V_w/V_v \times 100\%$ | $S_r = wG_s/e \times 100\%$ |

### A.2 土中应力计算公式 `[课下自学]` **（对应第3章）**

**自重应力**（均质土）：
$$\sigma_{sz} = \gamma z$$

**自重应力**（成层土）：
$$\sigma_{cz} = \sum_{i=1}^{n} \gamma_i h_i$$

**有效自重应力**（有地下水）：
$$\sigma_{cz}' = \sum \gamma_i' h_i \quad (i \text{ 在地下水位以下})$$

**静止侧压力系数**（经验公式）：
$$K_0 = 1 - \sin\varphi' \quad \text{（Jaky公式）}$$

**基底附加压力**：
$$p_0 = p - \sigma_{cd} = p - \gamma_0 D$$

**矩形均布荷载角点法**（深度 $z$ 处应力）：
$$\sigma_z = \alpha_c \cdot p_0$$

（角点下附加应力系数 $\alpha_c$ 查表求得，参见教材第3章）

**布辛尼斯克竖向应力解**（集中力 $P$）：
$$\sigma_z = \frac{3P}{2\pi R^2}\cos^2\theta = \frac{3P}{2\pi z^2}\cos^3\theta$$

**应力路径**（$p$-$q$ 坐标系）：
$$p = \frac{\sigma_1 + \sigma_3}{2}, \quad q = \frac{\sigma_1 - \sigma_3}{2}$$

### A.3 渗透与渗流公式 **（对应第4章）**

**达西定律**：
$$v = k \cdot i$$
$$q = k \cdot i \cdot A$$

**渗透系数**（经验公式）：
- Hazen经验公式（砂土）：$k \approx 0.01 D_{10}^2$（$D_{10}$单位mm，$k$单位cm/s）
- 太沙基经验公式：$k \approx 0.01 \sim 0.001 \cdot d_{20}^2$（$d_{20}$单位mm）

**流网应用**（渗流量）：
$$q = k \cdot \Delta H \cdot \frac{N_f}{N_d}$$

其中 $N_f$ 为流槽数，$N_d$ 为等势线间隔数，$\Delta H$ 为总水头差。

**临界水力坡降**（流土破坏）：
$$i_{cr} = \frac{G_s - 1}{1 + e} = (G_s - 1)(1 - n)$$

**渗流力**（单位体积力）：
$$j = \gamma_w i$$

**非饱和土渗透系数**（Van Genuchten模型）`[课下自学]`：
$$k_r(w) = \frac{k(w)}{k_s} = \sqrt{\Theta} \left[1 - (1 - \Theta^{1/m})^m\right]^2$$

其中 $\Theta = (w - w_r)/(w_s - w_r)$ 为有效饱和度。

### A.4 压缩性与固结公式 **（对应第5章）**

**压缩系数**：
$$a_v = \frac{e_1 - e_2}{\sigma_2 - \sigma_1} \quad (\text{MPa}^{-1})$$

**压缩指数**：
$$C_c = \frac{e_1 - e_2}{\log_{10}(\sigma_2/\sigma_1)}$$

**压缩模量**：
$$E_s = \frac{1 + e_0}{a_v}$$

**分层总和法最终沉降量**：
$$s = \sum_{i=1}^{n} \frac{e_{1i} - e_{2i}}{1 + e_{1i}} \cdot h_i = \sum_{i=1}^{n} \frac{\Delta p_i}{E_{si}} \cdot h_i$$

**太沙基一维固结理论**：
$$\frac{\partial u}{\partial t} = c_v \frac{\partial^2 u}{\partial z^2}$$

**固结度**（精确解）：
$$U_z = 1 - \frac{2}{\pi}\sum_{m=1,3,5}^{\infty}\frac{1}{m}\sin\frac{m\pi z}{2H}\exp\left(-\frac{m^2\pi^2}{4}T_v\right)$$

**平均固结度**（常用近似公式）：
- 当 $U > 60\%$：$T_v = \frac{\pi}{4}U^2$
- 当 $U < 60\%$：$T_v = -\frac{0.933\log_{10}(1-U) - 0.085}{\pi^2/4}$（Sivaram-Homanto公式）

### A.5 抗剪强度公式 **（对应第6章）**

**库仑定律**：
$$\tau_f = c + \sigma \tan\varphi$$

**莫尔-库仑极限平衡**（以主应力表示）：
$$\sigma_1 = \sigma_3 \tan^2\left(45^{\circ} + \frac{\varphi}{2}\right) + 2c\tan\left(45^{\circ} + \frac{\varphi}{2}\right)$$

**抗剪强度指标换算**（UU/CU/CD）`[课下自学]`：
$$c_u = \frac{q_u}{2} \quad (\varphi_u = 0)$$

**孔隙水压力系数**（Skempton）：
$$\Delta u = B[\Delta\sigma_3 + A(\Delta\sigma_1 - \Delta\sigma_3)]$$

**临界状态土力学** `[课下自学]`：
$$q = Mp + c \quad \text{（临界状态线）}$$
其中 $M$ 为临界状态线斜率，$p$ 为平均有效应力，$q$ 为广义剪应力。

### A.6 土压力公式 **（对应第7章）**

**静止土压力**：
$$e_0 = K_0 \gamma z, \quad K_0 = 1 - \sin\varphi'$$

**朗肯主动土压力**：
$$e_a = K_a \gamma z - 2c\sqrt{K_a}, \quad K_a = \tan^2\left(45^{\circ} - \frac{\varphi}{2}\right)$$

**朗肯被动土压力**：
$$e_p = K_p \gamma z + 2c\sqrt{K_p}, \quad K_p = \tan^2\left(45^{\circ} + \frac{\varphi}{2}\right)$$

**总主动土压力**（黏性土）：
$$E_a = \frac{1}{2}K_a\gamma(H - z_0)^2, \quad z_0 = \frac{2c}{\gamma\sqrt{K_a}}$$

**库仑主动土压力系数** `[课下自学]`：
$$K_a = \frac{\cos^2(\varphi - \alpha)}{\cos^2\alpha \cos(\alpha + \delta)\left[1 + \sqrt{\frac{\sin(\varphi + \delta)\sin(\varphi - \beta)}{\cos(\alpha + \delta)\cos(\alpha - \beta)}}\right]^2}$$

**Mononobe-Okabe 地震主动土压力** `[课下自学]`：
$$K_{ae} = \frac{\cos^2(\varphi - \theta - \alpha)}{\cos\theta\cos^2\alpha\cos(\alpha + \delta + \theta)\left[1 + \sqrt{\frac{\sin(\varphi + \delta)\sin(\varphi - \theta - \beta)}{\cos(\alpha + \delta + \theta)\cos(\alpha - \beta)}}\right]^2}$$

其中 $\theta = \arctan(K_h/(1-k_v))$ 为地震惯性角，$K_h$ 为水平地震系数。

---

### A.7 地基承载力公式 **（对应第8章）**

**太沙基极限承载力**（条形基础）`[课下自学]`：
$$p_u = \frac{1}{2}\gamma B N_\gamma + q N_q + c N_c$$

其中：
$$N_q = e^{2\pi\tan\varphi}\tan^2\left(45^{\circ} + \frac{\varphi}{2}\right)$$
$$N_c = (N_q - 1)\cot\varphi$$
$$N_\gamma \approx 0.5(N_q + 1)\tan\varphi$$

**临塑荷载**：
$$p_{cr} = \frac{\pi(\gamma D + c\cot\varphi)}{\cot\varphi + \varphi - \pi/2} + \gamma D$$

**修正后承载力特征值**：
$$f_a = f_{ak} + \eta_b\gamma(B - 3) + \eta_d\gamma_m(D - 0.5)$$

---

### A.8 边坡稳定公式 **（对应第9章）**

**无黏性土坡安全系数**（简单条分法）：
$$F_s = \frac{\tan\varphi}{\tan\beta}$$

**毕肖普条分法安全系数** `[课下自学]`：
$$F_s = \frac{\sum\frac{1}{m_\alpha_i}(c_i'l_i + W_i\tan\varphi_i)}{\sum W_i\sin\alpha_i}$$
其中 $m_{\alpha_i} = \cos\alpha_i + \frac{\tan\varphi_i\sin\alpha_i}{F_s}$

**瑞典条分法**（简化圆弧法）：
$$F_s = \frac{\sum(c_i'l_i + W_i\cos\alpha_i\tan\varphi_i)}{\sum W_i\sin\alpha_i}$$

---

### A.9 土动力特性公式 `[课下自学]` **（对应第10章）**

**Hardin-Drnevich模型参数**：
$$G_{max} = \rho v_s^2, \quad G_d = \frac{G_{max}}{1 + \gamma_d/\gamma_{r}}$$

**Seed液化简化判别法**（标准贯入）：
$$N_{cr} = N_0\left[0.9 + 0.1(d_s - d_w)\right]\sqrt{3/\pi}\cdot\beta$$
$$N_{cr} = N_0 \cdot \beta \left[\ln(0.6d_s + 1.5) - 0.1d_w - \sqrt{\frac{3}{\pi}}(0.6d_s + 1.5)\right]$$

## 附录B 土工试验方法概要

### B.1 室内试验

**颗粒分析试验** **（对应第2章）**
- 筛析法：适用于粒径 $> 0.075$ mm的土
- 密度计法（沉降法）：适用于粒径 $< 0.075$ mm的土
- 移液管法：最精确的细粒土分析方法

**含水率试验** **（对应第2章）**
- 烘干法（标准方法）：$105^{\circ}$C～$110^{\circ}$C烘至恒重
- 酒精燃烧法（快速法）：适用于有机质含量较低的土
- 炒干法：野外快速测定

**密度试验** **（对应第2章）**
- 环刀法：标准方法，适用于黏性土
- 蜡封法：适用于易扰动土样
- 灌砂法：适用于现场测定粗粒土

**界限含水率试验** **（对应第2章）**
- 液限：碟式仪法（ASTM）或圆锥仪法（76g锥沉17mm）
- 塑限：滚搓法（手工）或液限联合测定法
- 缩限：收缩皿法

**击实试验** **（对应第2章）**
- 轻型击实：2.5kg锤，落距30cm，25/3层，每层27击（适用于粒径<20mm）
- 重型击实：4.5kg锤，落距45cm，5/3层，每层59击（适用于粒径<40mm）
- 成果：最优含水率 $w_{op}$、最大干密度 $\rho_{d,max}$

**渗透试验** **（对应第4章）**
- 常水头渗透试验：适用于粗粒土（$k > 10^{-4}$ cm/s）
- 变水头渗透试验：适用于细粒土（$k < 10^{-4}$ cm/s）

**固结试验** **（对应第5章）**
- 逐级加载：每级荷载历时24h（或每h变形<0.01mm）
- 快速固结法：每级荷载历时1h（修正系数法）
- 成果：$e$-$\log p$ 曲线、$C_c$、$C_s$、$c_v$

**直剪试验** **（对应第6章）**
- 三种方法：快剪（Q）、固结快剪（RQ）、慢剪（S）
- 剪切速率：快剪 $> 0.8$ mm/min；慢剪 $< 0.02$ mm/min

**三轴压缩试验** **（对应第6章）**
- UU：每分钟应变0.5%～1.0%
- CU：固结时间 $> 24$ h；剪切速率 $< 0.1$ mm/min
- CD：剪切速率 $< 0.003$ mm/min

**动三轴试验** `[课下自学]` **（对应第10章）**
- 试验目的：测定土的动模量 $E_d$、阻尼比 $\lambda$、动强度
- 波形：正弦波（地震作用模拟）
- 频率：1～2 Hz（模拟地震频率）

**无侧限抗压强度试验** **（对应第6章）**
- 应变速率：1%～2%/min
- 破坏标准：峰值或 $\varepsilon_a = 20\%$

### B.2 原位测试

**标准贯入试验（SPT）** **（对应第2、6、8、10章）**
- 锤重：63.5 kg
- 落距：76 cm
- 贯入深度：30 cm
- 成果：$N$ 值（击/30cm）

**静力触探试验（CPT）** **（对应第2、8章）**
- 锥尖阻力 $q_c$：反映土的密实度和强度
- 侧壁摩阻力 $f_s$：反映土的类别
- 摩阻比：$R_f = f_s/q_c \times 100\%$

**十字板剪切试验** **（对应第6、8章）**
- 常用规格：$75 \times 100$ mm、$50 \times 100$ mm
- 扭矩施加速率：$0.1^{\circ}$～$0.5^{\circ}$/s

**平板载荷试验（PLT）** **（对应第8章）**
- 载荷板尺寸：$0.5 \times 0.5$ m（方形）或 $\phi 0.8$ m（圆形）
- 加载等级：预估极限荷载的 $1/8 \sim 1/10$
- 稳定标准：每级荷载下，沉降量 $< 0.1$ mm/h 且持续 $> 2$ h
