# 《土力学》创新教材 — 详细大纲

> **教材名称**：《土力学》创新教材（拟出版）
> **面向对象**：土木工程、岩土工程、地质工程等本科专业
> **总学时设计**：32学时课堂授课 + 课下自主学习
> **当前规模**：全12章，共286节，约163,500字（持续完善中）

---

## 教材定位与特色

### 核心定位
面向新工科背景下土木工程专业本科教学，系统阐述土力学基本理论与工程应用，深度融合人工智能技术前沿成果与课程思政元素，培养学生自主学习能力与工程创新思维。

### 五大创新方向（贯穿全书）

| 创新方向 | 实现方式 | 特色亮点 |
|---------|---------|---------|
| 🤖 **AI融合** | 每章设置AI应用专题，引入PINN、机器学习、数字孪生 | 智能预测土性参数、应力场、液化风险 |
| 🟥 **课程思政** | 每章设置课程思政专题，融入工程伦理、家国情怀、工匠精神 | 港珠澳/川藏/三峡/京沪高铁等大国工程 |
| 🔗 **力学贯通** | 从理论力学→材料力学→弹性力学→土力学的知识链讲解 | 力学方法在土力学中的系统应用 |
| 📚 **课程群衔接** | 第12章设置课程群知识图谱，关联工程地质、勘察、基础工程、地基处理 | 知识体系的系统贯通 |
| 🚀 **前沿进展** | 第11章集中介绍能源桩、MICP、PHREEQC、冻土工程等 | 科研前沿融入教学 |

### 课时设计理念："授人以鱼"+"授人以渔"

**32学时课堂授课**：聚焦核心知识点、工程案例、关键方法
**课下自主学习**：通过 `[课下自学]` 标识，引导学生利用AI工具自主拓展
- 课下内容类型：补充例题、启发式思考、知识扩展、力学推导、AI工具应用
- AI工具辅助：鼓励学生使用Python、机器学习库、数值模拟工具自主验证

## 教学方法说明

### 课堂32学时安排（建议）

| 教学单元 | 主要内容 | 建议学时 |
|---------|---------|---------|
| 第1~2章 | 土的物理性质与分类 | 5学时 |
| 第3~4章 | 土中应力与渗透性 | 5学时 |
| 第5~6章 | 压缩沉降与抗剪强度 | 6学时 |
| 第7~8章 | 土压力与地基承载力 | 6学时 |
| 第9~10章 | 边坡稳定与动力特性 | 5学时 |
| 第11~12章 | 前沿专题与课程群贯通 | 3学时 |
| 复习与考试 | 综合应用 | 2学时 |

### 课下自学内容（`[课下自学]`标识）

- **补充例题**：每章2~4道，含完整解答
- **启发式思考题**：每章2~4道，引导深入思考
- **知识点扩展**：前沿研究、理论推导、数值方法
- **AI工具应用**：Python编程、机器学习验证、有限元模拟
- **课程思政阅读**：大国工程案例、跨行业应用
