# 前言

这本教材的创新，概括为三个"融"字：

**第一，AI与土力学的融合。**  
人工智能正在深刻改变工程教育的形态。我在书中尝试将物理信息神经网络（PINN）、机器学习预测土性参数、数值模拟等AI方法融入土力学教学——不是要取代经典理论，而是要让学生掌握认识土力学规律的新工具。未来的岩土工程师，既要能用手算，也要会用AI；既要懂公式推导，也要能编程建模。

**第二，力学知识链的贯通。**  
土力学不是凭空产生的，它是力学学科在土这种特殊材料上的应用。这本教材从第1章起，就建立了从理论力学到材料力学、从弹性力学到土力学的知识链条，帮助学生理解土力学公式背后的力学逻辑，做到"知其然，更知其所以然"。

**第三，课程思政的自然融入。**  
土力学从来不缺大国工程的动人故事——青藏铁路建设者在海拔五千米的冻土上修筑路基，港珠澳大桥的建设者用世界最长的海底沉管隧道连接三地，三峡大坝的建设者用精细的渗流控制技术保障大坝安全。讲述这些工程背后的土力学原理，本身就是最好的课程思政——让学生看到，知识如何转化为改变世界的力量。

在本书的编写过程中，我参阅了大量国内外土力学经典教材和前沿文献，借鉴了清华大学、同济大学、浙江大学等高校的先进教学经验，也参考了国内外工程界的最新实践成果，在此一并致以诚挚的感谢。

2026年，是徐学燕老师八十岁寿诞之年。二十三年的师生情谊，成为我生命中最重要的精神财富之一。我常常想，用什么方式来表达对老师的敬意和感谢？思来想去，我觉得没有什么比写一本好教材更合适——因为教材是教师生命的延伸，是知识薪火相传的载体，是学生对老师最好的回报。

这本书之所以有底气提出"创新"，背后站着的是徐学燕老师二十三年来为我打下的坚实基础。没有她在我硕士和博士阶段手把手地教我做学问，就不会有我对土力学原理的深刻理解；没有她毕业后十余年来的持续关心和指导，没有她"严谨务实、宽厚待人"的身体力行，就不会有我今天这本教材的问世。

谨以此书，献给敬爱的恩师徐学燕教授。

献给所有热爱土力学、致力于我国岩土工程事业的人们。
