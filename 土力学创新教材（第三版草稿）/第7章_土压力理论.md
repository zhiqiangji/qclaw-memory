# 土压力理论

## 7.1 概述

### 7.1.1 土压力的定义与工程意义

**土压力**（Earth Pressure）是指挡土墙或侧向支护结构背离填土一侧的土体，对墙体产生的侧向压力。土压力的大小和分布规律是挡土墙设计、基坑支护设计、地下管线设计等岩土工程问题的核心计算内容。

土压力问题广泛存在于各类土木工程实践中：
- **挡土墙**：防止土坡滑塌的永久性支挡结构，如路堤挡墙、河道护岸、地下室侧墙
- **基坑支护**：深基坑开挖时的临时支护体系，如钢板桩、灌注桩、地下连续墙
- **桥台**：桥梁与路堤衔接处的侧向约束
- **隧道衬砌**：地下结构周围的土压力荷载

### 7.1.2 土压力类型

根据挡土墙的位移方向和位移量，土压力分为三种类型：

**静止土压力**（$E_0$）：挡土墙完全静止，不发生任何位移。土体处于侧限压缩状态，侧向应力等于土的自重应力乘以侧压力系数：

$$e_0 = K_0 \cdot \sigma_v = K_0 \cdot \gamma z$$

其中 $K_0$ 为静止土压力系数，$\gamma$ 为土的重度，$z$ 为计算点深度。

**主动土压力**（$E_a$）：挡土墙背离填土方向发生足够位移时，土体达到主动极限平衡状态，此时作用在墙背上的土压力达到最小值。墙主动推土体，土体推墙。

**被动土压力**（$E_p$）：挡土墙向填土方向发生足够位移时，土体达到被动极限平衡状态，此时作用在墙背上的土压力达到最大值。土主动推墙，墙被动抵抗土体。

三种土压力的关系为：$E_a < E_0 < E_p$。对于常规挡土墙设计，主动土压力是最主要的计算工况。

### 7.1.3 影响土压力的因素

土压力的大小和分布受多种因素影响：
- **墙背位移**：位移量和位移模式（平移、绕底转动、绕顶转动）
- **墙背形状和粗糙度**：光滑墙背 $\Rightarrow$ 垂直应力分布；粗糙墙背 $\Rightarrow$ 侧向摩阻力修正
- **填土性质**：重度 $\gamma$、内摩擦角 $\varphi$、黏聚力 $c$、含水量
- **填土表面形态**：水平、倾斜、有荷载
- **墙体材料与刚度**：刚性墙（位移分布决定土压力）；柔性墙（墙身弯曲变形与土压力相互作用）
- **地下水**：水压力与有效土压力的叠加
- **墙体施工方法**：大开挖施工 vs. 打入式施工

## 7.2 静止土压力计算

### 7.2.1 静止土压力系数

**静止土压力系数** $K_0$ 是土体在侧限条件下（无侧向变形）水平有效应力与竖向有效应力的比值：

$$K_0 = \frac{\sigma_h'}{\sigma_v'}$$

$h$ 为土的静止土压力系数，主要受以下因素影响：

**1. 土的性质与应力历史**
- 正常固结土：$K_{0,nc} \approx 1 - \sin\varphi'$（Jaky公式，1948）
- 超固结土：$K_{0,oc} = K_{0,nc} \cdot \text{OCR}^{m}$（Schmidt公式）
  其中 $\text{OCR}$ 为超固结比，$m \approx 0.41$（砂土）或 $m \approx 0.45$（黏土）

**2. 经验取值**
- 砂土：$K_0 = 0.30 \sim 0.50$
- 硬黏土：$K_0 = 0.50 \sim 0.70$
- 软黏土：$K_0 = 0.60 \sim 0.80$
- 超固结黏土：$K_0 > 1.0$（在超固结比很大时可能出现）

### 7.2.2 静止土压力分布与计算

对于均质土层，深度 $z$ 处的静止土压力强度为：

$$e_0(z) = K_0 \gamma z$$

静止土压力沿墙高的分布为**三角形**。总静止土压力为：

$$E_0 = \frac{1}{2} K_0 \gamma H^2$$

其中 $H$ 为墙高。总静止土压力作用点在墙高的下 $1/3$ 处。

对于成层土或地下水位以下，应分层计算。地下水位以下，**采用有效重度** $\gamma'$，且需叠加水压力：

$$e_0(z) = K_0 \gamma z \quad (0 \leq z \leq h_w)$$

$$e_0(z) = K_0 \gamma h_w + K_0 \gamma' (z - h_w) + \gamma_w (z - h_w) \quad (z > h_w)$$

其中 $h_w$ 为地下水位深度，$\gamma_w$ 为水的重度（$9.8$ kN/m³）。

**例题7.1**：某挡土墙高 $H = 6$ m，墙后填土为均质砂土，$\gamma = 18$ kN/m³，$\varphi = 30^{\circ}$，地下水位在地面下 $3$ m 处。求静止土压力分布和总静止土压力。

**解**：由 Jaky 公式，正常固结砂土 $K_0 = 1 - \sin\varphi' = 1 - \sin30° = 0.50$。

地下水位以上（$z = 0 \sim 3$ m）：
$$e_0 = K_0 \gamma z = 0.5 \times 18z = 9z \text{ (kPa)}$$
在 $z = 3$ m 处：$e_0 = 27$ kPa

地下水位以下（$z = 3 \sim 6$ m）：采用有效重度 $\gamma' = 18 - 9.8 = 8.2$ kN/m³
$$e_0 = K_0 \gamma h_w + K_0 \gamma'(z - h_w) + \gamma_w (z - h_w)$$
$$= 27 + 0.5 \times 8.2 \times (z - 3) + 9.8 \times (z - 3)$$
$$= 27 + 4.1(z - 3) + 9.8(z - 3) = 27 + 13.9(z - 3)$$

在 $z = 6$ m 处：$e_0 = 27 + 13.9 \times 3 = 68.7$ kPa

总静止土压力：
- 上部三角形（0~3m）：$E_0^{(1)} = \frac{1}{2} \times 27 \times 3 = 40.5$ kN/m
- 中部矩形（3~6m）：$E_0^{(2)} = 27 \times 3 = 81$ kN/m
- 水压力（3~6m）：$E_w = \frac{1}{2} \gamma_w h_w^2 = \frac{1}{2} \times 9.8 \times 3^2 = 44.1$ kN/m

总静止土压力 $E_0 = 40.5 + 81 + 44.1 = 165.6$ kN/m

## 7.3 朗肯土压力理论

### 7.3.1 基本原理与假定

朗肯土压力理论（Rankine's Earth Pressure Theory）是英国工程师朗肯（W.J.M. Rankine）于1857年提出的。其基本假定为：
1. 墙背垂直、光滑（不考虑墙背与土之间的摩擦力）
2. 填土表面水平
3. 墙身无限长（平面应变条件）
4. 土体为半无限体

在上述假定下，墙背处的土单元处于半无限体的侧限应力状态。当墙体发生位移时，土体从侧限状态逐渐向极限平衡状态发展。与库仑理论相比，朗肯理论基于**极限平衡理论**，数学推导更为简洁。

### 7.3.2 主动土压力

当墙体背离填土方向移动时，土体单元的侧向应力逐渐减小，而竖向应力 $\sigma_v$ 不变（等于自重应力 $\gamma z$）。当 $\sigma_h$ 减小到恰好等于土的抗剪强度时，达到主动极限平衡状态。

由莫尔-库仑极限平衡条件，令 $\sigma_3 = \sigma_h$（主动情况），$\sigma_1 = \sigma_v$：

**无黏性土**（$c = 0$）：
$$e_a = \sigma_v \tan^2\left(45^{\circ} - \frac{\varphi}{2}\right) = K_a \gamma z$$

其中 $K_a = \tan^2(45° - \varphi/2)$ 为主动土压力系数。

**黏性土**（$c \neq 0$）：
$$e_a = K_a \gamma z - 2c\sqrt{K_a}$$

主动土压力沿墙高呈**梯形分布**（黏性土）或**三角形分布**（无黏性土）。

对于黏性土，当 $z < z_0 = 2c/(\gamma\sqrt{K_a})$ 时，$e_a < 0$，即土压力为拉应力。由于土不能承受拉应力，这部分拉应力将被拉裂缝代替。在计算总主动土压力时，从拉应力消失的深度 $z_0$ 开始积分：

$$E_a = \frac{1}{2} K_a \gamma (H - z_0)^2 = \frac{1}{2} K_a \gamma H^2 - 2cH\sqrt{K_a} + \frac{2c^2}{\gamma}$$

### 7.3.3 被动土压力

当墙体向填土方向挤压时，土体单元的侧向应力 $\sigma_h$ 逐渐增大。当 $\sigma_h$ 增大到等于土的抗剪强度时，达到被动极限平衡状态。此时 $\sigma_1 = \sigma_h$（被动情况），$\sigma_3 = \sigma_v$：

**无黏性土**：
$$e_p = \sigma_v \tan^2\left(45^{\circ} + \frac{\varphi}{2}\right) = K_p \gamma z$$

其中 $K_p = \tan^2(45° + \varphi/2)$ 为被动土压力系数。

**黏性土**：
$$e_p = K_p \gamma z + 2c\sqrt{K_p}$$

被动土压力沿墙高呈**梯形分布**（黏性土）或**三角形分布**（无黏性土）。

### 7.3.4 朗肯与库仑土压力系数的比较

| 类型 | 朗肯 $K_a$ | 朗肯 $K_p$ | 库仑 $K_a$ | 库仑 $K_p$ |
|------|-----------|-----------|-----------|-----------|
| $\tan^2(45° \pm \varphi/2)$ | $K_a < 1$ | $K_p > 1$ | $K_a < K_{a,\text{Rankine}}$ | $K_p > K_{p,\text{Rankine}}$ |

库仑理论由于考虑了墙背摩擦力，计算得到的主动土压力通常**小于**朗肯值，被动土压力通常**大于**朗肯值。两者之差在 $\varphi$ 较大时尤为显著。

## 7.4 库仑土压力理论

### 7.4.1 基本原理与假定

1776年，法国工程师库仑（C.A. Coulomb）提出了基于滑动楔体分析的土压力理论。其基本假定为：
1. 墙背粗糙（考虑墙背与土之间的摩擦力）
2. 填土表面为任意形状（倾斜平面、折线、曲线）
3. 滑动破坏面为通过墙踵的平面
4. 滑动楔体为刚体，整体处于极限平衡

库仑理论通过分析墙后滑动土楔的静力平衡（楔体自重 $W$、墙背反力 $R$、破坏面反力 $F$ 三力平衡），求解主动土压力的大小和方向。

### 7.4.2 主动土压力公式推导

设墙背与垂直面的夹角为 $\alpha$（俯斜墙 $\alpha > 0$，仰斜墙 $\alpha < 0$，垂直墙 $\alpha = 0$），填土表面与水平面的夹角为 $\beta$，墙背与土的摩擦角为 $\delta$。

滑动楔体的受力分析：
- 自重 $W$：竖直向下，大小为 $\gamma \times \text{楔体面积}$
- 墙背反力 $R$：与墙背法线成 $\delta$ 角（摩擦角），作用于墙背
- 破坏面反力 $F$：与破坏面法线成 $\varphi$ 角（内摩擦角），作用于滑动面

由三力平衡的力三角形，可以求出 $R$ 和 $F$。作用在墙背上的反力 $R$ 的水平分力即为**主动土压力 $E_a$**：

$$E_a = \frac{1}{2} \gamma H^2 K_a$$

其中：

$$K_a = \frac{\cos^2(\varphi - \alpha)}{\cos^2\alpha \cdot \cos(\alpha + \delta)\left[1 + \sqrt{\frac{\sin(\varphi + \delta)\sin(\varphi - \beta)}{\cos(\alpha + \delta)\cos(\alpha - \beta)}}\right]^2}$$

当 $\alpha = 0$（垂直墙背）、$\beta = 0$（水平填土）、$\delta = 0$（光滑墙背）时，库仑公式简化为朗肯公式。

### 7.4.3 被动土压力

库仑被动土压力公式为：

$$E_p = \frac{1}{2} \gamma H^2 K_p$$

$$K_p = \frac{\cos^2(\varphi + \alpha)}{\cos^2\alpha \cdot \cos(\alpha - \delta)\left[1 - \sqrt{\frac{\sin(\varphi + \delta)\sin(\varphi + \beta)}{\cos(\alpha - \delta)\cos(\alpha - \beta)}}\right]^2}$$

### 7.4.4 库仑与朗肯理论的比较

| 比较项目 | 朗肯理论 | 库仑理论 |
|---------|---------|---------|
| 墙背粗糙度 | 假设光滑 | 考虑摩擦角 $\delta$ |
| 滑动面形状 | 半无限体侧限条件导出 | 假设为平面 |
| 适用条件 | 垂直光滑墙背、水平填土 | 任意墙背、任意填土面 |
| 计算结果（主动） | 通常偏大 | 通常偏小（更经济） |
| 计算结果（被动） | 通常偏小 | 通常偏大（偏保守） |
| 理论严密性 | 严密的极限平衡推导 | 近似方法（平面滑动假设） |

### 7.4.5 墙背摩擦角 $\delta$ 的选取

墙背与土之间的摩擦角 $\delta$ 的取值直接影响库仑土压力的大小。《建筑地基基础设计规范》GB 50007 建议：
- 墙背粗糙、良好排水：$\delta = \varphi/2 \sim 2\varphi/3$
- 墙背粗糙、排水不良：$\delta = \varphi/3$
- 墙背光滑、排水良好：$\delta = \varphi/3 \sim \varphi/2$
- 金属结构：$\delta = \varphi/2$

对于仰斜挡土墙，墙背摩擦力方向向上，有利于减少主动土压力；对于俯斜挡土墙，摩擦力方向向下，不利于减少主动土压力。

### 7.4.6 库仑土压力理论的完整推导 `[课下自学]`

#### 7.4.6.1 库仑滑动土楔模型

1776年，法国工程师 **夏尔·库仑**（Charles Coulomb）提出了基于滑动土楔极限平衡的土压力计算方法。其基本思想是：将墙背与填土之间的三角楔形体视为刚体，当该土楔处于极限平衡（即将滑动但尚未滑动）时，土压力的大小由静力平衡条件确定。

**基本假设**：
1. 墙后填土为理想的均质散粒体（$c = 0$）
2. 滑动面为通过墙踵的平面（滑动土楔为平面楔形体）
3. 墙背与填土之间存在摩擦（摩擦角 $\delta$），但墙背本身为平面
4. 填土表面为平面（水平或倾斜）

#### 7.4.6.2 主动土压力公式推导

考虑墙背垂直（$\alpha = 0$）、填土水平（$\beta = 0$）、墙背摩擦角 $\delta$ 的情况：

**取单位长度墙背对应的滑动土楔为隔离体**，土楔重力 $W = \gamma \cdot A_{土楔} = \gamma \cdot \frac{1}{2} H^2 \tan\theta$（其中 $\theta$ 为滑动面与水平面的夹角）。

**土楔体受力平衡**（水平、竖直方向）：

竖直方向：$R = W / \cos(\theta - \delta)$（$R$ 为滑动面上的反力）

水平方向：$E_a = W \tan(\theta - \delta) = \frac{1}{2} \gamma H^2 \tan\theta \tan(\theta - \delta)$

对 $\theta$ 求导，$\partial E_a / \partial \theta = 0$，得最优 $\theta$ 值。代入得库仑主动土压力公式：

$$K_a = \frac{\cos^2\varphi}{[\cos\delta \cdot (1 + \sqrt{\frac{\sin(\varphi+\delta)\sin(\varphi-\beta)}{\cos(\delta+\alpha)\cos(\delta-\beta)})})^2]}$$

当 $\alpha = 0$，$\beta = 0$ 时：

$$K_a = \frac{\cos^2\varphi}{\cos^2\delta \cdot [1 + \sqrt{\frac{\sin(\varphi+\delta)\sin\varphi}{\cos^2\delta}}]^2}$$

主动土压力合力：
$$E_a = \frac{1}{2} K_a \gamma H^2$$

#### 7.4.6.3 Rankine与库仑理论的对比

| 比较项目 | Rankine理论 | 库仑理论 |
|---------|-------------|---------|
| 基本假设 | 墙背光滑（$\delta = 0$），土体为半无限体 | 墙背可粗糙（$\delta \neq 0$），滑动土楔为平面 |
| 适用范围 | 墙背垂直，填土水平 | 任意墙背倾角 $\alpha$，任意填土坡角 $\beta$ |
| 计算结果 | 通常偏大（保守） | 通常偏小（经济） |
| 土压力分布 | 三角形（线性）| 三角形（线性）|
| 合力作用点 | $H/3$ | $H/3$ |

**结论**：Rankine 理论适用于墙背光滑、填土水平且不需要考虑墙背摩擦的近似估算；库仑理论适用于任意边界条件的实际工程设计。

## 7.5 工程条件下的土压力计算

### 7.5.1 填土表面有均布荷载

当填土表面作用均布荷载 $q$（kPa）时，相当于在填土表面增加了一层厚度为 $q/\gamma$ 的虚拟土层。因此，荷载产生的附加土压力沿墙高为**矩形分布**：

$$e_{a,q} = K_a \cdot q$$

总主动土压力（含自重土压力和荷载土压力）为：

$$E_a = \frac{1}{2} K_a \gamma H^2 + K_a q H$$

### 7.5.2 成层填土

墙后填土由多层不同性质的土组成时，应**分层计算**土压力。每层土按各自的 $\gamma_i$、$K_{a,i}$ 计算压力分布，在土层分界面处压力有突变。

第 $i$ 层土在界面处的主动土压力为：

$$e_{a,i}^{\text{顶}} = K_{a,i} \cdot \sum_{j=1}^{i-1} \gamma_j h_j$$

$$e_{a,i}^{\text{底}} = K_{a,i} \cdot \sum_{j=1}^{i} \gamma_j h_j$$

### 7.5.3 墙后有地下水

地下水对土压力的影响体现在三个方面：
1. **有效重度替代天然重度**：地下水位以下采用有效重度 $\gamma' = \gamma_{\text{sat}} - \gamma_w$
2. **水压力叠加**：地下水位以下需叠加静水压力 $\gamma_w z'$
3. **不利影响**：地下水位上升会降低有效应力，减少摩擦分量，但水压力增加总侧向力

工程中通常计算**土压力**和**水压力**分开，然后叠加。

### 7.5.4 墙后填土为黏性土

黏性土的主动土压力需要考虑：
1. **拉应力区**：墙体与黏性土脱离的区域（$e_a < 0$），此区域会产生垂直裂缝
2. **裂缝深度**：$z_0 = 2c/(K_a \gamma)$
3. **等代内摩擦角法**：工程设计中，为简化计算，通常将黏聚力 $c$ 折算为等效的内摩擦角 $\varphi_d$，即 $c$ 的贡献折算到 $\varphi$ 中

等代内摩擦角的常用计算方法：
$$\tan\varphi_d = \tan\varphi + \frac{2c}{\gamma H}$$

### 7.5.5 局部荷载和集中荷载

当墙后填土表面作用有局部均布荷载 $q$（宽度为 $b$，距墙背距离为 $a$）时，土压力计算需考虑荷载扩散的影响。从荷载边缘向墙背作两条扩散线（与水平面成 $\varphi$ 角），扩散线与墙背的交点即为荷载影响区的边界。在影响区内，土压力增加 $\Delta\sigma_a = K_a q$。

当墙后填土表面作用集中荷载 $P$ 时，可采用**弹性理论解**近似计算：
$$\Delta\sigma_z = \frac{2P}{\pi} \cdot \frac{z^3}{(x^2 + z^2)^2}$$

其中 $x$ 为荷载作用点距墙背的水平距离，$z$ 为计算点深度。

### 7.5.6 折线形墙背

对于折线形墙背（如衡重式挡土墙），需分段计算土压力：
1. 上墙：按库仑理论计算，墙背倾角取上部倾角
2. 下墙：按库仑理论计算，但需考虑上墙土体的"减压平台"效应

**减压平台**：上墙延伸形成的平台，可减小下墙的土压力。

### 7.5.7 土压力分布的工程实测与反演分析

#### 7.5.7.1 实测土压力的技术方法

土压力是挡土墙设计的核心依据，但理论计算与实际土压力之间往往存在差异。工程实测是验证理论、积累经验的重要手段。

**测试技术**：

1. **土压力盒**（Earth Pressure Cell）
   - 类型：钢弦式、液压式、电阻应变式
   - 埋设方法：墙背土压力盒直接埋设于墙-土界面；墙后土体内部土压力盒埋设于不同深度
   - 关键技术：土压力盒的"薄膜刚度效应"——土压力盒本身的刚度与周围土体刚度的差异会导致实测值偏离真实值，需通过标定曲线修正

2. **钢筋应力计**
   - 用于测量挡土墙墙身钢筋的应变，进而推算墙身弯矩和墙背土压力分布
   - 将弯矩分布曲线对 $z$ 求二阶导数，可反算土压力分布：
   $$e(z) = -\frac{d^2M}{dz^2}$$

3. **光纤光栅传感器（FBG）**
   - 新型传感技术，具有精度高、抗干扰、寿命长的优点
   - 可沿挡土墙墙面连续分布，实现土压力的分布式测量

#### 7.5.7.2 实测土压力分布的典型规律

根据大量实测数据的统计分析，挡土墙实测土压力分布呈现以下规律：

**规律一：非线性分布**

理论土压力（朗肯或库仑）为线性分布（$\sigma_a \propto z$）。但实测土压力常呈现明显的非线性特征：
- 墙背上部：实测主动土压力 > 理论值（实测值偏大）
- 墙背下部：实测主动土压力 < 理论值（实测值偏小）
- 原因：墙背与填土之间的摩阻力使土压力方向发生偏转，合力作用点位置上移

**规律二：与墙体变位模式相关**

墙体位移模式（平移 T、绕墙底转动 RT、绕墙顶转动 TT）对土压力分布影响显著：

| 位移模式 | 土压力分布特征 | 合力作用点 |
|---------|--------------|----------|
| T（平移）| 近似线性 | $H/3$ |
| RT（绕底转）| 下部增大、上部减小 | $> H/3$ |
| TT（绕顶转）| 上部增大、下部减小 | $< H/3$ |

**规律三：时间效应**

施工完成初期，实测土压力最小（填土尚未完全压密，墙-土摩阻力较小）；随时间增长，土压力逐渐增大（填土固结、墙-土摩阻力发展），稳定值可能比设计值大 $10\% \sim 30\%$。

### 7.5.8 基坑土压力计算的特殊问题

#### 7.5.8.1 基坑支护结构的土压力特点

基坑工程中的土压力计算与普通挡土墙有本质区别：

**特点一：支护结构的变形模式决定土压力状态**

基坑开挖过程中，支护结构（地下连续墙、钢板桩、排桩）从初始静止状态向主动状态发展。土压力的大小和分布取决于支护结构的**变形模式**和**变形量**。

| 工况 | 支护结构状态 | 土压力类型 | 备注 |
|------|------------|----------|------|
| 开挖前 | 静止 | $K_0$ | 静止土压力 |
| 开挖过程中 | 向坑内变形 | 主动土压力（支护侧）+ 被动土压力（坑内）| 变形量决定侧压力系数 |
| 开挖完成 | 最大变形 | 主动土压力（支护侧）| 坑底以下可能反向 |

**特点二：分区土压力**

基坑支护结构两侧土压力不对称：
- 坑外（支护结构外侧）：主动土压力（或静止土压力）
- 坑内（支护结构内侧）：被动区土压力

坑底以下，被动区土压力（抵抗力）与主动区土压力（推力）之差构成**支护结构的反弯点**（弯矩为零点）。

#### 7.5.8.2 增量法土压力计算

**增量法**（Simplified Trapezoidal Method）是基坑设计中常用的土压力计算方法：

**原理**：将开挖过程分解为若干步，每一步开挖引起的土压力变化作为"增量"，逐步施加于支护结构。

**计算步骤**：
1. 计算初始状态土压力分布（静止土压力）
2. 开挖至第一层标高，卸除该层土的重量，计算卸荷后的土压力增量（主动侧减少，被动侧不变）
3. 架设支撑（或锚杆），记录支撑轴力
4. 继续开挖，重复上述过程
5. 叠加各步增量，得到最终土压力分布和支撑轴力

```python
# 增量法土压力计算（简化Python代码）
def incremental_earth_pressure(K0, Ka, Kp, gamma, c, phi, D, H_exc, z_levels):
    """
    增量法土压力计算
    K0: 静止土压力系数
    Ka: 主动土压力系数
    Kp: 被动土压力系数
    gamma: 土体重度 (kN/m3)
    c: 黏聚力 (kPa)
    phi: 内摩擦角 (deg)
    D: 开挖深度 (m)
    H_exc: 当前开挖深度 (m)
    z_levels: 计算点深度列表 (m)
    """
    results = []
    for z in z_levels:
        if z <= H_exc:
            # 坑内（支护结构内侧）
            sigma = Ka * gamma * z - 2*c * (Ka**0.5)
            p_type = "主动"
        else:
            # 坑外（支护结构外侧）
            sigma = Ka * gamma * H_exc + Kp * gamma * (z - H_exc) - 2*c * (Kp**0.5)
            p_type = "被动"
        results.append((z, sigma, p_type))
    return results

# 示例：开挖至5m深度
z_points = [1, 2, 3, 4, 5, 6, 7, 8]
pressures = incremental_earth_pressure(K0=0.5, Ka=0.33, Kp=3.0, 
                                        gamma=18, c=0, phi=30,
                                        D=10, H_exc=5, z_levels=z_points)
for z, p, t in pressures:
    print(f"深度{z}m: {p:.1f} kPa ({t}侧)")
```

### 7.5.9 加筋土挡墙的土压力分析

#### 7.5.9.1 加筋土的作用机理

**加筋土**（Reinforced Earth）是法国工程师 Henri Vidal 于 1963 年发明的土体加固技术。其基本原理是：

通过在填土中水平铺设加筋材料（土工格栅、土工织物、钢筋带等），利用加筋材与土之间的**摩阻力**，将部分土体重量转化为加筋材的拉力，使土体形成类似复合材料的整体结构。

**简化分析模型**：将加筋土视为等效的"重力式挡土墙"，加筋材的抗拉力等效为墙体的抗滑力。

**加筋土挡墙的设计步骤**：
1. 确定设计参数（墙体高度、坡度、填土参数、加筋材料参数）
2. 内部稳定性分析：验算每层加筋材的抗拔稳定性
3. 外部稳定性分析：验算整体抗滑稳定、抗倾覆稳定、基底压力
4. 排水设计：设置完善的排水系统

#### 7.5.9.2 加筋材的抗拔验算

加筋材的抗拔稳定性由下式控制：
$$\frac{T_i}{W_i \tan\delta} \leq F_{pull}$$

其中 $T_i$ 为第 $i$ 层加筋材的设计拉力，$W_i$ 为该层加筋材上覆土的重量，$\delta$ 为加筋材-土界面的摩擦角。

加筋材的设计拉力 $T_i$ 由墙背土压力确定：
$$T_i = K_a \gamma z_i S_v$$

其中 $S_v$ 为加筋材的竖向间距（通常 $0.4 \sim 1.0$ m）。

## 7.6 地震土压力

### 7.6.1 地震土压力概述

在地震活跃地区（如我国西南、西北地区），挡土墙设计必须考虑地震作用下的土压力。地震惯性力作用于墙后土体和墙体，改变了土压力的分布和大小。

地震土压力的计算方法主要有：
- **拟静力法**：将地震作用简化为水平加速度和竖向加速度，等效为作用在墙后土体和墙体的惯性力
- **Mononobe-Okabe公式**（M-O公式）：库仑理论的地震扩展，是工程中最常用的方法
- **极限分析数值方法**：有限元、离散元等可以考虑地震波的传播和土-结构动力相互作用

### 7.6.2 Mononobe-Okabe基本公式

Mononobe-Okabe（1926, 1929）将库仑土压力理论扩展到地震条件，引入水平地震系数 $k_h$ 和竖向地震系数 $k_v$。地震主动土压力系数为：

$$K_{ae} = \frac{\cos^2(\varphi - \psi - \alpha)}{\cos\psi \cos^2\alpha \cos(\alpha + \delta + \psi)\left[1 + \sqrt{\frac{\sin(\varphi + \delta)\sin(\varphi - \psi - \beta)}{\cos(\alpha + \delta + \psi)\cos(\alpha - \beta)}}\right]^2}$$

其中 $\psi = \arctan(k_h / (1 \pm k_v))$ 为地震角。

地震土压力增量（地震主动土压力减去静主动土压力）通常单独计算，用于设计验算。地震被动土压力可类似计算（M-O被动公式）。

**设计要点**：
1. 对于地震设防烈度 7 度及以上的重要挡土墙，应进行地震土压力验算
2. 地震土压力分布可简化为**倒梯形**（上部增大，下部减小）
3. 应验算地震工况下的**抗滑移稳定性**和**抗倾覆稳定性**

### 7.6.3 地震土压力特点与设计要点

与静力土压力相比，地震土压力有以下特点：

**1. 土压力增大**

地震惯性力使土楔体的下滑力增大，土压力增大。典型情况：
- 7 度地震：土压力增大约 10%~20%
- 8 度地震：土压力增大约 20%~40%
- 9 度地震：土压力增大约 40%~80%

**2. 作用点上移**

地震土压力的作用点位置高于静力土压力（$H/3$），通常在 $0.4H \sim 0.6H$ 处。

**原因**：地震惯性力沿墙高分布，上部土体的惯性力贡献更大。

**3. 竖向地震的影响**

竖向地震系数 $k_v$ 对土压力的影响：
- 竖向向下（$k_v > 0$）：土体重力增大，土压力增大
- 竖向向上（$k_v < 0$）：土体重力减小，土压力减小

通常忽略竖向地震的影响（偏安全）。

**设计建议**：

**地震土压力计算要点**：

1. **地震系数选取**：
   - 中国规范：$k_h = a/g$（$a$ 为设计地震加速度）
   - 实际工程中常取 $k_h = 0.1 \sim 0.3$

2. **墙背摩擦角**：
   - 地震条件下取 $\delta = 0$（偏安全）
   - 或取 $\delta = \varphi/2$（需验算）

3. **作用点位置**：
   - 简化计算取 $0.5H$
   - 精确计算需考虑分布形式

4. **安全系数调整**：
   - 地震工况下安全系数可适当降低
   - 抗滑稳定：$K_s \geq 1.1$
   - 抗倾覆稳定：$K_t \geq 1.3$

## 7.7 挡土墙设计

### 7.7.1 挡土墙的类型

按结构形式，挡土墙分为：
1. **重力式挡土墙**：依靠墙身自重抵抗土压力，浆砌片石或混凝土浇筑，适用于低矮挡墙（$H < 6$ m）
2. **悬臂式挡土墙**：钢筋混凝土结构，适用于中等高度（$H = 6 \sim 12$ m）
3. **扶壁式挡土墙**：在悬臂墙基础上增加肋板，适用于高墙
4. **锚杆挡土墙**：利用锚杆将墙背土压力传递到稳定地层
5. **加筋土挡土墙**：利用拉筋与填土的摩擦作用约束土体
6. **桩板式挡土墙**：抗滑桩与挡土板组合

### 7.7.2 挡土墙设计验算

挡土墙设计需进行以下**稳定性验算**：

**1. 抗滑移稳定性**：
$$F_s = \frac{\text{抗滑力}}{\text{滑动力}} = \frac{(W + E_v)\tan\varphi}{E_h} \geq [F_{s,\min}]$$

通常要求 $F_s \geq 1.3$（静荷载），$F_s \geq 1.1$（地震荷载）。

**2. 抗倾覆稳定性**：
$$F_s = \frac{\text{抗倾覆力矩}}{\text{倾覆力矩}} = \frac{W \cdot x_0 + E_v \cdot x_f}{E_h \cdot y} \geq [F_{s,\min}]$$

通常要求 $F_s \geq 1.5$（静荷载），$F_s \geq 1.2$（地震荷载）。

**3. 地基承载力验算**：
偏心荷载下的基底压力按材料力学公式计算：
$$p_{\max/\min} = \frac{W + E_v}{B} \left(1 \pm \frac{6e}{B}\right) \leq [f_a]$$

其中 $e$ 为偏心距，$[f_a]$ 为修正后的地基承载力特征值。

**4. 墙身强度验算**：按钢筋混凝土结构设计方法验算墙身配筋。

### 7.7.3 改善挡土墙稳定性的措施

1. **增加墙后排水**：排水不畅会导致水压力增大、黏性土膨胀，是挡墙失稳的重要原因
2. **合理选择墙背形式**：仰斜墙背的主动土压力最小，俯斜墙背最大
3. **墙趾加宽**：增大基底宽度，提高抗倾覆稳定性
4. **设置卸荷平台**：在高挡墙中部设置卸荷平台，减小墙体所受土压力
5. **墙后填土优化**：选用砂卵石等低内摩擦角填土（有利于减少主动土压力）

### 7.7.4 挡土墙完整设计流程

挡土墙设计是一个系统工程，需要综合考虑稳定性、强度、变形和经济性。完整的设计流程如下：

**步骤一：确定设计参数**
- 墙高 $H$、墙顶宽度、墙面坡度
- 填土参数：$\gamma$、$c$、$\varphi$
- 地基承载力特征值 $f_a$
- 地下水位位置
- 地震设防烈度

**步骤二：初步拟定墙体尺寸**
- 重力式挡土墙：底宽 $B \approx (0.4 \sim 0.6)H$
- 悬臂式挡土墙：底板宽度 $B \approx (0.5 \sim 0.7)H$
- 扶壁式挡土墙：扶壁间距 $s \approx (0.3 \sim 0.5)H$

**步骤三：土压力计算**
- 根据墙背形式和填土条件选择计算方法（朗肯、库仑）
- 计算主动土压力 $E_a$ 和作用点位置

**步骤四：稳定性验算**
- 抗滑稳定：$K_s = \frac{N\tan\delta + cB}{E_a} \geq 1.3$
- 抗倾覆稳定：$K_t = \frac{M_R}{M_O} \geq 1.6$
- 整体稳定：通过圆弧滑动法验算

**步骤五：地基承载力验算**
- 基底压力：$p_{\max} = \frac{N}{B} + \frac{6M}{B^2} \leq 1.2f_a$
- 偏心距：$e \leq B/6$（避免出现拉应力）

**步骤六：墙身强度验算**
- 计算控制截面的弯矩和剪力
- 配筋计算（钢筋混凝土挡土墙）

**步骤七：构造设计**
- 排水孔设置：间距 2~3 m，直径 5~10 cm
- 滤水层：砂砾料或土工织物
- 变形缝：间距 10~20 m

### 7.7.5 重力式挡土墙设计实例

**设计条件**：
- 墙高 $H = 6$ m，墙背直立，填土水平
- 填土：$\gamma = 18$ kN/m³，$c = 0$，$\varphi = 32^{\circ}$
- 墙背摩擦角 $\delta = 16^{\circ}$（$\varphi/2$）
- 地基：$f_a = 200$ kPa，基底摩擦系数 $\mu = 0.45$
- 墙身材料：浆砌片石，$\gamma_m = 22$ kN/m³

**设计过程**：

（1）土压力计算（库仑理论）：

$$K_a = \frac{\cos^2\varphi}{\cos\delta\left[1 + \sqrt{\frac{\sin(\varphi+\delta)\sin\varphi}{\cos\delta}}\right]^2} = 0.28$$

$$E_a = \frac{1}{2}\gamma H^2 K_a = \frac{1}{2} \times 18 \times 6^2 \times 0.28 = 90.7 \text{ kN/m}$$

作用点距墙底：$z = H/3 = 2$ m

（2）拟定墙体尺寸：

设顶宽 $b = 0.8$ m，底宽 $B = 2.5$ m（$B/H = 0.42$）

墙身自重：
$$W = \frac{1}{2}(b + B) \times H \times \gamma_m = \frac{1}{2} \times 3.3 \times 6 \times 22 = 217.8 \text{ kN/m}$$

（3）抗滑稳定验算：

$$K_s = \frac{W \mu}{E_a} = \frac{217.8 \times 0.45}{90.7} = \frac{98.0}{90.7} = 1.08 < 1.3$$

**不满足！** 需增大底宽或设置基底凸榫。

调整底宽至 $B = 3.0$ m，重新计算：
$$W = \frac{1}{2} \times 3.8 \times 6 \times 22 = 250.8 \text{ kN/m}$$
$$K_s = \frac{250.8 \times 0.45}{90.7} = 1.24 \approx 1.3 \text{（满足）}$$

（4）抗倾覆稳定验算：

墙身重心距墙趾：
$$x_c = \frac{b \times B + \frac{1}{3}(B-b)^2}{b + B} = \frac{0.8 \times 3.0 + \frac{1}{3} \times 2.2^2}{3.8} = 1.25 \text{ m}$$

抗倾覆力矩：$M_R = W \times x_c = 250.8 \times 1.25 = 313.5$ kN·m/m
倾覆力矩：$M_O = E_a \times z = 90.7 \times 2 = 181.4$ kN·m/m

$$K_t = \frac{313.5}{181.4} = 1.73 > 1.6 \text{（满足）}$$

（5）地基承载力验算：

偏心距：
$$e = \frac{B}{2} - \frac{M_R - M_O}{W} = 1.5 - \frac{313.5 - 181.4}{250.8} = 1.5 - 0.53 = 0.97 \text{ m}$$

$e = 0.97$ m $> B/6 = 0.5$ m，基底出现拉应力，**不满足**！

需要进一步调整设计，或采用扩大基础。

### 7.7.6 挡土墙的排水设计

#### 7.7.6.1 排水的重要性

挡土墙后积水会产生以下问题：

1. **土压力增大**：静水压力直接作用在墙背
2. **有效应力降低**：土的有效重度降低，强度降低
3. **冻胀破坏**：冬季积水结冰膨胀，推挤挡土墙
4. **渗透破坏**：渗流可能带走细颗粒，形成空洞

**设计原则**："防排结合，以排为主"

#### 7.7.6.2 排水措施

**1. 地表排水**
- 墙顶设置截水沟
- 填土表面设置防水层（黏土铺盖、土工膜）
- 坡面设置排水沟

**2. 墙身排水**
- 排水孔：直径 5~10 cm，间距 2~3 m，梅花形布置
- 排水管：预埋透水管，集中排水
- 排水层：墙背设置砂砾排水层或土工织物

**3. 基底排水**
- 基底设置排水垫层
- 设置纵向排水沟

### 例题7-1（朗肯与库仑理论对比）

**题目**：某重力式挡土墙，墙高 $H = 5$ m，墙背垂直，墙后填土水平。填土参数：$\gamma = 18$ kN/m³，$c = 0$，$\varphi = 35^{\circ}$。墙背与填土间的摩擦角 $\delta = 20^{\circ}$（工程经验：$\delta \approx 0.5\varphi$）。

试：（1）用朗肯理论计算主动土压力合力 $E_a$ 及分布；（2）用库仑理论计算 $E_a$ 及分布；（3）比较两者差异并说明原因。

**解题步骤**：

（1）朗肯理论（$\delta = 0$）：
$$K_a = \tan^2(45^{\circ} - \varphi/2) = \tan^2(45^{\circ} - 17.5^{\circ}) = \tan^2 27.5^{\circ} = 0.271$$
$$\sigma_a(z) = K_a \gamma z \quad \Rightarrow \quad E_a = \frac{1}{2} \times 0.271 \times 18 \times 25 = 61.0 \text{ kN/m}$$

（2）库仑理论（$\delta = 20^{\circ}$）：
$$K_a = \frac{\cos^2\varphi}{\cos^2\delta [1 + \sqrt{\frac{\sin(\varphi+\delta)\sin\varphi}{\cos^2\delta}}]^2}$$

代入 $\varphi = 35^{\circ}$，$\delta = 20^{\circ}$：
$$K_a = \frac{\cos^2 35^{\circ}}{\cos^2 20^{\circ} [1 + \sqrt{\frac{\sin 55^{\circ} \sin 35^{\circ}}{\cos^2 20^{\circ}}}]^2} = \frac{0.671}{0.883[1+0.866]^2} = \frac{0.671}{0.883 \times 3.48} = 0.219$$

$$E_a = \frac{1}{2} \times 0.219 \times 18 \times 25 = 49.3 \text{ kN/m}$$

（3）比较：
$$E_{a,\text{Rankine}} = 61.0 \text{ kN/m}, \quad E_{a,\text{Coulomb}} = 49.3 \text{ kN/m}$$

朗肯比库仑大 $(61.0 - 49.3)/49.3 = 23.7\%$。原因：朗肯假设墙背完全光滑（$\delta = 0$），忽略了墙背摩擦对土压力的有利影响。

**答案**：（1）$E_a = 61.0$ kN/m（朗肯）；（2）$E_a = 49.3$ kN/m（库仑）；（3）朗肯偏大 23.7%，偏保守。

### 例题7-2（填土表面有超载的土压力）

**题目**：某挡土墙，墙高 $H = 5$ m，填土表面作用均布荷载 $q = 20$ kPa。填土参数：$\gamma = 18$ kN/m³，$c = 0$，$\varphi = 30^{\circ}$。用朗肯理论计算主动土压力分布和总力。

**解题步骤**：

朗肯主动土压力分布：
$$\sigma_a(z) = K_a \gamma z + K_a q$$

其中 $K_a = \tan^2(45^{\circ} - 15^{\circ}) = 0.333$

墙顶（$z = 0$）：$\sigma_a = K_a q = 0.333 \times 20 = 6.67$ kPa
墙底（$z = 5$ m）：$\sigma_a = K_a(\gamma H + q) = 0.333 \times (18 \times 5 + 20) = 0.333 \times 110 = 36.6$ kPa

总主动土压力：
$$E_a = \frac{1}{2} K_a \gamma H^2 + K_a q H = \frac{1}{2} \times 0.333 \times 18 \times 25 + 0.333 \times 20 \times 5$$
$$= 75.0 + 33.3 = 108.3 \text{ kN/m}$$

合力作用点（对墙底的力矩平衡）：
$$y_c = \frac{\frac{1}{2}\gamma H^2 \times \frac{H}{3} + qH \times \frac{H}{2}}{\frac{1}{2}\gamma H^2 + qH} = \frac{75 \times \frac{5}{3} + 33.3 \times 2.5}{108.3} = \frac{125 + 83.3}{108.3} = 1.92 \text{ m}$$

**答案**：总主动土压力 $E_a = 108.3$ kN/m，作用点距墙底 $y_c = 1.92$ m。

### 例题7-3（成层土主动土压力）

**题目**：某挡土墙，墙高 $H = 8$ m。墙后填土分三层：

| 层号 | 土类 | 层厚 (m) | $\gamma$ (kN/m³) | $c$ (kPa) | $\varphi$ (°) |
|------|------|---------|------------------|----------|-------------|
| ① | 砂土 | 3 | 18 | 0 | 32 |
| ② | 粉土 | 3 | 17 | 5 | 20 |
| ③ | 黏土 | 2 | 16 | 15 | 15 |

墙后填土水平，不考虑地下水位。用朗肯理论计算主动土压力分布并绘制土压力图。

**解题步骤**：

（1）计算各层土的主动土压力系数：

$K_{a1} = \tan^2(45° - 32°/2) = \tan^2(29°) = 0.307$
$K_{a2} = \tan^2(45° - 20°/2) = \tan^2(35°) = 0.490$
$K_{a3} = \tan^2(45° - 15°/2) = \tan^2(37.5°) = 0.589$

（2）计算各特征点处的土压力：

**第①层顶**（$z = 0$）：$\sigma_a = 0$

**第①层底 / 第②层顶**（$z = 3$ m）：$\sigma_a^{(1)} = 0.307 \times 18 \times 3 = 16.6$ kPa

**第②层底 / 第③层顶**（$z = 6$ m）：
$$\sigma_a^{(2)} = K_{a2}[\gamma_1 h_1 + \gamma_2 h_2] - 2c_2\sqrt{K_{a2}}$$
$$= 0.490 \times (18 \times 3 + 17 \times 3) - 2 \times 5 \times 0.700 = 0.490 \times 105 - 7.0 = 51.5 - 7.0 = 44.5 \text{ kPa}$$

**第③层底 / 墙底**（$z = 8$ m）：
$$\sigma_a^{(3)} = K_{a3}[\gamma_1 h_1 + \gamma_2 h_2 + \gamma_3 h_3] - 2c_3\sqrt{K_{a3}}$$
$$= 0.589 \times (18 \times 3 + 17 \times 3 + 16 \times 2) - 2 \times 15 \times 0.768$$
$$= 0.589 \times 140 - 23.0 = 82.5 - 23.0 = 59.5 \text{ kPa}$$

（3）计算总主动土压力合力：

分三层计算面积（三角形或梯形）：

$$E_{a1} = \frac{1}{2} \times 16.6 \times 3 = 24.9 \text{ kN/m}$$
$$E_{a2} = \frac{1}{2} \times (16.6 + 44.5) \times 3 = 91.7 \text{ kN/m}$$
$$E_{a3} = \frac{1}{2} \times (44.5 + 59.5) \times 2 = 104.0 \text{ kN/m}$$

$$E_a = 24.9 + 91.7 + 104.0 = 220.6 \text{ kN/m}$$

**答案**：主动土压力分布：$z=0$ 处 $0$ kPa；$z=3$ m 处 $16.6$ kPa；$z=6$ m 处 $44.5$ kPa；$z=8$ m 处 $59.5$ kPa。总合力 $E_a = 220.6$ kN/m。

### 例题7-4（地下水位影响的土压力）

**题目**：某重力式挡土墙，墙高 $H = 6$ m。墙后填土为中砂，$\gamma_{sat} = 19.5$ kN/m³，$\varphi' = 32^{\circ}$，$c' = 0$。地下水位在墙底以上 $h_w = 2.5$ m 处（距墙顶 $z = 3.5$ m）。用朗肯理论计算考虑水压力后的总侧向压力。

**解题步骤**：

（1）主动土压力系数：
$$K_a = \tan^2(45° - 32°/2) = \tan^2 29° = 0.307$$

（2）土压力分布（用浮重度计算地下水位以下）：

- 墙顶（$z = 0$）：$\sigma_a = 0$
- 地下水位（$z = 3.5$ m）：$\sigma_a = K_a \gamma_{sat} z = 0.307 \times 19.5 \times 3.5 = 21.0$ kPa（注意：水位以上实际重度也是 $\gamma_{sat}$，因假设填土处于饱和状态）
  更精确地：水位以上用天然重度 $\gamma = 18$ kN/m³：
  $\sigma_a(3.5) = K_a(\gamma \times 1.5 + \gamma' \times 2.0) = 0.307 \times (18 \times 1.5 + 9.5 \times 2.0) = 0.307 \times (27 + 19) = 14.1$ kPa
- 墙底（$z = 6$ m）：
  $\sigma_a(6) = K_a(\gamma \times 1.5 + \gamma' \times 4.5) = 0.307 \times (27 + 42.75) = 21.4$ kPa

（3）水压力分布（地下水位以下，三角形分布）：
- 墙底水压力：$\sigma_w = \gamma_w \times h_w = 10 \times 2.5 = 25$ kPa

（4）总压力分布（代数叠加）：
- 墙底总压力：$21.4 + 25 = 46.4$ kPa

（5）总压力合力：
- 土压力合力：梯形面积 $= (14.1 + 21.4)/2 \times 6 - 1/2 \times 10 \times 2.5$ 的水压力... 
  实际上：
  $E_a = 1/2 \times (0 + 14.1) \times 3.5 + 1/2 \times (14.1 + 21.4) \times 2.5 = 24.7 + 44.4 = 69.1$ kN/m
  $E_w = 1/2 \times 25 \times 2.5 = 31.3$ kN/m
  $E_{total} = 69.1 + 31.3 = 100.4$ kN/m

**答案**：总侧向压力合力 $E \approx 100.4$ kN/m，其中土压力 $69.1$ kN/m，水压力 $31.3$ kN/m。

### 例题7-6（地震土压力计算）

**题目**：某挡土墙，墙高 $H = 6$ m，墙背直立，填土水平。填土：$\gamma = 18$ kN/m³，$\varphi = 30^{\circ}$，$c = 0$。设计地震加速度 $a = 0.2g$（8 度）。

计算：（1）静力主动土压力；（2）地震主动土压力；（3）地震土压力增大百分比。

**解题步骤**：

（1）静力主动土压力（朗肯理论）：
$$K_a = \tan^2(45° - 30°/2) = 0.333$$
$$E_a = \frac{1}{2} \times 18 \times 6^2 \times 0.333 = 108 \text{ kN/m}$$

（2）地震主动土压力：

地震角：$\theta = \arctan(0.2) = 11.3°$

采用简化公式：
$$K_{ae} \approx \frac{K_a}{1 - k_h \tan\varphi} = \frac{0.333}{1 - 0.2 \times 0.577} = \frac{0.333}{0.885} = 0.376$$

$$E_{ae} = \frac{1}{2} \times 18 \times 6^2 \times 0.376 = 121.7 \text{ kN/m}$$

（3）增大百分比：
$$\frac{E_{ae} - E_a}{E_a} = \frac{121.7 - 108}{108} = 12.7\%$$

**答案**：（1）静力土压力 108 kN/m；（2）地震土压力 121.7 kN/m；（3）增大 12.7%。

### 研究背景

传统土压力计算依赖于简化假定（如平面滑动面、线性破坏包线等），难以考虑地质条件的空间变异性、墙体-土体相互作用以及施工全过程的影响。人工智能技术为土压力分析提供了以下新途径：

1. **有限元/离散元数值模拟**：机器学习加速大规模数值计算
2. **不确定性量化**：考虑土性参数空间变异性的可靠土压力分析
3. **优化设计**：挡土墙截面的多目标优化

### 物理信息神经网络（PINN）求解土压力

PINN将土力学的基本方程嵌入神经网络的损失函数中，在训练数据有限的情况下仍能给出符合物理规律的预测。

**以朗肯主动土压力为例的PINN框架**：

```python
import torch
import torch.nn as nn
import numpy as np

class EarthPressurePINN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 64), nn.Tanh(),
            nn.Linear(64, 64), nn.Tanh(),
            nn.Linear(64, 64), nn.Tanh(),
            nn.Linear(64, 1)
        )
    
    def forward(self, z, phi):
        # z: 深度, phi: 内摩擦角
        x = torch.cat([z, phi], dim=1)
        return self.net(x)
    
    def physics_loss(self, z, phi, gamma, Ka):
        # 强制满足朗肯土压力公式 e_a = Ka * gamma * z
        pred = self.forward(z, phi)
        Ka_pred = pred / (gamma * z + 1e-8)
        return torch.mean((Ka_pred - Ka)**2)

# 训练数据
z_data = torch.tensor([[z] for z in np.linspace(0, 6, 50)], dtype=torch.float32)
gamma = 18.0; phi = 30.0; Ka = np.tan(np.radians(45 - phi/2))**2
e_data = torch.tensor([[Ka * gamma * z] for z in np.linspace(0, 6, 50)], dtype=torch.float32)

# 训练（物理约束损失 + 数据拟合损失）
# PINN学习的是在任意(gamma, phi)条件下的通用土压力规律
```

## 🟥 课程思政：基础设施安全与国计民生 🟥

### 挡土墙失稳的教训

挡土墙是基础设施中数量最多、覆盖面最广的支挡结构之一。据不完全统计，我国公路、铁路、水利、城市建设中每年新建挡土墙超过数万公里。挡土墙的失稳破坏不仅造成经济损失，更可能危及人民生命安全。

**案例：某山区公路挡土墙倒塌（2010年）**
某省道改造工程中，一段高8米的浆砌片石挡土墙在雨季发生倒塌，造成2人死亡、3人受伤。事故调查发现：
- 墙后填土为含大量黏土块的开挖弃渣，压实度不足
- 挡墙未设置排水设施，墙后积水严重
- 原设计将墙后填土视为均质砂卵石，实际为复杂混合土
- 施工期间未进行抗滑稳定性验算

### 工程师的精细化设计意识

土压力计算看似简单，实则对工程判断的要求极高。一个好的土压力计算工程师，必须：
1. **深入理解土-结构相互作用**：不能机械套用公式，要根据现场条件判断选用哪种理论
2. **重视勘察资料**：土的 $\gamma$、$\varphi$、$c$ 直接决定计算结果，必须严格审查勘察报告
3. **做好排水设计**：排水不良是挡墙失稳的首要原因，排水设计应与土压力计算同等重视
4. **留有安全裕度**：计算结果的可靠性取决于参数的可靠性，设计应考虑参数的不确定性

## 本章小结

1. 土压力分为**静止土压力、主动土压力和被动土压力**三种类型，其大小关系为 $E_a < E_0 < E_p$。

2. **朗肯土压力理论**假定墙背垂直光滑、填土水平，基于半无限体的极限平衡条件推导，计算公式简洁：$e_a = K_a \gamma z$。

3. **库仑土压力理论**考虑墙背摩擦力和任意填土面形状，通过滑动楔体静力平衡分析推导，计算结果更接近工程实际。

4. 实际工程中，应根据**墙背粗糙度、填土条件、排水条件**等因素选择合适的计算方法。规范建议对粗糙墙背、复杂填土条件使用库仑公式。

5. **地震土压力**采用Mononobe-Okabe拟静力法计算，将地震加速度等效为惯性力。

6. 挡土墙设计需进行**抗滑移、抗倾覆、地基承载力**三项稳定性验算，并满足相应的安全系数要求。

7. **排水设计**是挡土墙设计的生命线，必须与土压力计算同等重视。
