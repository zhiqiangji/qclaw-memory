## 问题描述

用户在整合各个 Markdown 文件为 DOCX 文件时，出现了格式不正常的问题，表格和公式都有显示问题。但是用 Trae 里安装的插件显示就是正确的。

## 问题分析

### 表格格式问题
普通文本编辑器或简单复制粘贴无法正确解析 Markdown 表格的分隔符（`|`）和对齐标记（`-`）

### LaTeX 公式问题
DOCX 本身不支持原生 LaTeX 语法，需要特殊处理才能正确渲染数学公式

### Trae 插件能正确显示的原因
Trae 内置了专业的 Markdown 解析器和 LaTeX 渲染引擎（如 KaTeX 或 MathJax）

## 解决方案

### 使用 Pandoc 进行专业转换

创建了专门的转换脚本，实现以下功能：

1. **自动按章节顺序合并**所有 Markdown 文件：
   - 序
   - 前言
   - 大纲
   - 第1章 绪论
   - 第2章 土的物理性质及分类
   - 第3章 土中应力
   - 第4章 土的渗透性与渗流
   - 第5章 土的压缩性与地基沉降
   - 第6章 土的抗剪强度
   - 第7章 土压力理论
   - 第8章 地基承载力
   - 第9章 土坡稳定分析
   - 第10章 土的动力特性
   - 第11章 岩土工程前沿专题
   - 第12章 综合应用与课程群知识图谱
   - 知识图谱
   - 附录

2. **使用 Pandoc 参数确保正确转换**：
   - `--mathml`：将 LaTeX 公式转换为 MathML 格式，确保在 DOCX 中正确渲染
   - `--table-of-contents`：自动生成目录
   - `--toc-depth=3`：目录深度为3级
   - `--number-sections`：自动章节编号
   - `-V lang=zh-CN`：设置语言为中文

## 生成的文件

- `整合教材.md`：合并后的完整 Markdown 文件
- `土力学创新教材.docx`：最终转换的 DOCX 文件，包含正确显示的表格和公式

## 转换命令

```bash
pandoc 整合教材.md -o 土力学创新教材.docx \
  --from markdown \
  --to docx \
  --mathml \
  --table-of-contents \
  --toc-depth=3 \
  --number-sections \
  --highlight-style=pygments \
  -V lang=zh-CN
```

## 注意事项

如果公式仍然显示有问题，可能需要确保 Word 版本支持 MathML（建议使用 Office 365 或较新版本）。
