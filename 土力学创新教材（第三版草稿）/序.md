# 序

土力学是土木工程专业的核心基础课程之一。它之所以重要，不仅因为所有建筑物都"坐"在土或岩基上，更因为土是一种介于固体与流体之间的特殊材料——它同时具有颗粒骨架的力学刚度，又充满可以流动的孔隙水，还有可能发生复杂的化学与热力学相互作用。这种多相耦合的复杂性，使得土力学成为最接近真实自然界、最富有工程挑战性的力学分支，也对教学提出了更高的要求。

长期以来，我国高校土力学教材大多以经典理论为主线，强调公式推导和计算方法，这当然是必要的。但面对新工科建设的新要求，面对人工智能等新技术对传统学科的深刻渗透，面对"碳达峰、碳中和"背景下绿色岩土工程的迫切需求，我们有没有可能编写一部既有扎实理论根基、又能引领学科前沿、还能激发学生创新思维的新型土力学教材？

吉植强教授的这本《土力学》创新教材，就是对这一问题的有益探索。我有幸在付梓之前通读全稿，认为本书具有以下鲜明特色：

**第一，力学知识体系的贯通。** 本书从第1章起，便明确建立了从理论力学到材料力学、从弹性力学到土力学的知识链条，帮助学生理解土力学公式背后的力学逻辑，而非孤立记忆。这种贯通让学生明白：土力学不是一座孤岛，而是力学学科体系中一脉相承、枝繁叶茂的一支。

**第二，人工智能与土力学教学的有机融合。** 书中既有对物理信息神经网络（PINN）求解渗流场、机器学习预测液化风险的专题介绍，也在各章例题中穿插Python实现。这种融合不是贴标签式的赶时髦，而是真正将AI作为认识土力学规律的新工具、新视角传授给学生——未来的土木工程师既要能用手算，也要会用AI。

**第三，课程思政的自然融入。** 从港珠澳大桥海底隧道到川藏铁路高原冻土路基，从三峡大坝的渗流控制到京沪高铁的无砟轨道沉降控制——这些大国工程案例不是外加的"思政点缀"，而是土力学原理最生动、最有说服力的应用场景。当学生理解了青藏铁路建设者如何用热棒技术驯服冻土，他们对有效应力原理的理解也会更加深刻。

**第四，课程群知识的系统衔接。** 土力学上承工程地质，下接基础工程与地基处理。本书第12章专门绘制了完整的课程群知识图谱，帮助学生建立"大土木"的整体视野，为后续专业课程的学习奠定系统性基础。

当然，任何教材都有继续打磨的空间。本书的部分章节在深度上还有提升余地，有些工程案例的交代还可以更充分。但瑕不掩瑜，这是一部有追求、有特色、有创新精神的新型土力学教材。

植强是我2003年招收的硕士研究生，后于2006年直博，2010年获得博士学位。在近七年的师生相处中，他给我的印象是：勤于思考、肯下功夫、对土力学问题有一种发自内心的兴趣。他硕士和博士阶段均在我的指导下完成，研究方向从冻土力学逐渐扩展到环境岩土工程。毕业后十五年来，他始终保持与我的密切联系，在教学和科研上不断精进，先后主持国家自然科学基金项目3项，在相关领域取得了扎实的学术成果。

更难能可贵的是，植强始终坚守教学一线，对土力学教学怀有深厚感情。他常说，想写一本学生真正看得懂、喜欢看的土力学教材。这本教材的面世，正是他三十五年教学思考和学术积淀的结晶。

是为序。

哈尔滨工业大学教授、博士生导师
